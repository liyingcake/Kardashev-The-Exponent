## 1. 目标与定位

M02 回答三个问题：**玩家什么时候经历什么？玩家靠什么长？玩家为什么愿意重来？**

- **纪元**＝文明成长的"节奏骨架"：把 00 文档的 11 档功率阶梯翻译成玩家可感知的时代主题、标志性突破与里程碑时刻。
- **科技树**＝文明成长的"机制引擎"：5 条分支不只加数值，更承担"玩法范式切换"——每一个重要纪元都要引入一种新玩法，避免中后期退化成纯数字比拼。
- **Prestige**＝文明成长的"回环"：纪元更替即 Prestige，让玩家带着"文明的记忆"（文明特质永久乘数）重走一遍功率阶梯，最终以"奇点式体验"收束到 T1 与二周目戴森球相位。

**一句话定位**：*"文明不是一条直线，而是十次脱胎换骨。"* —— M02 负责把这十次"脱胎换骨"做成可执行的设计。

## 2. 范围与边界

**范围内**：
1. 10 个纪元的功率门槛、时代主题、标志性突破、进入/离开里程碑时刻（动画与文案方向）。
2. 5 条科技分支的层级结构、每纪元解锁网格、机制解锁器清单。
3. 科技卡字段模板与 6 张示例卡。
4. Prestige 完整流程、文明特质池（10 个永久乘数）、重置/保留清单、T1 奇点包装、二周目"戴森球相位"。
5. 时间映射方案（30–60 现实小时 ↔ 模拟年）。

**范围外**（与 02 文档口径一致，写明边界）：
- ❌ 能源/资源的结算公式与 EROI 精确定值 → M01。
- ❌ 事件内容本体与风险系统 → M04（本模块只定义"纪元状态机"与事件挂接点）。
- ❌ 轨道力学/殖民地热力学手感 → M03（本模块只定义太空科技对 M03 的解锁接口）。
- ❌ 完整过场动画/叙事 → M07（阶段 2）。里程碑时刻只给"方向"，不产出资产。
- ❌ 数值平衡终值 → 阶段 1 数值原型用电子表格跑通（01 文档 Roadmap）。
- ❌ 逐国家逐人物的历史复刻 → 文明抽象化，科技名用通用概念（"蒸汽机"而非"瓦特的蒸汽机"）。

#### 3.1.3 纪元专属机制（防止"中后期只是数字变大"）

每个纪元引入一个新玩法范式，随纪元进入解锁、随 Prestige 重置，随对应科技线深化：

1. **火种**：最小循环教学（采集→燃烧→分配），无分支决策。
2. **农耕**：**资源互斥取舍**——同一块地在"种田/放牧/晒盐"间二选一，首次引入沉没成本。
3. **青铜·铁器**：**金属倍率资源**（铜→青铜→铁逐级解锁倍率）+ 道路物流。
4. **前工业**：**科研系统诞生**（印刷术解锁论文系统，见 3.2.3）+ 跨区贸易。
5. **早期工业**：**集中 vs 分布**——工厂集中化省维护但造供给瓶颈；作坊分布式灵活但效率低。
6. **电气化**：**电网架构抉择**（集中电站 + 输电网 vs 分布式小电站）+ 人口爆发期。
7. **原子能**：**太空层解锁**（第一个"行星外"UI 区域）。
8. **近未来**：**全球科研网络**（跨区域科研协同，区域数×区域数 的协同乘数）+ AI 自动化。
9. **聚变**：**轨道工业物流链**（行星↔轨道双向物流，能耗换效率）。
10. **行星际**：**跨行星功率网络**（光速延迟 + 传输损耗），手动决策集中于轨道/殖民。
11. **T1**：奇点演出，无玩法。

### 3.2 科技树结构

#### 3.2.1 五条分支总览

每条分支 7–10 层，共约 44 层，每层 2–3 张卡 → **全树 100–130 张**；阶段 1 数值原型只做**骨架 60 张**（每纪元每分支 1 张 + 全部机制解锁器）。

| 分支 | ID | 子线（层级演进） | 核心贡献 | 灵魂机制卡 |
|---|---|---|---|---|
| 能源 | ENE | 火源→水力/风帆→蒸汽→电力→核电→聚变→戴森 | 直接推高 P，主功率线 | 取火 / 蒸汽机 / 电网 / 受控聚变 |
| 材料 | MAT | 石器→青铜→钢铁→合金→半导体→超导→纳米→戴森材料 | 开采效率、设施等级、建筑上限 | 铁器冶炼 / 贝塞麦钢 / 超导 |
| 社会制度 | SOC | 部落→城邦→帝国→行会→公司→国家→跨国→全球治理→行星政府→太阳系协议 | 人口上限、效率乘数、科研加成 | 文字 / 印刷术 / 互联网 |
| 太空 | SPC | 天文→火箭→卫星→空间站→月球→火星→小行星→拉格朗日→戴森 | 解锁 M03 轨道层与行星际资源 | 人造卫星 / 轨道工业 / 戴森云 |
| 自动化 | AUT | 畜力→水磨→机械钟→纺织机→装配线→自动化工厂→计算机→互联网→AI→空间自治 | 离线/挂机收益、劳动力解放 | 装配线 / AI / 自复制机器人 |

**层级规则**：
- 每分支内科技分两类——**工具卡**（线性，推功率，几乎必点）与**范式卡**（机制解锁器，可跳点，见 3.2.3）。
- 跨分支前置（如 SOC 的文字 → ENE 的灌溉 → MAT 的青铜）形成"分工-协作"织网，鼓励玩家横向铺开而非一条线点到底。
- 每纪元至少 1 张范式卡，保证"每次纪元更替都有新玩法"。

### 3.3 科技卡模板

每张科技卡 = 一个"迷你成就 + 一次规则变化 + 一条科学知识"。

#### 字段定义

| 字段 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `编号` | 是 | `分支ID-纪元-序号`，全树唯一 | `ENE-4-02` |
| `名称` | 是 | 通用概念名，不绑定真实国家/人物 | 蒸汽机 |
| `年代` | 是 | 模拟年份（启发式，见 3.5） | 模拟年 1760 |

| `前置` | 是 | 科技 ID 列表（可空）；含跨分支前置 | `ENE-3-01`、`MAT-3-02` |
| `成本` | 是 | 科研点 + 特殊资源；公式见下方"成本草案" | 3000 RP + 铁锭×50 |
| `类型` | 是 | `工具` / `机制` / `范式` | 工具 |
| `效果-数值` | 是 | 交给 M01 的修改器（±% 或 +绝对量） | 煤炭开采 +50% |
| `效果-机制` | 条件 | 触发的玩法变化（机制卡必填） | 解锁论文系统 |
| `科学说明` | 是 | 1–2 句真实历史/物理，标 `[硬数据]`/`[软数据]` | 蒸汽机把热能→机械功，效率早期约 5% `[软数据]` |
| `待核实项` | 条件 | 需科学顾问确认的数值与建议来源 | 早期蒸汽机热效率区间 |
| `里程碑` | 否 | 是否触发进入/离开时刻 | 触发"离开纪元4" |
| `百科链接` | 否 | 指向 M05 百科条目 ID | `ENC-ENE-04` |

#### 成本草案（[软数据]，阶段 1 校准）

```
科研点成本 RP = 基础成本 × 分支系数 × 纪元修正
  基础成本：第 n 层工具卡 ≈ 100 × 10^(0.15n)；范式卡 ×3
  分支系数：ENE 1.0 / MAT 1.1 / SOC 1.2 / SPC 1.3 / AUT 1.0
  纪元修正：(1 + 0.15 × 当前纪元档位)
科研点产出 RP/秒 ≈ 盈余功率 S × 0.05 × 科学范式乘数 × (1 + 区域协同)
  （S 为负 → 科研停摆，与 00 文档一致）
```

### 3.4 Prestige 系统

#### 3.4.1 纪元更替完整流程

> **Prestige = 纪元更替**（00 文档 §5）。每次跨过功率门槛都是一次 Prestige，共 9 次更替 + 1 次 T1 通关。

1. **触发条件**：净功率连续 ≥ 下一纪元门槛 30 个"模拟月"（换算见 3.5；离线可累计）。玩家可点"准备更替"暂缓，最多暂缓 3 次。
2. **结算**：产出**文明印记**（Prestige 货币）：
   ```
   印记 = round( log10(P_峰值 / P_门槛) × 50 )
         + 已解锁科技数 × 3
         + (人口峰值 / 人口门槛) × 10
         + 首次完成本纪元成就 × 20
   ```
   超额功率越多印记越多 → 鼓励"憋足了再更替"。
3. **选择文明特质**：从特质池抽 3 选 1（池见 3.4.2）；已有槽位上限时改为"强化已有特质"。
4. **重置**：按 3.4.3 清单回退资源/人口/建筑/科技树。
5. **保留**：文明特质（永久乘数）、文明印记余额、百科/图鉴、编年史、皮肤装饰、二周目解锁位。
6. **重生演出**：文明从灰烬中重起但带着记忆——旁白 *"文明没有消失，它只是换了一种活法。"* 新纪元门槛标尺显示为"已征服"状态（视觉上镀金）。

**槽位进度**：起始 1 槽；第 2/4/6/8 次更替各 +1 槽 → 最终 5 槽。同类乘数**加性**叠加（两个 +10% 科研 = +20%），防叠乘爆炸。

#### 3.4.4 T1 奇点体验与二周目"戴森球相位"

**T1 奇点演出**（对标 Universal Paperclips 奇点阶段的"失控之美"）：
1. 净功率达 10¹⁶ W 且累计达标 30 现实分钟（可离线累计）→ 通关判定。
2. 演出脚本：戴森云首环合拢 → 视角拉远到太阳系 → 全轨道能源线路逐条点亮 → **数字失控**：功率、人口、建筑量以 ×10/秒 疯涨 10 秒，屏幕读数超越可读性。
3. 白屏过场 + 一行字：*"我们不再需要刻度了。"*
4. 结算：本局成就总览、印记折算、二周目解锁提示。

**二周目"戴森球相位"**（本阶段只做彩蛋级设计）：
- 换皮重开：文明从"行星文明"升格为"恒星文明"，主题从"征服地球功率"变为"包裹一颗恒星"。
- 新指标：K 标尺上方出现 **D 指数（戴森完成度 0–100%）**；功率需求从 10¹⁶ 起步冲向 10²⁶ W（T2 门槛，K=2.0）。

- 保留：全部文明特质 + 额外"戴森特权"（每次更替多选 1 特质）。
- 本阶段交付物：概念图 + 一段占位文案 + 入口按钮，具体玩法进 M06/阶段 2。

### 3.5 时间映射（30–60 现实小时 ↔ 模拟年）

#### 3.5.1 总量方案

- **总跨度：约 8,000–10,000 模拟年**（Q1 倾向，与 02 文档"~8000 年"一致）。
- 与真实历史的对应是**启发式压缩**：真实从取火到现代是数十万年，游戏压缩为万年量级，**压缩本身透明展示**（百科标注"此处时间轴已压缩，真实火种时代持续数十万年"）。
- **现实总时长**：活跃玩法约 20–25 小时；标称 **30–60 现实小时**（含挂机/离线弹性），与 00 文档 §6 一致。

#### 3.5.2 模拟流速函数草案（[设计自由]）

```
时间流速 v(模拟年/现实秒) = C × 10^( −a × 纪元档位 )
  草案：C = 20（火种期 1 现实秒 ≈ 20 模拟年）
       a = 0.85（每过一个纪元，流速约 ×1/7）
→ 前段飞掠数千年（教学感、史诗感），后段贴近"实时直播一个文明"（挂机感）
```

#### 3.5.3 各纪元现实时长分配

| 区间 | 现实时长 | 阶段性质 | 模拟年覆盖（草案） |
|---|---|---|---|
| 火种→农耕（K 0.0→0.1） | 10 分钟 | 教学 | ~3,000 年 |
| 农耕→青铜铁器 | 15 分钟 | 教学/首次取舍 | ~2,000 年 |
| 青铜铁器→前工业 | 15 分钟 | 快节奏 | ~1,200 年 |
| 前工业→早期工业 | 20–30 分钟 | 科研系统上线 | ~800 年 |
| 早期工业→电气化 | 1 小时 | 手动高峰 | ~300 年 |
| 电气化→原子能 | 1–1.5 小时 | 手动高峰 | ~150 年 |
| 原子能→近未来 | 1.5–2 小时 | 太空层解锁 | ~80 年 |
| 近未来→聚变 | 3–4 小时 | 手动决策高峰 | ~40 年 |
| 聚变→行星际 | 4–6 小时 | 挂机提速段 | ~30 年 |
| 行星际→T1 | 6–10 小时 | 离线/挂机主导 | ~20 年 |
| **合计** | **≈ 20–25 活跃小时** | 标称 30–60h（含离线） | **≈ 8,620 模拟年** |

#### 3.5.4 挂机/离线规则（Q5 倾向）

- **离线收益上限 = 36 现实小时 × 离线效率系数**；离线效率系数受 AUT 分支与"协作本能"特质影响（0.4→1.0）。
- 离线期间自动按"最高历史纪元"结算，不触发事件、不消耗关键资源。
- 防"上线即无敌"：离线收益封顶 + 关键资源（聚变燃料/轨道产能）离线效率额外打折。

## 5. 风险与开放问题

### 5.1 设计风险

| 风险 | 说明 | 缓解 |
|---|---|---|
| 科技树规模爆炸 | 100–130 张卡制作成本高、平衡难 | 阶段 1 只做 60 张骨架；范式卡优先保证 |
| "机制感"流失 | 后期科技退化为纯数值 | 硬性规则：每纪元 ≥1 张机制卡（3.2.3 清单为保底） |
| Prestige 挫败感 | 全重置让玩家觉得"白玩了" | 保留清单透明（3.4.3）+ 文明印记可视化 + 镀金视觉 |
| 时间流速困惑 | 流速函数非线性，玩家不知道"一年多久" | UI 常驻"纪元历"（模拟年月日实时显示） |
| 与 M01 冲突 | M01 的 P 阶梯若改动，纪元门槛表作废 | 纪元表只引用不定义；变更走 00 文档回改流程 |

### 5.2 本模块遗留开放问题（供汇总）

1. **更替时机**：达标后自动更替 vs 玩家手动确认（草案：自动检测 + 3 次暂缓机会）。
2. **科研点是否完全重置**：草案——工具卡清空、范式类成果保留为"百科永久解锁"。
3. **文明特质抽取**：随机 3 选 1 vs 自由选购（印记消费）。草案倾向 3 选 1（随机带来重开策略性）。
4. **模拟年总量**：8,000 vs 10,000 年，需阶段 1 用电子表格验证节奏后定标。
5. **T1 通关判定**：净功率达标 30 现实分钟（累计）是否太松/太紧，待原型数据。
