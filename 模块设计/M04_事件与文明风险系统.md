# M04 事件与文明风险系统（因果链事件）v0.1

> 设计原则锚点：**P4 失败即内容**——文明崩溃是因果链事件而非 Game Over 惩罚。
> 核心约束锚点：**EROI 是文明命脉**（见 00 文档 §3），本模块所有"能源危机"类事件必须以"真实因果链"上演并可视化。
> 配套文档：《00_总指标与设计锚点》《01_设计规范与计划》《02_讨论范畴与开放问题》。
> 本模块依赖：M01（核心循环/资源/人口状态量）、M02（纪元/科技树/Prestige）、M03（轨道/殖民地事件源）、M05（百科/教学展示）。

---

## 1) 目标与定位

### 1.1 一句话定位

把"文明为什么崩溃"设计成一套**可阅读、可干预、可回退、可学习**的因果链剧场：EROI 跌破、资源枯竭、气候临界等硬约束不再是抽象的红色警示数字，而是从"原因"出发、经过"中间环节"、抵达"后果"的多段链条，玩家可以在链条上截断、缓解或转化危机。

### 1.2 设计目标

1. **崩溃可读**：任何一次文明衰减，玩家能指着因果链说"死因是这条链上的第 3 个环节"。
2. **EROI 神圣化**：EROI 是"法则一"，峰值石油、电网过载、能源枯竭等全部由 EROI/储量真实状态触发，而非随机刮刮乐。
3. **失败有营养**：每一次失败产出三样东西——视觉冲击（灾难演出）、数值教训（Post-mortem 分析）、可保留的知识（历史教训条目，回退后不丢失）。
4. **回退有代价**：允许时间倒流（Q3 倾向：允许），但用"时间信标"限定次数、用"教训留存"保障教育价值、用"余波不可完全抹除"维持紧张感。
5. **特质有记忆**：成功渡过的危机固化进文明特质（永久乘数），随 Prestige 保留，成为文明"性格"。

### 1.3 定位边界（与 M05 的分工）

- 本模块负责**事件的规则、数据结构、危机库、回退逻辑**（内容层 + 规则层）。
- M05 负责**这些规则的呈现**：百科条目、科学卡片、因果链 UI 的动效、教学引导。本模块只给出 UI 需求清单，不实现。

## 2) 范围与边界

### 2.1 范畴内（本轮设计）

- 事件生成规则：状态量阈值触发 + 纪元风险钟概率触发（双层系统）。
- 因果链数据结构：触发节点 → 中间传播节点 → 后果节点，含延迟/放大/分支。
- 因果链 UI 可视化需求（交互与信息结构，动效交给 M05）。
- 危机库草案：12 个跨纪元代表性危机（含 2 个扩展库成员），每个含触发/因果链/应对/失败后果/科学说明。
- 检查点与回退规则：时间信标机制、回退保留清单、教育价值保障。
- 事件成功奖励：科研加成、韧性特质、历史教训条目，与 M02 特质系统接口。
- 对 02 文档 Q1–Q8 给出倾向性答案（本模块相关部分）。

### 2.2 范畴外（明确不做）

- **不模拟真实国家/人物/政治实体**（遵循 02 §2）：社会动荡是抽象"社会凝聚力"指标，不是具体政权更迭。
- **不做完整过场动画/长文本叙事**（阶段 2 归 M07）；事件以"卡片 + 因果链图 + 短句日志"呈现。
- **不做 T2+ 文明事件**；大过滤器事件只做"解锁二周目相位"的彩蛋级接入。
- **不做事件写作工具**（阶段 3 平衡与填充时再考虑数据驱动配置表）。
- 不做数值精确的气候/流行病仿真：用"风险系数"抽象，物理真实只保证在链条两端。

### 2.3 设计原则落点

| 原则 | 在 M04 的落点 |
|---|---|
| P1 模糊正确 | 所有事件数值标 [软数据]/[待核实]，常数（如 CO₂ 温度敏感度）标 [硬数据] |
| P2 透明简化 | 事件百科标注"此事件已简化：真实世界机制见科学卡片 X" |
| P4 失败即内容 | 崩溃=因果链内容，失败产出教训条目，回退保留知识 |
| P5 数字有意义 | 事件触发一律读真实状态量，禁止纯随机伤害 |

## 3) 关键机制与数值草案

### 3.1 事件生成规则：双层系统

事件分为两个来源，所有事件最终都必须**在因果链面板上显示触发依据**（否则玩家认为游戏在作弊，违反 P1/P5）。

#### 层 1：确定性阈值触发器（"前兆"）

状态量跌破/升破阈值即触发**前兆事件**（黄色预警），给玩家观察窗口，若持续恶化则升级为危机（红色）。

| 触发器 | 判定状态量（来自 M01/M02） | 前兆阈值 | 危机阈值 | 事件示例 |
|---|---|---|---|---|
| EROI 报警 | 当前能源组合加权 EROI Ē | Ē < 8 [软数据] | Ē < 3 | 峰值石油、能源危机 |
| 储量枯竭 | 主能源储采比 R = 储量/年耗 | R < 30 年 | R < 12 年 | 森林枯竭、峰值石油 |
| 人口过载 | 食物盈余率 = (食物产出−人口维持)/食物产出 | < 5% | < 0%（负） | 粮荒/黑死病前兆 |
| 热浪/过载 | 峰值负荷/装机容量 L | L > 85% | L > 98% | 电网过载 |
| 气候压力 | 累计排放 CO₂ × 温度敏感系数 → ΔT | ΔT > +0.5℃ | ΔT > +1.2℃ | 气候临界点 |
| 盈余为负 | 净功率盈余 S | S < 0（连续 5 年） | S < 0（连续 20 年） | 文明衰减、科研停摆 |
| 卫生/密度 | 人口密度 × 卫生水平系数 D | D > 城市容量 120% | D > 150% | 黑死病（大流行） |
| 社会张力 | 通胀指数 × 不平等系数 G | G > 60 | G > 85 | 社会动荡 |
| 设施老化 | 平均设施冗余/维护投入 M | M < 30% | M < 10% | 核危机、殖民事故、电网过载 |
| 轨道风险 | 殖民地生命维持冗余（M03 手感层） | 冗余 < 200% | 冗余 < 100% | 殖民事故 |

> 阈值均为 [软数据] 草案，待阶段 1 数值原型校调。原则：**前兆先于危机**，给玩家"看得到、来得及"的机会窗口。

#### 层 2：纪元风险钟（概率性扰动）

- 每个纪元有一个"风险钟"，按模拟年倒计时，归零掷骰决定是否激活一次随机扰动（小事件或危机前兆）。
- 风险钟周期随纪元缩短：**文明越高级，能量体系越复杂，失效模式越多**。

| 纪元 | K | 风险钟周期（模拟年） | 扰动强度系数 | 事件类型池 |
|---|---|---|---|---|
| 0–1 火种/农耕 | 0.0–0.1 | 200 | 0.3 | 天灾类（小冰期、野火、洪涝） |
| 2–3 铁器/前工业 | 0.2–0.3 | 150 | 0.5 | 疫病、森林枯竭、社会动荡 |
| 4–5 工业/电气化 | 0.4–0.5 | 100 | 0.8 | 峰值石油、电网过载、环境退化 |
| 6–7 原子能/近未来 | 0.6–0.7 | 75 | 1.0 | 核危机、气候临界、太阳耀斑 |
| 8–9 聚变/行星际 | 0.8–0.9 | 50 | 1.2 | 殖民事故、大过滤器前兆、供应链断裂 |

- **加权逻辑**：状态越差，风险钟走得越快。风险钟速度 ×= (1 + 风险压力系数)，压力系数由 EROI 低下、盈余为负、维护不足等因素累加。
- **里程碑事件**：每个纪元强制安排 1–2 个"标志性危机"（如纪元 5 必遇峰值石油或电网过载），保证"失败即内容"的教学密度，且事件与 M02 科技树解锁节奏挂钩。

### 3.2 因果链机制

#### 3.2.1 数据结构草案（事件配置）

```yaml
id: "peak_oil"                    # 事件 ID
name: "石油峰值"
epochs: [5, 6, 7]                 # 可发生纪元
trigger:                          # 层1 阈值触发（也可由风险钟掷骰命中）
  metric: "weighted_eroi_fossil"  # 判定状态量
  when: "< 8"
  window_years: 25                # 从预警到爆发的观察窗口
nodes:                            # 因果链节点（左→右）
  - {id: N1, kind: cause,   name: "轻质原油枯竭",   metric: "oil_peak_reached"}
  - {id: N2, kind: relay,   name: "油价×3",         delay_years: 5,  amp: 1.0}
  - {id: N3, kind: relay,   name: "运输/化工成本↑", delay_years: 3,  amp: 1.2}
  - {id: N4, kind: relay,   name: "通胀与社会动荡", delay_years: 8,  amp: 1.3}
  - {id: N5, kind: relay,   name: "科研预算收缩",   delay_years: 5,  amp: 0.9}
  - {id: N6, kind: effect,  name: "文明功率 -20~40%", damage: "P×0.6", trait_damage: "科研速率×0.5"}
interventions:                    # 玩家干预点
  - {at: N2, action: "转型新能源", cost: {science: 300, surplus: 10}, effect: "截断 N3–N6"}
  - {at: N3, action: "需求压缩政策", cost: {surplus: 5, population_happy: -10}, effect: "强度 -40%"}
  - {at: N4, action: "补贴民生", cost: {surplus: 8}, effect: "截断 N5–N6"}
failure: {effect: "P×0.6 持续 20 年", loot: "教训条目 '能量饥荒'"}
success: {rewards: {science_bonus: "+15% 五年", trait: "能源多样化", lesson: "过渡期=能源转型"}, }
```

#### 3.2.2 传播规则

1. **链式推进**：每个 relay 节点有 `delay_years`（传播延迟），玩家在延迟窗口内可干预；节点间传播由"因果链接通器"驱动——只有上游节点真正达成（数值条件满足）才推进到下游，**不搞假链条**（P5）。
2. **放大/衰减**：`amp` 系数反映环节放大效应（如通胀对社会的非线性放大）；链条总伤害 = Π(amp) × 基础伤害。
3. **分支与合流**：允许 1 个原因分叉成多个后果（如能源危机 → 社会动荡 **且** 科研停摆），也允许多个前兆合流入同一危机（风险钟扰动叠加阈值触发）。
4. **中断即停滞**：节点状态有"传导态/已中断/已转化"三种；中断后下游全部熄灭，但上游损伤结算已发生（如石油峰值不可逆，只能转化其后果）。
5. **因果一致性硬约束**：链条的中间环节必须与现实因果一致（"石油峰值→通胀"成立，"石油峰值→直接扣血"不允许）。审查由科学顾问执行。

#### 3.2.3 玩家干预点（何时可截断/转化）

| 干预类型 | 时机 | 机制 | 代价形式 |
|---|---|---|---|
| **截断** | 任一 relay 节点延迟窗口内 | 直接切断某节点向下游传导 | 科研点 / 盈余 / 人口满意度 |
| **缓解** | 任意节点 | 降低 amp 或缩短后果持续时间 | 同上，成本低于截断 |
| **转化** | 特定"机会节点"（用 ⚡ 标记） | 把危机转成收益（如疫病后劳动力短缺→推动机械替代科研，黑死病史实） | 需先解锁对应科技 |
| **被动防御** | 前兆期（预警） | 提前投资（储备、维护、冗余）降低强度 | 盈余消耗，先行投入 |

> 设计点：**转化干预**是"失败即内容"的正面表达——鼓励玩家在危机中看到机遇，而不是只想着逃避。

#### 3.2.4 因果链 UI 可视化需求（交互信息结构，供 M05）

- **因果链面板**：左→右节点链，每个节点显示：图标 + 状态量读数 + 传导进度条（剩余延迟年数）。危机从预警（黄）→爆发（红）→余波（褐）三色。
- **干预点高亮**：可干预节点显示金色"干预槽"，悬停展开可选行动与代价，行动确认后有反馈演出（链条断裂/变绿的动画）。
- **触发依据页签**：每个事件头部有"为什么发生"标签，点开显示触发它所需的全部状态量快照（触发前 5 年对比图）——兑现 P5。
- **历史时间线**：主界面左侧垂直时间线记录全部事件（含成功与失败），每条可点开复盘因果链。**历史即内容**：失败的时间线条目保留，回退后仍可见（见 3.4）。
- **风险钟显示**：顶部小图标显示风险钟进度与压力来源（hover 显示哪些状态在拉高风险）。

### 3.3 危机库草案（12 个跨纪元危机）

> 标记：📖=历史类，🔬=物理类，🌍=环境类，🛰=太空类，❓=理论概念类。数值均为 [软数据]；科学说明均 [待核实]，权威来源 URL 见 §6 清单。

#### 3.3.1 小冰期（冷事件）— 📖 纪元 2–6，天然/气候

- **触发**：纪元 2–4 权重最高；火山活动指数高 + 太阳活动处于长周期低值 + CO₂ 浓度低于阈值时风险钟加速。
- **因果链**：太阳辐射↓×火山气溶胶 → 全球均温 −0.5~1.5℃ → 生长季缩短 → 粮食减产 20–40% → 饥荒/人口衰减 → 劳动力不足 → 功率产出下降。
- **可选应对**：储备粮仓（提前，前兆期）；抗寒作物选育（科研）；暖房/温室技术（纪元 3+ 解锁）；向暖区移民（消耗资源）。⚠ 有"转化机会"：低温压低虫害/疫病，可转成农业稳定性提升。
- **失败后果**：人口 −15%，盈余 −30% 持续 25 模拟年；若同时社会张力高则连锁触发"社会动荡"。
- **科学说明**：约 1300–1850 年间全球多处冷期，火山与太阳活动为主要外因（小冰期成因仍属学术讨论）[待核实]。

#### 3.3.2 黑死病（大流行）— 📖 纪元 1–4，生物

- **触发**：城市人口密度超阈值 × 卫生技术等级低 × 贸易/航线网络已连通（跨区传播）。
- **因果链**：病原经贸易引入 → 城市内高密度传播 → 人口 −30~60% → 劳动力骤缺 → 生产与税收崩溃 → 社会结构重组。
- **可选应对**：隔离与检疫（纪元 2 前兆期可执行）；公共卫生/下水道科研；城市疏散（降低密度，代价是资源流失）。⚠ **转化机会**：劳动力贵 → 机械化/畜力替代的科研加速（史实：黑死病后欧洲工资上涨、技术替代加速）。
- **失败后果**：人口 −20%（若已前置卫生科研则 −10%），维持体系暂时失衡。
- **科学说明**：1346–1353 年黑死病，欧洲人口死亡约三分之一至一半，普遍引用"约 1/3" [待核实]。

#### 3.3.3 森林枯竭（薪柴危机）— 🌍 纪元 0–3，资源

- **触发**：生物质（薪柴）年消耗率 > 再生率持续 30 年，森林存量跌破安全线。
- **因果链**：薪柴过采 → 森林退化 → 生物质 EROI 下降（砍更远/更差柴）→ 冶炼/制陶/取暖能源短缺 → 城镇产出下降 → 被迫烧劣质燃料（成本更高）或砍光存量。
- **可选应对**：林业轮作管理（低成本，恢复再生率）；提前转煤炭/畜力（科技依赖）；节约用能政策。⚠ 无转化机会（纯损耗型），但尽早转型收益最高。
- **失败后果**：能源产出 −25%，"存量森林"被一次性耗尽导致 EROI 永久再降。
- **科学说明**：古代多文明面临薪柴危机；复活节岛、美索不达米亚为常引案例 [待核实]。

#### 3.3.4 峰值石油（Hubbert 峰值）— 🔬 纪元 5–7，能源

- **触发**：石油储采比 R < 15 年 或 化石能源加权 EROI < 8（见 3.1 触发器表）。
- **因果链**：轻质原油峰值 → 石油产量见顶 → 油价 ×3 → 运输/化工/化肥成本全面上升 → 通胀 → 社会动荡 → 科研预算收缩 → 文明功率 −20~40%。
- **可选应对**：新能源转型（核/可再生，高科研成本，截断全链）；需求压缩（节能）；低 EROI 续命（页岩/重油，只缓解 10–20 年）；燃油税再分配（缓解社会动荡环节）。
- **失败后果**：功率 ×0.6 持续 20 年；若社会动荡环节未处理，叠加"科研停摆"条目。
- **科学说明**：Hubbert 1956 峰值理论；美国本土常规石油 1970 年前后达峰为标志案例 [待核实]。

#### 3.3.5 电网过载（级联停电）— 🔬 纪元 5–9，基础设施

- **触发**：峰值负荷/装机容量 > 85% 且储能容量不足。
- **因果链**：负荷尖峰 → 频率跌落 → 连锁跳闸（级联故障）→ 大面积停电 → 工业/制冷/供水停摆 → 功率骤降 + 城市秩序压力。
- **可选应对**：储能投资（前兆期）；需求响应（削峰）；分区隔离与黑启动预案（减少级联）；分布式微网（冗余）。⚠ 无转化，纯防御型。
- **失败后果**：短时功率 −50% 达 2–3 个模拟月，恢复成本（盈余）高，电网设备老化 +1 档。
- **科学说明**：2003 年美加大停电、2021 年德州电网崩溃为典型级联停电案例 [待核实]。

#### 3.3.6 核危机（堆芯事故）— 🔬 纪元 6–8，能源

- **触发**：核设施维护投入 M < 30% 且随机自然灾害（地/水/热）命中，或设计冗余等级低。
- **因果链**：维护不足/极端事件 → 堆芯熔毁 → 辐射泄漏 → 民众反核 → 政策限核 → 核能产能清零 → 能源缺口退回化石（推高排放）。
- **可选应对**：安全预算投资（前兆期，成本高但最有效）；三区独立监管（缓和社会环节）；选址分散化（降低事件概率）；被动安全堆型科研（熔盐堆，未来免疫）。
- **失败后果**：核能产能清零，其他能源扩张延迟 10 年；社会凝聚力 −10。
- **科学说明**：三哩岛（1979）、切尔诺贝利（1986）、福岛（2011）三大事故的共性：人因/维护/极端事件耦合 [待核实]。

#### 3.3.7 气候临界点（反噬）— 🌍 纪元 6–9，环境

- **触发**：累计 CO₂ 排放驱动温升 ΔT > +1.2℃（温度敏感系数 [硬数据]：IPCC 平衡气候敏感度 ≈ 3℃/2×CO₂，游戏内线性化）。
- **因果链**：温升 → 触发临界要素（AMOC 减弱/亚马逊退化/极地冰盖加速崩解）→ 气候模式剧变 → 农业带迁移 → 粮荒 → 移民冲突 → 功率重组。
- **可选应对**：碳捕集（碳税驱动）；甲烷/CO₂ 减排政策（长期）；加速聚变/地热替代；行星工程（反射板，[设计自由] 高争议）。⚠ 临界点有"不可逆"标记——即使后续降温，部分后果（冰盖）保持。
- **失败后果**：粮食产出 −30% 永久，人口上限 −20%；北极冰盖崩解后海平面上升触发沿海设施损失。
- **科学说明**：Lenton 等 2008 年提出地球系统临界要素；AMOC、亚马逊、冰盖为最常被引的三个 [待核实]。

#### 3.3.8 太阳耀斑（磁暴）— 🔬 纪元 4–9，天文

- **触发**：风险钟掷骰（低概率周期性），纪元 4+ 起可用；周期约 100–150 模拟年触发一次"接近事件"，小概率（约 1/3）升级为强磁暴。
- **因果链**：耀斑 → 日冕物质抛射 → 磁暴 → 电网变压器过载 + 卫星失效 → 通信/导航中断 → 供应链断裂 → 临时功率 −40%。
- **可选应对**：变压器冗余储备（前兆期，成本高）；卫星关断保护协议；地下/光纤冗余通信；磁暴预警系统（科研）。⚠ 无转化。
- **失败后果**：基础设施大修消耗盈余，电网老化 +1 档；若恰逢电网过载（3.3.5）则两者叠加（合流）。
- **科学说明**：1859 年卡灵顿事件（全球电报系统失灵）、1989 年魁北克停电为经典案例 [待核实]。

#### 3.3.9 殖民事故（基地失压/生态循环崩溃）— 🛰 纪元 8–9，轨道/殖民地（接口 M03）

- **触发**：殖民地生命维持冗余 < 100% 或气密结构老化；由 M03 手感层状态提供事件源。
- **因果链**：结构/生命维持故障 → 氧气/水循环崩溃 → 殖民人员损失 → 殖民地进度回退 + 投资方信心下降 → 星际计划预算削减。
- **可选应对**：冗余系统投资（氧气/水双回路）；自动维修机器人；疏散与救援预案；地面试车全流程（降低事故率）。
- **失败后果**：殖民地人口 −50%，星际预算 −30%（下个纪元爬坡变慢）。
- **科学说明**：阿波罗 13（1970）失压求生、联盟 11（1971）减压悲剧为参考；殖民地闭环生态（如 BIOS-3/MELiSSA）仍在研发 [待核实]。

#### 3.3.10 大过滤器（文明筛查）— ❓ 纪元 9→K=1.0，理论概念

- **触发**：K ≥ 0.95 时强制激活（仅一次）；设计定位为"K1.0 前最后考试"，回答"文明有没有资格成为 I 型文明"。
- **因果链**：文明跃入行星际规模 → 宇宙"沉默"悖论浮出 → 一次全文明能力审查：综合韧性特质总数、冗余覆盖率、教育传承、科研无死角度 → 判定"通过/降级"。
- **可选应对**：前置积累韧性特质（长期）；事件内一次文明级抉择：**分散化生存**（多点低耦合，稳健，发展慢）vs **集中化突破**（高速，脆弱）。⚠ 二选一影响二周目相位差异。
- **失败后果**：不 Game Over——判定为"保守文明"，K 上限临时锁定 0.98 十个模拟年，期间只能稳健发展；解锁二周目"戴森球相位"（00 §5 彩蛋级设计）。
- **科学说明**：费米悖论与大过滤器假说（Hanson 1998）为概念来源；本事件属 [设计自由]，科学上无约束，作为"元叙事仪式" [待核实]。

#### 3.3.11 社会动荡（粮价/革命）— 📖 纪元 2–7（扩展库）

- **触发**：社会张力 G > 85（由粮价、通胀、不平等累积）且盈余为负。
- **因果链**：粮价上涨 → 民生恶化 → 叛乱/罢工 → 基建破坏 + 科研停滞 → 功率 −10~20%。
- **可选应对**：社会政策（教育/福利，长期）；粮价平抑（盈余换稳定）；改革导向科研（把动荡转成制度更新——转化机会：战后重建 + 生产力 +5%）。
- **失败后果**：人口 −10%，随机设施损坏 2 个。

#### 3.3.12 关键矿产短缺（稀土断供）— 🌍 纪元 6–9（扩展库）

- **触发**：稀土/关键金属储采比 < 20 年且回收率低。
- **因果链**：矿产短缺 → 电子/电池/磁体产能下降 → 自动化与新能源升级减速 → 技术代际回退半档。
- **可选应对**：回收体系（前兆期）；替代材料科研；深空采矿解锁（纪元 8+）。
- **失败后果**：自动化升级进度回退，新能源 EROI 临时 −10%（因为缺磁体/电池）。

### 3.4 检查点 / 回退规则

#### 3.4.1 检查点机制

- **自动检查点**：每个危机**触发（预警）瞬间**自动生成快照（状态量、资源、科技、设施完整备份）。这是玩家可回退的"事件前"基准。
- **手动检查点**：玩家可额外手动标记（消耗 1 个时间信标），用于自己看中的时机。

#### 3.4.2 回退规则（"时间信标"）

- **信标额度**：每纪元 2 个，可通过"历史积分"（见 3.5）额外 +1；每纪元上限 3 个 [软数据]。
- **回退动作**：消耗 1 个信标，回到当前危机的最早自动检查点。
- **回退保留清单**（兑现 Q3"保护教育价值"）：

| 项目 | 保留程度 | 理由 |
|---|---|---|
| 科技树解锁节点 | 100% | 知识不可被"遗忘"，且避免玩家重复刷科技 |
| 文明特质（韧性） | 100% | 与 M02 Prestige 一致：文明性格保留 |
| 历史教训条目 | 100% | 回退的核心教育价值："我的文明记得教训" |
| 因果链事件日志 | 100%（含失败） | 历史即内容；时间线保留失败记录 |
| 资源/人口/设施 | 回到快照值 | 时间倒流的代价落在"物质层" |
| 已消耗的信标 | 不返还 | 防止无限刷 |

- **回退演出**："历史透镜"倒带动画（M05 动效），失败画面保留约 1 秒定格后回退——给玩家"这一秒的刺痛"，维持紧张感。

#### 3.4.3 教育价值 vs 紧张感的权衡结构

1. **首次失败免费学**：每个危机首次失败后，Post-mortem 面板完整复盘因果链（哪些节点可以截断、截断代价是多少），然后**自动回退**（消耗信标，但信标额度在事件开始时确保 ≥1）。
2. **二次失败代价实化**：同一危机若回退后再次失败，不再自动回退；文明进入"余波状态"（按失败后果结算）并持续 10 模拟年，期间时间信标补发速度减半。
3. **紧张感来源不是"会死"，而是"代价"**：资源/人口会真损失，但科技与教训永存——这使"失败"成为**信息获取手段**而非终点（对标 FTL: Faster Than Light 的"每个失败都是学习"体验）。
4. **硬核模式（可选项）**：开局可选"孤注一掷"模式——信标数量减半、失败不回退。设计为教育版（M06）之外的难度选项，默认不开。

## 5) 风险与开放问题

### 5.1 内部风险

1. **因果链复杂度失控**：链条过长 → 玩家干预窗口拥挤 → 挫败。缓解：上限 6 节点/链；relay 节点默认只读（延迟窗口内不要求玩家每环都操作）。
2. **"未卜先知"作弊感**：玩家提前知道阈值 → 卡线规避。缓解：阈值有 ±20% 随机抖动（波动后仍标 [软数据]），且风险钟概率性保证"不可完全预知、只能预防性投资"。
3. **回退滥用导致文明"永生"**：信标额度 + 历史积分上限已在 3.4 约束；若仍失衡，可加"回退后同危机强度 +5%"的递减惩罚 [待裁决]。
4. **大过滤器事件的叙事定位争议**：作为"考试"可能突兀。缓解：定位为二周目相位解锁仪式，不纳入主线必过，可跳过只获彩蛋奖励。

### 5.2 需要用户裁决的冲突点（汇总，供主智能体标红）

1. **【冲突 A】失败后的终极状态**：信标耗尽且失败时，文明走"余波状态继续玩"（本模块倾向）还是"硬核重开"（部分玩家可能想要）？——直接决定 Q2 的答案形态。
2. **【冲突 B】时间倒流上限**：每纪元 3 个信标是否足够平衡"教育价值 vs 紧张感"？若用户更重紧张感，可减到每纪元 1 个 + 硬核模式默认开启。
3. **【冲突 C】大过滤器是否强制**：K≥0.95 是否必须触发？强制=保证二周目彩蛋可见；可选=保护"只看攀功率"的玩家。
4. **【冲突 D】阈值随机抖动**：±20% 抖动牺牲"确定性教学"（学生玩家想精确学阈值），换取"不可作弊"。教育版（M06）建议关闭抖动。需用户拍板默认值。

### 5.3 对 02 文档 Q1–Q8 的倾向性答案

| # | 问题 | 本模块倾向 | 依据 |
|---|---|---|---|
| Q1 | 时间尺度 | 支持 ~8000 模拟年；建议事件节奏参照此标尺（纪元 0–1 事件稀疏，体现"漫长农业时代"） | 与 M01/M02 节奏目标一致 |
| Q2 | 失败惩罚 | **分级失败**：前兆/轻度危机→小损失+教训；重大危机→有限次回退（信标）；信标耗尽→余波状态继续玩（文明衰减但不重开）；硬核模式可选 | 完全执行 P4；把"失败=内容"做成默认，而不是用"死亡"威胁 |
| Q3 | 时间倒流 | **允许，但有约束**：时间信标限次 + 物质层回退 + 知识层保留 + 失败记录留存。这是教育价值与紧张感的最佳平衡点 | 若彻底禁止回退则破坏"失败即内容"；若无限回退则紧张感归零；限次+代价+学习保留是折中 |
| Q4 | 2D 地图 | 要，且本模块需要它承载**因果链地理可视化**（资源流/灾难扩散面） | 因果链节点的"地点感"增强叙事冲击 |
