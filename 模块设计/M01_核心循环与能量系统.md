## 1. 目标与定位

### 1.1 设计目标

1. **让功率成为唯一可结算的物理量**：任何"增长"都必须回溯到某条能源链；违反"铁律：文明不能凭空造功率"的数字一律不出现在本模块。
2. **把 EROI 变成可玩的硬约束**：EROI 不是一条属性，而是贯穿每个状态的"隐形税务"——它决定建新设施是否划算、能源换代何时发生、文明何时因吃老本而崩塌。
3. **提供闭环的三大存量**：功率流（能量）、资源（物质）、人口（劳动力）三张表在每 tick 内完成闭环结算，不产生无来源数字。
4. **为 M02–M05 提供稳定接口**：本模块只结算"量"，纪元/科技/事件/离线只消费本模块暴露的状态量。

### 1.2 在整体架构中的位置

```
M00 总指标（K 映射、EROI 锚点、铁律）
   └─ M01 核心循环与能量系统  ◀── 本模块：全游戏结算引擎
        ├─ M02 纪元·科技·Prestige（消费：P、S、R）
        ├─ M03 轨道/殖民地手感层（消费：P、能量流、散热）
        ├─ M04 事件与文明风险（消费：S、库存、人口、燃料）
        └─ M05 增量留存·UX·百科（消费：全部，并回馈离线/自动）
```

### 1.3 成功标准（阶段 1 验收）

- [ ] 火种→T1 全程数值闭合：任何时刻 P 可逐源追溯，无凭空功率。
- [ ] 一张电子表格即可模拟"挂机 8 小时后 K 值变化"，数值不爆炸不归零。
- [ ] 每纪元有且仅有一组"当纪元瓶颈"（见 §5），且瓶颈切换可被玩家感知。

## 3. 关键机制与数值草案

> 数据标签约定（见 01 文档）：`[硬数据]` 有确定物理依据；`[软数据]` 量级合理可调；`[待核实]` 待科学顾问确认；`[设计自由]` 纯玩法决策。
> **所有标注 [软数据] 的数值以"量级对"为验收标准，精确到一位有效数字即可。**

### 3.1 核心循环状态机

#### 3.1.1 主循环总览

```
        ┌────────────────────────────────────────────────────────┐
        │                                                        ▼
   S1 开采 ──原生资源流──▶ S2 提炼 ──精炼资源──▶ S3 发电 ──有效功率 P──▶ S4 维持
        ▲                                                   │              │
        │                                                   ▼              ▼
        │                                              S5 盈余 S     人口/设施状态
        │                                                   │              │
        │                                                   ▼              │
        │                                              S6 科研 R ◀────────┘
        │                                                   │
        │                                                   ▼
        │                                              S7 解锁 ──▶ 新能源/新设施/纪元推进
        │                                                   │
        └──────────── S8 自动化（消耗功率+资本，扩大 S1–S3 规模）◀──┘
```

**铁律执行点**：`P_total = Σ 各设施净输出`，且每个设施必须能追溯到"它吃掉了哪种初级能源 × 转换效率"。禁止任何"能量凭空出现"型乘数（文明特质等永久乘数只能作用于 `净功率的再分配`，不能增加 `初级采集`）。

#### 3.1.2 八个状态的输入/输出/损耗定义

| 状态 | 输入 | 输出 | 环节损耗 | 主约束 |
|---|---|---|---|---|
| **S1 开采** | 探明储量、开采设施、驱动功率（畜力/燃料/电）、劳动力或自动化 | 原生资源流 `M_raw`（kg/s 或 t/s） | 开采损耗率 `l_extract`（煤约 1–5% [软数据]；开采成本随"品位下降"递增） | 储量枯竭曲线；可采速率上限 |
| **S2 提炼** | 原生资源流、功率（冶炼/精炼/化工厂） | 精炼资源流 `M_ref` | 质量损耗（矿石→金属，如铁矿石含铁 30–60% [硬数据]）；能量损耗（冶金 EROI 附加惩罚） | 冶金/化工工艺解锁进度 |
| **S3 发电** | 燃料/初级能源流、发电设施 | 有效功率 `P_el`（电或机械功） | 热机效率（受卡诺上限约束 [硬数据]）；输电损耗（电网，3–15% [软数据]） | 卡诺效率；间歇性；废热排出 |
| **S4 维持** | 食物（生物质功率）、运维功率 | 人口稳定 N、设施"在役"状态 | 人口食物消费（人均约 100 W 代谢 [软数据]）；设施运维（约 1–5% 额定功率/年 [软数据]） | 人口即负载；人口即劳动力 |
| **S5 盈余** | 有效功率 P、维持功率 | 盈余 S = P − 维持 | —（S<0 即开始吃库存/砍人口） | 无盈余则无增长（见 3.1.3 流转规则 B） |
| **S6 科研** | 盈余功率（配额）、科研设施、素养人口 | 科研点速率 `dR/dt` | 科研消耗功率一去不回（科研是"熵增投资"，不返还功率） | 盈余为负 → 科研停摆 |
| **S7 解锁** | 累积科研点 R、当前纪元 | 新技术/新设施/新能源解锁；纪元推进触发（功率门槛，见 M00 §2） | 解锁即消耗 R（科技树由 M02 定义） | 纪元门槛=功率门槛 |
| **S8 自动化** | 功率、资本（盈余积蓄）、科研 | 设施从"手动"转"自动" | 自动化增加设施功耗（约 +10–30% 额定功耗 [软数据]），换取消劳动力占用 | 劳动力上限即瓶颈（见 §5） |

#### 3.1.3 流转规则（状态机转移条件）

- **规则 A（正向主循环）**：每 tick 依序结算 S1→S2→S3→S4→S5→S6→S7→S8，全部为瞬时/准稳态结算；玩家仅干预"投资去向"（建哪个设施、开哪条科研、何时自动化），不干预结算本身。
- **规则 B（亏损回退）**：当 `S < 0`：
  1. 优先级 1：调用储能/库存放电（燃料库存、电池、粮仓）。
  2. 优先级 2：科研配额先清零（S6 停摆）。
  3. 优先级 3：设施按"逆向能量密度排序"下线（先停高耗低效者，后停维持必需者）。
  4. 优先级 4：人口衰减（见 §3.3 人口公式），触发 M04 崩塌事件。
  - 一旦 `S ≥ 0` 恢复，按相反顺序逐级恢复（不免费复原，恢复有重启成本）。
- **规则 C（枯竭切换）**：当某燃料储量耗竭或 EROI 跌破 1.5，其对应设施自动"降级"：优先切换至同代次备用能源（薪柴→炭→煤→油→气→聚变），无备用则触发规则 B。切换需 1 个结算 tick 的"停机检修"损失（停机损失 = 该设施额定功率 × 停机时长 [软数据]）。
- **规则 D（自动化替代）**：设施被自动化后，其劳动力占用归零，改为额外功耗；该操作不可逆（防止来回刷劳动力）。
- **规则 E（纪元切换）**：当 `P_total ≥ 下纪元功率门槛`（M00 §2 的 10 倍阶梯）且维持 `t_hold`（见 M02）后，触发 Prestige 结算（保留文明特质，重置资源/人口/科技，见 M02）。

#### 3.1.4 单 tick 结算顺序（可执行的伪代码）

```
for each tick:
    # 1. 产能侧
    M_raw  = Σ 开采设施(储量, 驱动, 自动化) × (1 − l_extract)
    M_ref  = Σ 提炼设施(M_raw, 功率) × 质量保持率
    P_el   = Σ 发电设施(M_ref 或 间歇源, 效率η, 储能平滑) − 输电损耗
    # 2. 负载侧
    P_maint = 人口食物(Pop) + 设施运维 + 散热开销
    S      = P_el − P_maint
    # 3. 分配
    if S > 0: 按玩家配额分配 → 科研 dR/dt、投资资本、储能、人口增长
    else:     按规则 B 回退
    # 4. 状态推进
    R += dR/dt; 解锁检查; 自动化检查; 枯竭检查; 纪元检查
```

#### 3.2.1 统一量化惩罚公式（三类惩罚）

- **枯竭惩罚**（不可再生源）：单井/矿区产量 `Q(t) = Q₀ / (1 + t/τ)^0.5`（对数衰减近似 [软数据]）；储量耗尽 → 规则 C 降级。可再生能源（薪柴/水电/风/光）无储量耗尽，但有**可采集速率上限**（受土地/站点/面积约束）。
- **间歇惩罚**：间歇源实际输出 `P_eff = P_rated × CF × η_storage`，其中 `CF`（容量因子）随能源而异 [软数据]：光伏 0.18–0.25（地表）/0.35–0.45（空间）、风电 0.3–0.5、水车枯水 0.5、风帆 0.25–0.45。`η_storage` 为储能往返效率：抽水蓄能 0.75–0.8、锂电 0.85–0.92 [软数据]。
- **废热惩罚**（热力学，[硬数据] 原则）：有效输出 `P_useful = E_primary × η_carnot`，其中 `η_carnot ≤ 1 − T_cold/T_hot`。**冷却子系统**：废热 `Q_waste = E_primary × (1−η)` 必须排出，散热速率上限 `Q_max = A_radiator × σ×T⁴`（斯特藩-玻尔兹曼 [硬数据]）。当 `Q_waste > Q_max` → 设施过热，效率惩罚 / 过热事件（M04）。**这一条是 K0.8+ 的核心硬瓶颈**（见 §5），也是戴森云"以面积换散热"的铺垫。

#### 3.2.2 储能系统（四种 + 需求公式）

储能需求公式：
```
B_required = (Σ P_intermittent × 无源时长) / η_storage
```
- **蓄水池/水坝**（K0.2+，抽水蓄能 K0.6）：0.75–0.8 往返效率。
- **热储能**（熔盐，K0.7）：光伏配套，0.6–0.7。
- **电池**（K0.7 起，锂电；K0.9 起固态/超导）：0.85–0.95。
- **轨道蓄电池/飞轮**（K0.8+）：空间站缓冲，0.9+。

> 设计含义：间歇源占比超过 ~30% 时，储能成本开始吃掉盈余（`储能 EROI 惩罚` 在 §3.2 各源中已标注），逼玩家保持"基荷+调峰"混合结构——这是真实的电力系统思维，也是教学点。

#### 3.2.3 戴森云的玩法化（T1 段）

- 戴森云 = 逐环入轨的太阳能收集单元，总遮挡 `Σ A / 4πR_orbit²` 逼近上限；**当遮挡达到 100%×（恒星辐照份额）即 T1 通关**（00 文档口径 10¹⁶ W）。
- 触发"散热悖论"：收集的功率越多，本体废热越大，云层必须以更大收集面积+散热片覆盖——这个"面积竞赛"就是末段的核心决策（散热 vs 收集 vs 轨道物流），[设计自由]。
- 现实佐证：太阳总辐照 ~3.8×10²⁶ W（太阳光度 [硬数据]）；收集 10¹⁶ W 仅占 2.6×10⁻¹¹ 的恒星输出——因此 T1 只需"极小片"云，符合"文明能量总量=戴森基础设施规模"的设定。

### 3.3 结算公式草案（伪公式）

**符号**：`P`=功率(W)、`S`=盈余、`N`=人口、`L`=劳动力、`R`=科研点、`K`=卡尔达肖夫指数。

1. **文明总功率**（主指标，M00 定义）
   ```
   P_total = Σ_i P_eff_i          # 各能源净输出之和（已含 EROI/间歇/储能惩罚）
   K = (log₁₀(P_total) − 6) / 10  # [硬数据] 萨根公式
   ```

2. **单源净输出**
   ```
   P_eff = M_primary × E_density × η_conv × CF × η_storage × (1 − 输电损耗)
   ```

3. **盈余**
   ```
   S = P_total − P_maintain
   P_maintain = N × e_food_per_capita(≈100 W [软数据]) + Σ 设施运维(≈2–5% 额定) + 散热开销
   ```

4. **科研点**
   ```
   dR/dt = α × S_r × (1 + 素养系数) × 范式乘数
   其中 S_r = 玩家分配给科研的盈余功率，α = 科研转化率(≈1e−3 点/W·tick [软数据])
   范式乘数：由 M02 科技树（书写→印刷→教育→AI 辅助）叠加，上限设防爆炸
   ```
   约束：`S ≤ 0 → dR/dt = 0`（科研停摆，00 文档规则）。

5. **人口增长**（逻辑斯蒂 + 能量门控）
   ```
   dN/dt = N × r₀ × (1 − N/N_carry) × gate_food
   gate_food = 食物盈余/(食物盈余+食物需求) ∈ [0,1]     # 无余粮则不增长
   N_carry = f(土地/生态容量, 农业科技)                   # 马尔萨斯上限
   ```
   人口死亡：`gate_food < 0.5` 时反向衰减 + M04 饥荒事件。

6. **劳动力**
   ```
   L = N × 劳动参与率 × (1 − 素养教育占比)
   L_available = L − 已被占用劳动力(设施/农作)   # 本模块的"劳动力上限"即由此出
   ```

7. **自动化成本**
   ```
   C_auto = c₀ × P_facility^0.8 × (1 + n_auto)^0.5   # 边际成本上升，防单点爆炸
   自动化后：设施劳动力占用=0，额定功耗 ×(1 + 0.1~0.3)
   ```

8. **资本（建造投资）**
   ```
   建造任何设施：一次性投资 E_build = P_rated × T_payback（§3.2 各源资本门槛列）
   投资来源 = 累积盈余（无盈余则无法扩张）→ 实现"零资本=零增长"
   ```

9. **资源枯竭**
   ```
   不可再生储量 R_res(t) = R₀ − ∫Q dt；Q(t) = Q₀/(1+t/τ)^0.5（[软数据]）
   ```

### 3.4 资源分类与生产链

**五层资源**（抽象为 5 条生产链，每层 3–4 个资源节点）：

| 层 | 资源节点（→转化→） | 用途 | 主要损耗 |
|---|---|---|---|
| L0 生物质 | 野生采集 → 农田 → 林场 | 人口食物、薪柴、畜力饲料 | 与人口增长直接冲突 |
| L1 矿物 | 石/砂/陶土 → 砖/水泥 | 基建（道路、设施外壳） | 质量比低（矿石→建材） |
| L2 金属 | 铜→青铜；铁→生铁→钢→工业合金 | 工具、机械、电网、航天结构 | 冶金耗能占工业功率 ~15–25% [软数据] |
| L3 能源载体 | 木炭→煤→焦炭；石油→汽油/航空煤油；铀→浓缩铀；氘→氚 | 燃料/驱动/发电 | 精炼损耗 5–20% [软数据] |
| L4 高级材料 | 硅→晶圆→芯片；碳纤维→超导→纳米/轨道材料 | 光伏、电子、轨道设施 | 高纯工艺极耗能（P2 透明简化：注明"高纯材料=隐形功率税"） |

**示例生产链（金属层，教科书级简化）**：
```
铁矿(60% Fe) ──高炉(焦炭)──▶ 生铁 ──转炉──▶ 钢 ──合金化──▶ 工业合金(航天级)
    每步能量：生铁 ≈ 6–10 GJ/t [软数据]；钢 ≈ 20–30 GJ/t [软数据]
```
**设计含义**：每层链的"中间产物"都是可观测资源流（2D 地图可视化节点，呼应 Q4）。玩家优化的是"每层损耗"——用科技（更好的冶炼/回收）降低损耗，等价于间接提高有效 EROI。

### 3.5 瓶颈与缩放（随 K 迁移）

> 定义：**当纪元瓶颈** = 当前限制 `dP/dt` 最紧的单项约束。瓶颈必须每纪元可感知、可突破（突破即"里程碑时刻"，00 文档节奏目标）。

| K 区间 | 纪元 | 主瓶颈 | 瓶颈性质 | 突破手段 |
|---|---|---|---|---|
| K0.0–0.2 | 火种/农耕 | **土地+劳动力** | 薪柴产量受森林再生上限；人均产出低 | 农具金属化、畜力、灌溉 |
| K0.2–0.4 | 青铜/前工业 | **燃料(木炭)+运输** | 木炭成本随森林消耗上升；畜力运输半径短 | 煤炭革命（跨过 K0.4 门槛） |
| K0.4–0.6 | 早期工业/电气化 | **燃料(煤/油)+资金** | 枯竭曲线与峰值危机；设施资本回收期长 | 石油化工、电网规模化 |
| K0.6–0.7 | 原子能 | **燃料+资本+散热(初)** | 化石渐衰、裂变基建重；城市热岛事件 | 天然气快调峰+水电基荷 |
| K0.7–0.8 | 近未来 | **储能+电网** | 间歇源占比高，储能成本吃盈余 | 大电网互联、储能技术、轨道太阳能 |
| K0.8–0.9 | 聚变/轨道 | **散热+轨道物流** | 聚变废热、轨道基建发射成本 | 聚变工程、轨道工厂、拉格朗日枢纽 |
| K0.9–1.0 | 行星际 | **散热+面积** | 散热上限=面积上限（斯特藩-玻尔兹曼），单位面积功率逼近物理极限 | 戴森云以更大收集面积换功率（面积竞赛） |

**缩放关系**：
```
dP/dt ∝ (盈余 S) × (资本投向效率) / (纪元瓶颈阻力)
瓶颈阻力 = max(土地约束, 燃料约束, 散热约束, 资金约束) × 缩放因子
```
- K<0.4：瓶颈在**供给侧**（燃料/土地），P 呈"斜率递减"增长。
- K0.4–0.7：瓶颈在**资本侧**，P 呈"阶梯增长"（每纪元一次大扩张+一次瓶颈）。
- K>0.7：瓶颈在**散热侧**，P 增长受面积约束 → 向空间/戴森云迁移的动机自然涌现。

## 4. 与相邻模块的接口

### 4.1 提供给 M02（纪元·科技·Prestige）
- **状态量**：`P_total`、`K`、`S`、`R`（科研点存量）、`N`、`L_available`、当前纪元。
- **调用点**：纪元门槛检查（`P_total ≥ 门槛 × 维持时长`）；科研消耗（`R` 支付解锁）；Prestige 结算读取文明特质（不产生功率，只做再分配）。
- **契约**：任何科技/特质乘数**只能**作用于 `η_conv / CF / 损耗 / 劳动力` 等"分配型"系数，不能直接加 `P_total`。

### 4.2 提供给 M03（轨道·殖民地手感层）
- **能量流接口**：轨道设施功率输入、微波传输损耗、空间散热 `Q_max`。
- **回流**：M03 的轨道基建成功 → 更新 M01 的"轨道能源可用性"（拉格朗日/轨道太阳能解锁条件），M03 失败 → 对应设施缺功率（走规则 B）。

### 4.3 提供给 M04（事件与文明风险）
- **事件触发器**：`S < 0` 连续 tick 数、燃料库存 < 阈值、`Q_waste > Q_max`、人口衰减率、资源枯竭接近 0。
- **事件回写**：事件奖励/惩罚表现为——追加/移除设施、修正常数（效率、储量）、临时危机状态（本模块只消费回写，不定义事件内容）。

### 4.4 提供给 M05（留存·UX·百科）
- **离线收益**：缓存 `{P_total, S, R, N, 储量, 设施列表, 分配配额}` 快照，离线结算由 M05 定义规则（见 Q5 倾向）。
- **UI 数据**：主刻度尺直接消费 `P_total`；资源流可视化消费 §3.4 五层链的节点速率。
- **科学卡片**：§3.2/§3.3 所有 `[硬数据]` 项可直接映射为百科条目（如萨根公式、斯特藩-玻尔兹曼、能量密度表）。

## 5. 风险与开放问题

### 5.1 本模块特有的风险

| 风险 | 描述 | 缓解 |
|---|---|---|
| **数值爆炸**（后期功率指数级失控） | 戴森云若与科研/特质乘数叠加可能指数爆表 | 铁律：乘数只作用于分配型系数；散热面积上限天然设顶 |
| **早期死锁**（火种段饿死） | 人口增长与食物增长耦合可能震荡崩溃 | `gate_food` 平滑；粮仓缓冲；P4"失败即内容"（回退检查点） |
| **EROI 软数据不实** | 学界对光伏/风电 EROI 争议大（制造边界取法） | 统一"含制造"口径，全部标 [软数据]，科学顾问复核（见 §6） |
| **自动化反直觉** | 玩家可能因自动化功耗高而拒用 | 教学关卡展示"劳动力上限"瓶颈时才引导自动化 |
| **散热机制过重** | 斯特藩-玻尔兹曼对休闲玩家过于硬核 | P3 分层真实：手感层才细化散热，战略层只暴露"散热上限"一维 |

### 5.2 开放问题（本模块视角）

1. 资本用"能量投资"计价（本稿方案）还是独立"货币/资金"体系？影响 §3.3 公式 8 与 M02 经济设计。
2. 人口应否作为"可感知资源"直接管理，还是完全抽象为"劳动力-食物"两个派生量？（倾向后者，见 Q 部分）
3. 薪柴/生物质的 EROI 2–15（00 文档）与本稿 5–15 的取舍（本稿取可再生"边际回报"口径）。
4. 畜力 EROI 4–10 是否偏低（会削弱农耕纪元强度）？建议 6–12，留待平衡阶段定夺。
