# M03 物理手感层：轨道力学 + 殖民地热力学（KSP-lite × ONI-lite）v0.1

> 角色：物理玩法设计师（子智能体 C）
> 依赖：M01（功率结算）、M02（纪元/科技树解锁时序）、M04（事件联动）、M05（科学卡片/UI 规范）
> 依据：《00_总指标与设计锚点》《01_设计规范与计划》《02_讨论范畴与开放问题》
> 数据标签：`[硬数据]` 确定物理依据 ／ `[软数据]` 量级合理可调 ／ `[设计自由]` 纯玩法决策 ／ `[待核实]` 需外部权威来源确认

## 1. 目标与定位

### 1.1 三目标（优先级排序）

1. **操作手感**：提供"轻物理"的即时操作闭环——拖动、预览、确认、看结果。手感层是增量游戏的"手动操作高峰"来源（对照 00 文档第 6 节：中段 K0.4–0.7 手动高峰、末段 K>0.7 以轨道与殖民决策为主）。
2. **科学教学**：玩家通过"亲手做错→看懂为什么→下次做对"学会两类真物理：轨道力学与热力学。这是游戏教育价值的主载体。
3. **产出结算**：手感层的每次成功操作折算为战略层的净功率与材料（见第 4 节接口），回填主循环 `开采→…→发电`，但不参与战略层的逐帧结算。

### 1.2 定位原则（呼应 P3 分层真实）

- 战略层（M01）只收"汇总数字"：净功率 P、材料清单、人口。M03 内部自己结算，不把物理逐格状态泄露到战略层。
- M03 只深度模拟**两个**物理系统：二体/简化三体轨道力学 + 格子热力学。其余（化学工业、流体机械、结构力学、生态细节）一律抽象为倍率或成本——**这是 P3 的硬边界，超出即越界**。
- 表现层（M07 阶段 2）负责艺术化：拟人空气分子、温度渐变色、爆炸粒子。M03 只定义"物理正确的内容"，不定义渲染。

### 1.3 解锁节奏（与 M02 的接口草案）

| 阶段 K | 轨道层活动 | 殖民地层活动 |
|---|---|---|
| K0–0.5 | 不出场（仅科普卡片预热） | 不出场（科普卡片预热：冶炼即"小型热系统"） |
| K0.5–0.6 | **第一颗人造卫星**：模板档教学（固定轨道，一键发射） | 第一座**密封前哨**教学（热管理入门） |
| K0.6–0.7 | 同步轨道 / 通信星座 / 载人站（手动节点出现） | 月球前哨：气液循环 + 生命维持教学 |
| K0.7–0.8 | 极地/太阳同步、行星际转移窗口、离子推进 | 火星基地：CO₂→O₂ 生态循环、相变利用 |
| K0.8–0.9 | **轨道太阳能工业**（核心收益期）、太阳帆、拉格朗日 L1/L2 | 轨道/月球工业：零重力制造，拉格朗日工厂 |
| K0.9–1.0 | L4/L5 驻留工业群、戴森云首环、引力弹弓深空航线 | 殖民地全自动化，只留危机手动 |

> 设计意图：**教学在前、收益在后**。K0.5–0.7 用手感层当"物理课"，K0.8 之后用手感层当"功率金矿"，避免轨道玩法一上来就值钱而教学被跳过。

## 2. 范围与边界

### 2.1 范畴内（本轮要设计）

**轨道层**
- 发射窗口 / 会合周期、霍曼转移、引力弹弓、拉格朗日点（L1/L2/L4/L5）、同步轨道、极地/太阳同步轨道、星座部署、太阳帆与离子推进的"可玩化规则"。
- 轨道决策对战略层功率的影响：日照因子、日凌中断、传输损耗、站保成本。
- 自动/手动切换体系与"首飞强制手动"教学闸门。

**殖民地层**
- 2D 网格建造；PV=nRT 的**既定简化程度**（见 3.2.2）；热传导与热辐射的查表近似；冰/水/汽相变；O₂/CO₂/温度生命维持三要素；密封失效（泄压、气闸、抢修）。
- 卡通化包装下的科学正确性规则（P2 透明简化）。

**失败即教学**
- 通用 5 阶段教学事故模板 + 轨道/热力学各一套事故序列设计。

**接口**
- 与 M01/M02/M04/M05 的折算规则与数据契约。

### 2.2 范畴外（明确不做，防越界）

| 不做 | 原因/替代 |
|---|---|
| n 体数值积分（只做二体 + 拉格朗日点静态模型） | 性能与上手门槛 |
| 3D 自由视角轨道编辑器（用 2D 轨道平面 + 一个"倾角滑条"） | UI 复杂度上限（见 3.5） |
| 逐秒燃料质量闭环（Δv 直接折算为推进剂消耗量） | 战略层只看"Δv 预算" |
| 真实三体摄动、轨道长期衰减精度 | 量级正确即可 |
| 殖民地全球铺格子（单基地 ≤ 24×24 格，超出自动扩建新基地） | 防止"第二个游戏" |
| 气体扩散/对流 CFD（用"连通域均压 + 时间常数"） | 教学所需精度足够 |
| 湿度、气压病的精确模拟 | 只做 O₂/CO₂/T 三要素 |
| 相对论、太阳系尺度之外的轨道 | 范围外 |

## 3. 关键机制与数值草案

### 3.1 轨道层（KSP-lite）

#### 3.1.1 三档操控抽象（回应 Q6 的核心答案）

| 档位 | 操作形式 | 失败风险 | 教学价值 | 适用 |
|---|---|---|---|---|
| **模板档 T1** | 从预设列表选"同步轨道/太阳同步/拉格朗日 L2"一键部署，固定标价 | 低（只受材料与 Δv 预算约束） | 极低 | 批量部署、挂机自动化、玩家熟悉后的一切 |
| **手动档 T2** | 2D 轨道平面上拖拽远/近点、调 Δv 滑条，实时预览转移轨道（KSP 节点类比） | 高（预览已标红/黄/绿） | 最高 | 首次部署、关键转移、危机救援 |
| **自动档 T3** | 设目标轨道+约束，系统自动算出最优窗口与最优转移并执行 | 中（只受约束设定错误影响） | 无（学习已结束） | 深度自动化、离线挂机 |

- **切换规则**：某类轨道"首飞强制手动"（必须手动档通过一次），成功后才解锁该类轨道的模板档与自动档。这是"教学闸门"，防玩家用模板跳过学习。
- **危机模式**：日凌/耀斑/卫星失效期间自动档强制降级为手动档（"自动失效，必须人上"）——把"手动关键时刻"做成规则而非选项。
- **中途接管**：自动执行中可随时点"接管"，进入手动档当前状态。

#### 3.1.2 数值核心：Δv 预算与转移参照表

- 推进资源以 **Δv 预算** 计（km/s），由战略层"推进剂材料"折算（`[设计自由]` 比例待 M01 定）；**不做燃料质量逐帧积分**，把火箭方程对数项预计算成换算表（P2 透明标注"此处已把对数映射为线性表"）。
- 火箭方程 δv = Isp·g₀·ln(m₀/m₁) `[硬数据]`，游戏中仅用于科学卡片展示，结算用查表。

**设计用 Δv 参照表**（单位 km/s，量级合理，`[待核实]` 详见第 6 节）：

| 任务段 | Δv | 备注 |
|---|---|---|
| 地面→LEO（含重力/气动损耗） | ≈9.3–9.8 | 视运载设计 `[软数据]` |
| LEO→GEO（霍曼两段） | ≈3.9（2.46+1.48） | 两段霍曼 `[硬数据]` |
| LEO→月球轨道 | ≈3.9–4.1 | `[硬数据]` |
| LEO→日地 L1/L2 | ≈3.2–3.5 | `[软数据]` |
| LEO→逃逸 | ≈3.2（=0.414×LEO 速度） | `[硬数据]` |
| 火星转移（对地相对） | ≈2.9–4.3（依窗口） | `[软数据]` |

**霍曼转移公式**（科学卡片内容）`[硬数据]`：转移轨道半长轴 a=(r₁+r₂)/2；转移时间 t=π·√(a³/μ)；两段脉冲 Δv 按 a 与 r₁、r₂ 的相对关系计算。游戏中玩家不输入公式，只拖拽预览。

#### 3.1.3 发射窗口（会合周期）

- 游戏化规则：跨天体任务有"窗口日历" UI——时间轴上绿色块标注可发射窗口，玩家**不自己算**会合周期（物理细节进科学卡片）。
- 窗口间隔 = 会合周期 1/|1/T₁−1/T₂|（开普勒第三定律）`[硬数据]`。设计表（`[软数据]`）：
  - 地球→火星 ≈ 26 个月；地球→金星 ≈ 19 个月；地球→水星 ≈ 3.9 个月。
- 错过窗口 = 等待下一窗口；**教学点**：第一次深空任务必然有人在窗口外发射（见 3.3 教学序列 T-2）。
- 同步轨道 / LEO 任务**几乎每天有窗口**，不施加会合惩罚——把窗口机制集中在行星际，保持手感聚焦。

#### 3.1.4 轨道类型 × 战略产出表（"轨道决策如何影响功率"核心表）

轨道层每单位太阳能阵列额定 1 MW `[设计自由]`；实际功率 = 额定 × 日照因子 × 传输效率 × EROI 因子（光伏 EROI 3–12 含制造与发射，`[软数据]` 沿用 00 文档）。

| 轨道/位置 | 解锁 K | 日照因子 | 传输效率 | 战略作用 | 成本/维护 | 教学点 |
|---|---|---|---|---|---|---|
| LEO 近地轨道 | 0.6 | ≈0.6–0.7（90 分钟周期，地影占 30–40%）`[软数据]` | 0.9 | 遥感/科研点/小功率 | 低，寿命 5–10 年 | 地影=间歇性 |
| GEO 同步轨道 | 0.7 | ≈0.9–0.99（仅春秋分季节有地影）`[软数据]` | 0.95 | **通信骨干**、固定星下点聚光 | 中，站保少 | 日凌中断（见 3.1.7） |
| SSO 极地太阳同步（晨昏轨道） | 0.7 | ≈0.95–1.0（晨昏面近乎连续日照）`[软数据]` | 0.9 | **光伏金矿**、全球覆盖 | 中 | 进动机制 |
| 极地轨道（非太阳同步） | 0.6 | ≈0.5–0.7 | 0.9 | 极区覆盖 | 低 | 极轨≠永久日照（纠正直觉） |
| 日地 L1 | 0.8 | **1.0 连续日照** | 0.9 | **太阳能中继/永久发电** | 高（不稳点，需站保 3–20 m/s/年 `[待核实]`） | 不稳平衡=站保 |
| 日地 L2 | 0.8 | 1.0 | 0.85 | 遮蔽望远镜、背面设施 | 高 | 遮蔽=优点 |
| L4/L5 | 0.9 | 1.0 | 0.8 | **驻留工业群**、天然稳定 | 中（稳定点省站保） | 三角平动点=稳定 |
| 月球表面 | 0.6 | ≈0.5（14 天昼/14 天夜 `[硬数据]`） | 0.7 | 水冰/氦-3、材料精炼 | 高（月夜需储能） | 月夜=大电池 |
| 火星表面 | 0.7 | ≈0.6（沙尘季衰减 `[软数据]`） | 0.7 | 殖民地、CO₂ 资源 | 高 | 沙尘=光伏杀手 |

**设计含义**：极地/太阳同步与 L1 的"永久日照"是**最贵的轨道**（Δv 大、站保高），逼迫玩家在"便宜够用（LEO/GEO）"与"贵而满产（SSO/L1）"间做战略取舍——轨道决策因此有意义，而不是"越贵越好"。

#### 3.1.5 引力弹弓

- 简化定位：**只在行星际转移路径中出现**（K0.9+ 解锁），不是常备操作。
- 游戏化规则：转移预览路径上出现"弹弓候选"标记（金星/木星/土星），选择加入则：
  - Δv 需求 −30%～−50%（`[设计自由]` 档位）；航程 +6～+18 个月（`[软数据]`）；
  - 每次弹弓含一次"精度校准"小操作（滑条对准逃逸角，成功/失控二分，`[设计自由]`）。
- 失败模式（教学点）：精度偏 → 探测器被弹入太阳 / 甩出系统 / 撞入行星大气。这是 KSP 最经典的"弹弓事故"。
- 若弹弓系统超出 MVP 预算，可退化为"预计算折扣 + 事件"，见第 5 节 R3。

#### 3.1.6 推进类型三角

| 推进 | 比冲 | 推力 | 游戏化规则 | 教学点 |
|---|---|---|---|---|
| 化学推进 | 250–450 s `[硬数据]` | 高 | 发射/快速转移标配；Δv 贵 | 高推力≠高效 |
| 离子推进 | 3000–10000 s `[硬数据]`（Dawn/BepiColombo 量级） | 极低 | Δv 省 60–80%，但转移时间 ×3–10 | 慢而省的权衡 |
| 太阳帆 | 免费（光压） | 极低 | 零推进剂 Δv，但只沿背离/面向太阳方向；距离远光压按 1/r² 衰减 `[硬数据]` | 平方反比定律 |

- 光压参照：1 AU 处阳光光压 ≈ 4.6 μPa（全吸收）/ ≈9.2 μPa（理想反射）`[硬数据]`；著名工程：IKAROS（2010）、LightSail-2（2019）。
- 设计作用：推进类型 = 玩家的"时间/成本/风险"三向滑块。离子+太阳帆让"便宜的深空"成为可能但拖慢节奏，化学推进贵但快——与战略层"快进节奏"对接。

#### 3.1.7 日凌（Sun Outage）与通信中断

- 科学依据：同步轨道卫星在春分/秋分前后各约 10 天、每天数分钟至十余分钟，太阳、卫星、地面站近似共线，下行信号受太阳噪声淹没 `[软数据]`。
- 游戏化：**日凌 = 有预警的短时掉功率事件**（5–15 分钟模拟时间），且自动档在此窗口强制手动降级。提供"跳过日凌"科技（轨道重构/多星冗余）作为后期升级。
- 教学点：太阳不是无声背景——这是把天文事件做成手感事件的最便宜方式（与 M04 事件系统接口，见第 4 节）。

#### 3.1.8 星座部署

- 规则：星座 = N 星集群（如 6/12/60 星档位 `[设计自由]`），提供：覆盖率（区域→全球）、冗余（单星失效不掉功率）、激光中继链路。
- 成本：随 N 非线性上升（每星需发射 + 维护）；收益：覆盖率与可靠性上升。玩家权衡"密星座 vs 稀疏星座 + 备份点"。
- 失败模式：单星失效→局部掉功率（战术小危机）；大规模失效（太阳耀斑/碎片）→ 整体事故（教学：冗余与备份）。

### 3.2 殖民地层（ONI-lite）

#### 3.2.1 布局与定位

- 2D 网格，单基地 12×12～24×24 格；格间为可建造舱室/管道/气闸。**不全球铺格子**，超出自动扩建新基地（基地→战略层一个节点）。
- 核心循环：建造舱室 → 充气/加热 → 人口入驻 → 产出功率/材料 → 维护（补氧、控温、补漏）。
- 前置校验：舱室必须是**密封闭合回路**才能保压（游戏自动判定，但玩家会因"漏了一条缝"而学会密封概念）。

#### 3.2.2 PV=nRT 简化到何种程度（教学精度线）

**保留（简化但真实）**：
- 理想气体状态方程 P·V = n·R·T `[硬数据]`；每**连通域**（互相连通的舱室集合）一个气压值，域内均匀混合——**砍掉扩散与对流模拟**。
- 压力差驱动的跨域交换：开口/阀门流量 Q ∝ 开度 × ΔP（简化为线性+时间常数平滑，`[设计自由]`）；气闸 = 两级阀门防失压。
- 气体种类：只模拟 O₂、CO₂、N₂、H₂O 四种（简化混合用"平均摩尔质量"）。

**明确砍掉（透明标注在百科）**：
- 非理想气体修正（范德华项）→ 百科卡片注明"此处用理想气体，误差 <1% 在常温常压"。
- 湿度/露点、气压病、部分压精确生理学。
- 扩散系数模拟 → 用连通域均压近似。

**数值草案**：标准大气压 101.325 kPa `[硬数据]`；宜居舱气压 80–110 kPa 视为舒适带 `[软数据]`。

#### 3.2.3 热传导与热辐射

- 热传导：傅里叶定律 q=−k∇T `[硬数据]`；游戏化为**逐格/逐面热阻 R**，格温差驱动热流 Q=ΔT/R，用时间常数平滑。材料热导率表（W/(m·K)，`[硬数据]` 标准工程数据）：

| 材料 | 热导率 | 游戏定位 |
|---|---|---|
| 铜 | ≈385–400 | 导热王（散热器/热管） |
| 铝 | ≈205 | 结构兼导热 |
| 钢 | ≈45–50 | 默认舱壁 |
| 玻璃 | ≈0.8–1.1 | 透明采光+保温折中 |
| 岩棉/气凝胶 | ≈0.03–0.05 | 保温层 |
| 真空 | 传导≈0，仅辐射 | **"真空=隔热层"教学点** |

- 热辐射：斯忒藩-玻尔兹曼 Q=εσA(T⁴−T_env⁴)，σ=5.67×10⁻⁸ W/(m²·K⁴) `[硬数据]`；游戏用**查表近似**，玩家不面对四次方。
- 关键教学点：**真空中没有对流，散热只能靠辐射**——把热水管丢进"真空绝热层"结果过热，因为真空既隔热也隔散热。这是 ONI 玩家最重要的"反直觉"课。
- 环境温度参照：月球表面 −173℃～+127℃、火星平均 ≈ −63℃（昼夜 −87℃～+20℃）`[硬数据]` 量级。

#### 3.2.4 相变（冰→水→汽）

**数据（`[硬数据]` 标准值）**：
- 冰熔化潜热 333.55 kJ/kg；水汽化潜热 2256–2260 kJ/kg；
- 比热容：冰 2.09、水 4.18、水汽 ≈1.99 kJ/(kg·K)；冰熔点 0℃、水沸点 100℃（1 atm）。

**游戏化规则**：
- 相变需要**海量能量**（潜热 ≫ 显热，教学点："1 kg 水烧开所需的能量≈把 0℃ 的水升到 80℃ 的 6.7 倍量级"）。
- 相变进行时温度**钉在相变点**直到潜热吸收完毕（教学点：沸腾温度恒定，不是一直升温）。
- 蒸干/结冰是两种典型事故（教学序列见 3.3）。
- CO₂ 升华（−78.5℃）可选做高阶素材（火星 CO₂ 冰），氧液化（−183℃）作为推进剂制造——都做"数值对、UI 简化"。

#### 3.2.5 生命维持

- 三要素（宜居度 = 0–100% 标量）：O₂ 分压、CO₂ 分压、温度舒适带 15–30℃ `[软数据]`。
- 循环：呼吸耗氧产 CO₂；光合室（藻类/植物）CO₂→O₂；温控由加热器/散热器/热泵完成。
- 数值草案（`[软数据]` 生理量级）：人均耗氧 ≈0.5–1.0 kg/天；CO₂ 呼出 ≈0.8–1.0 kg/天；人体产热 ≈100 W（静息）～300 W（活动）。
- 设计含义：人口是殖民地"负载"，生命维持功率随人口线性涨——与战略层人口/食物机制（M01）接口。

#### 3.2.6 密封失效

- 泄压规则：舱壁破损 → 泄漏速率与破口面积 × 内外压差成正比（简化 Q∝A·ΔP，`[设计自由]`）；游戏给出"剩余保压时间"读数。
- 事故来源：陨石/微碎片（随机+有预警）、热应力裂纹（玩家把冷热剧烈拼接）、操作失误（开错阀门）。
- 应对玩法：气闸隔离、抢修补丁、自动关阀/冗余舱段。气闸 = 两级阀门设计，是"密封教学"的最小教具。

#### 3.2.7 卡通化包装如何保留科学正确（P2 透明简化细则）

- 表现层拟人化：O₂ 画成绿色泡泡、CO₂ 画成灰色团、温度用蓝→红渐变色、压力用"舱壁鼓起程度"。**数值层不变**。
- 每个卡通物都有"真实化按钮"：长按任意泡泡/管子 → 弹出真实公式与简化说明卡片（"这里是 PV=nRT，游戏里我们用连通域均压近似"）。
- 规则：**卡通改变表现，不改变结算**。任何美术符号必须能追溯到一条真实物理量。

### 3.3 失败即教学（KSP 教学法落地）

#### 3.3.1 通用 5 阶段事故模板

1. **情境**：玩家做第一次 X（首次转移/首次加热/首次充气）。
2. **事故**：带戏剧性的失败（轨道上燃料耗尽的静默漂移、殖民地热爆炸、破舱呼啸声），**不立即结算惩罚**（P4 失败即内容）。
3. **物理侦探回放**：3 秒慢动作回放 + 高亮"错在哪一步"，附一句话物理诊断（"此时地球与火星相位差 140°，还差 40° 才能进入转移窗口"）。
4. **科学卡片 + 防再犯工具解锁**：弹出对应卡片（会合周期/相变潜热/热阻…），同时**解锁一个把该错误自动化规避的 UI 工具**（窗口日历/过热预警/泄漏探测）。
5. **无痛重试**：免费回到本次操作前（检查点回退），第二次做对 → 小成就与"传统点"。

> 要点：**失败成本 = 时间，不是资源**。第一次事故永远免费，同一类事故第二次起按规则扣材料。这保证"敢试"，也保证"学会了才有意义"。

### 3.4 与战略层的接口（折算规则）

**原则：战略层只收净数字，手感层不上报物理逐格状态。**

#### 3.4.1 轨道层 → 战略层

```
轨道净功率 = Σ [额定面板功率 × 日照因子(轨道类型) × 传输效率 × EROI因子(光伏 3–12, 含制造发射)]
轨道材料产出 = 前哨/拉格朗日工业吨位 × 加成(零重力制造 ×1.5–3 [软数据])
轨道维护成本 = 站保 Δv → 推进剂材料 + 星座补发材料
```
- 日照因子/传输效率表见 3.1.4，直接给 M01 做查表。
- **日凌/耀斑/失效 = 短时掉功率**，作为 M04 事件的数据输入。

#### 3.4.2 殖民地层 → 战略层

```
前哨净产出 = 精炼材料吨位 + 推进剂(水/液氧)吨位 + 科研点
生命维持消耗 = 人口 × 人均(氧 0.5–1.0 kg/天 + 功率 100–300 W/人) [软数据]
人口上限扩展 = 前哨宜居舱总容积 → 战略层人口上限 += f(容积)
```
