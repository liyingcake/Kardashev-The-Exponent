# M05 增量留存·UI/UX·科学教育系统 v0.1

> 模块角色：体验与教育设计师（子智能体 E）
> 依赖：M00（总指标锚点）、M01（核心循环数值）、M02（纪元/科技树/Prestige）、M03（手感层）、M04（事件/风险）
> 配套主文档：《00_总指标与设计锚点》《01_设计规范与计划》《02_讨论范畴与开放问题》
> 本模块的三个身份：**挂机节奏的设计师**、**单屏界面的守门员**、**把科学"顺路"塞进玩法的人**。

---

## 1) 目标与定位

### 1.1 一句话定位

让玩家"上瘾地挂机"（增量引擎）的同时，"顺手学懂"轨道力学、热力学与 EROI（教育引擎），并把"一根功率标尺"变成既有颜值又有信息量的唯一主界面。

### 1.2 三条灵魂目标

1. **上瘾**：把"下一次里程碑"做成一条永远向前的引力线——每次会话至少兑现 1 次正反馈高峰；离线不等于离开，离线也参与叙事。
2. **教得会**：遵守 P1（模糊正确>精确错误）与 P2（透明简化）——百科/科学卡片是**参考书**而非**课本**，教学时刻（just-in-time）由玩法需求触发，不打断心流。
3. **不堆砌**：参照 Universal Paperclips 的极简而深刻——主界面任何时刻常驻信息块 ≤ 7±2，数字永远带单位、永远可追问"为什么"。

### 1.3 与项目锚点的对齐

- 对齐 00 文档 §6 节奏目标：单局 30–60h、每次会话 ≥1 里程碑、中段手动高峰、末段挂机+决策。
- 对齐 00 文档 §7 数值铁律：本模块产生的每个反馈数字（离线收益、里程碑预测、留存钩子）都有物理/心理依据，不确定即标 [待核实]。
- 对齐 02 文档范畴：不做多人/社交；做完整增量骨架（挂机/离线/Prestige/奇点彩蛋）；做教育价值。

## 3) 关键机制与数值草案

### 3.A 增量留存机制

#### 3.A.1 挂机节奏分层（`[设计自由]`，数值 `[软数据]`）

把玩家体验切为四个"时间颗粒"，每层有独立的目标与反馈：

| 层 | 时间尺度 | 反馈锚点 | 频率承诺 |
|---|---|---|---|
| 心跳层 | 秒 | 功率/盈余数字跳动、手动操作即时进账 | 打开即有 |
| 分钟层 | 1–15 分钟 | 首个设施落成、首次盈余转正、首条科研完成 | 每 10 分钟 ≥1 |
| 里程碑层 | 15 分钟–3 小时 | 新纪元降临、新能源首点火、自动化层级解锁 | 每次会话 ≥1 |
| 纪元层 | 1–3 小时（中段）/ 1–3 天（末段） | Prestige 纪元更替、文明特质三选一 | 每 1–3 天 ≥1 |

设计依据：符合 Csikszentmihalyi 心流模型——挑战须略高于能力且目标清晰（见 §6 文献）；增量游戏的标准节奏则是"分钟级小刺激 + 小时级大刺激"双轨（参考 Cookie Clicker 的升级/成就双层结构）。

**节奏锚点数值（承接 00 文档 §6）**：
- 前 4 纪元（K<0.4）：30–60 分钟通过，每分钟都有新内容解锁 → 教学曲线（对应留存 D1）。
- 中段（K0.4–0.7）：每纪元 1–3 小时，手动操作高峰（能源切换、殖民决策）。
- 末段（K>0.7）：挂机/离线为主，手动做轨道与殖民决策（进入"指挥官"角色）。

#### 3.A.2 离线收益设计（回应 Q5）

**设计原则**：离线不亏，在线更赚；离线是"暂停的进程"而非"赠送的礼包"。

**三条防"上线即无敌"的天花板**（三者叠加，缺一不可）：

1. **时间硬上限** `[软数据]`：离线收益最多累积 24 小时（t_off ∈ [0, 24h]）。超出部分不累积，但玩家收到"离线信封"时显示被截断的量，以鼓励及时回来。上限可由科技/文明特质提升（上限 48h，配合 Prestige 循环）。
2. **效率衰减曲线 η(t_off)** `[软数据]`：
   ```
   0h ≤ t < 2h    : η = 1.00（全效）
   2h ≤ t < 6h    : η 从 1.00 线性衰减到 0.50
   6h ≤ t ≤ 24h   : η = 0.50（软封顶）
   ```
   衰减曲线的人因依据：短期离开（2h 内）应感觉"什么都没错过"；长时间离开（>6h）则鼓励玩家回来亲自操作（在线手动有 1.2–1.5× 加成，见 3.A.3），从而把"离线"变成"回到游戏的理由"。
3. **按离线时刻生产率结算（防无敌的真正关键）** `[设计自由]`：
   ```
   离线收益 E_off = P_net(t=离线上线时) × η(t_off) × t_off
   ```
   **不使用回城时刻的生产率**。玩家离线时若 P=10¹² W，离线 8h 只按 10¹² W 结算；回来解锁了聚变科技不会让旧收益翻倍。这是防止"上线即无敌"的核心机制。

**离线收益内容与限制** `[设计自由]`：
- 离线期间**盈余照常累积**（能源在无人干预下仍运行——符合"自动化文明"的叙事），按"离线焦点"（见下）分流。
- 离线期间**科研继续**，但**范式跃迁/需决策的科技节点暂停**，必须在线确认（保证事件与教育时刻由玩家亲手触发）。
- 离线期间**不推进事件链与文明风险**：因果链事件（M04）必须在线发生——这同时保证"失败即内容"不发生在玩家缺席时。

**离线焦点（主动委托）** `[设计自由]`：下线前玩家可从 3 个焦点选 1 个：
| 焦点 | 加成 | 代价 |
|---|---|---|
| 能量专注 | 发电效率 +30% | 科研速率 ×50% |
| 科研专注 | 科研速率 +40% | 建设进度 ×50% |
| 均衡 | 全 ×100%（基准） | 无 |

设计意图：离线收益从"被动白拿"变成"主动战略决策"，增加策略深度，也让"上线即无敌"的担忧转化为"我选错了焦点"的自我归因（降低流失时对游戏的怨气）。

**成本曲线（机会成本视角）** `[设计自由]`：
- 离线效率上限 = 在线自动生产的 100%（η=1 时），而在线手动操作另有"手动火花"加成（见 3.A.3），因此**永远存在"回来玩比挂机赚"的差分**。
- 离线不产生"手动火花"、不触发里程碑确认、不推进事件链 → 离线是"时间投入的低收益选项"，在线是"时间投入的高收益选项"。这给增量游戏最关键的命题（离线 vs 在线）一个清晰但不惩罚的答案。

#### 3.A.3 手动操作激励（"手动火花"）

`[设计自由]` 主动操作（点击建造/切换能源/决策）产生"手动火花"Culture Sparks，累积可兑换：
- 临时全局 ×1.1–×2 倍率（持续 30s，手动高峰爆发感）；
- 直接加速某科研节点（"顿悟"）；
- 用于预支一小段离线上限（上限 24h→+2h/次，限每日 3 次）。

目的：让"回来亲自动手"永远比挂机更有即时回报，且手动与自动化形成互补叙事（自动化移除劳动力上限，手动提供爆发）。

#### 3.A.4 自动化解锁节奏

自动化在 M05 只定义**节奏与呈现**，数值成本归 M01，科技节点归 M02。节奏草案：

| 纪元段 | 自动化里程碑 | 玩家角色转变 |
|---|---|---|
| K0.0–0.1 火种 | 纯手动（教学期，教会"点击=产出"） | 采集者 |
| K0.1–0.2 农耕 | 畜力自动灌溉（首个自动化设施） | 农庄主 |
| K0.3–0.4 前工业 | 水车/风车"水力自动化" | 磨坊主 |
| K0.4–0.5 蒸汽 | 首条自动产线（机械自动化） | 工厂主 |
| K0.5–0.6 电气 | 电气自动化（自动化乘数解锁） | 电网调度员 |
| K0.6–0.7 计算机 | 信息自动化 | 系统管理员 |
| K0.7–0.8 AI/互联网 | 全局自动化 + 自动再投资 | 战略家 |
| K0.8–0.9 聚变 | 自动化上限 +50% | 轨道规划师 |
| K0.9–1.0 戴森 | 完全自主运营（"观星者"） | 文明的最后操作员 |

节奏承诺：**每个纪元至少解锁 1 个自动化里程碑**，让"挂机能力"与"文明进度"同速成长；自动化的教育映射（畜力→水力→蒸汽→电气→信息→AI）即现实的自动化史，每个里程碑配 1 条百科词条。

#### 3.A.5 里程碑时刻设计

**定义**：里程碑 = 跨越性事件，触发条件满足时进入"里程碑演出"，玩家获得正反馈峰值。每次会话 ≥1 次（00 文档承诺）。

**三层里程碑**：

| 层级 | 触发 | 呈现（演出协议） | 落点 |
|---|---|---|---|
| 小里程碑 | 首个设施落成/盈余转正/首科研完成 | 数字跳动 + 音效 + 1 行提示 | 分钟层 |
| 大里程碑 | 跨 0.1 功率门槛、新能源首点火、自动化层级解锁 | 30s 全屏演出 + 纪元卡牌 + 科学卡片入口 | 里程碑层 |
| 终极里程碑 | 戴森云首环（K=1.0 前） | 特制 60s 动画 + 成就徽章 + Prestige 引导 | 结局层 |

**大里程碑演出协议**（可复用的状态机，供 M04/M02 接入）：
1. **铺垫**：标尺显示下一门槛倒计时（"距离 K=0.4 还有 2 小时 10 分"），制造"引力线"。
2. **触发**：跨越瞬间，全局音量压低→静默 0.8s（戏剧性对比）。
3. **呈现**：纪元卡牌（纪元名 + 代表能源图标 + 解锁清单 + 1 句史实对照"现实参照"）+ "查看科学卡片"按钮。
4. **沉淀**：事件永久写入"文明年表"（供 Prestige 回望）；标尺光标落点定格。

**"1 分钟里程碑检查"系统** `[设计自由]`：主界面右上角常驻一行"下一个里程碑：K=0.40，预计 2 小时 10 分"。这行文字是留存钩子的核心——它承诺了未来，让玩家随时知道"还有多久有大事发生"。

#### 3.A.6 Prestige 仪式感（纪元更替）

Prestige = 纪元更替（00 文档 §5：跨门槛后重置资源/人口/科技树，保留文明特质）。M05 负责把"重置"包装成**仪式**而非**损失**：

**转生动画（20–30s，可跳过但默认播放）**：
1. 刻度尺快速回卷至起点，当前文明影像（能源混剪）逐帧"风化"；
2. 收缩为一粒火种 → 新的薪火点燃；
3. 屏幕浮现一句"薪火相传"式文案（避免具体国家/人物，符合范畴外约定）。

**数据回望页："你上次的文明留下了什么"**（Prestige 确认前的必看页，类死亡统计页）：
- **文明年表**：每个里程碑的时间戳（"纪元 K=0.5·电气化 · 用时 2 小时 14 分"）。
- **功率历史曲线**：总功率 vs 模拟年份（一眼看出文明增速的"历史"）。
- **文明遗产**：人口峰值、能源组合饼图、最成功的单一设施。
- **知识遗产**：已解锁的百科条目数与科学卡片数（教育向留存钩子——"还有 137 条没读"）。
- **文明印记**：本局获得的文明特质列表（见下）。

**文明特质（永久乘数）——史实概念包装（回应 Q8）** `[设计自由]`：
- 每次纪元更替时 3 选 1 特质，特质用史实概念命名与描述（避免"+10% 产出"这种裸数字，也避免具体国家/人物）：
  | 特质名 | 效果 | 史实注脚 |
  |---|---|---|
  | 工程师传统 | 建设速度 +10% | 从水利工程到大型拱券的传承 |
  | 记账制度 | 所有产出 +5% | 从楔形文字泥板到复式记账 |
  | 印刷术 | 科研速率 +12% | 知识的边际成本骤降 |
  | 星图传统 | 轨道操作容错 +1 | 从托勒密到开普勒的观测积累 |
  | 盐与金属 | 自动化工成本 −10% | 贸易与冶金的规模效应 |
- 特质是"文明的身份印记"而非"装备"，用"你的文明因何而伟大"的句式呈现，保护代入感。

### 3.B UI/UX 原则

#### 3.B.1 单屏主界面布局

```
┌──────────────────────────────────────────────────────────┐
│  [文明刻度尺 ▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░]  K=0.23   下一门槛 0.30 │  ← 灵魂
│           （预计 2 小时 10 分）                             │
├─────────────┬─────────────────────────┬──────────────────┤
│  资源流图     │      能量总量 P  = 1.2 TW │  纪元面板         │
│  来源→需求→盈余 │      盈余 S   =  +85 GW │  纪元名/代表能源    │
│  (活瀑布流)   │      科研速率 = 1200/s   │  能源组合堆叠条    │
│             │    [ 主要互动区          │  设施/人口/自动化  │
│             │      手动火花池 ]        │  科研树快捷入口     │
├─────────────┴─────────────────────────┴──────────────────┤
│  [事件带] [年表] [百科] [科学顾问] [图鉴] [设置]              │
└──────────────────────────────────────────────────────────┘
```

布局原则：
1. **灵魂居中且最大**：文明刻度尺横贯顶部，是全屏唯一永驻的大物件（对标 Cookie Clicker 的中心大 Cookie）。
2. **左侧是"物理"**：资源流图显示能量从哪来、流向哪（功率守恒的可视化，教育核心）。
3. **右侧是"文明"**：纪元面板显示当前阶段与解锁进度。
4. **底部是"时间"**：事件带 + 年表，暗示游戏是"一条时间线"。
5. **单屏永不自锁**：任何详情以**浮层**展开，不新开全屏窗口（挂机游戏必须"随时可回看全局"）。

#### 3.B.2 "一根功率标尺"视觉化方案

- **形态**：横向长条，0.0→1.0，10 等分（每格 0.1 = 一个纪元），格内填充该纪元代表能源的微图标。
- **光标**：当前 K 值位置，带"呼吸"动画（亮度脉动）；盈余为正时泛暖光，为负时灰暗颤抖。
- **门槛线**：下一门槛以闪烁刻度线标示，悬停显示"K=0.30 · 距离 2h10m · 届时解锁：铁路/电报"。
- **升级脉冲**：每次跨 0.1 门槛，全尺脉冲一次（光环扩散），随后进入大里程碑演出。
- **能级隐喻** `[设计自由]`：标尺底色随能级变化——暖橙（火）→ 亮黄（工业）→ 白（电气）→ 冷蓝（聚变/戴森），用色温直观传达"文明温度"。
- **交互**：点击任意格 → 该纪元详情（能源/事件/可重玩内容）；长按 → 总功率历史曲线。

**为什么是"一根尺"**：K=(log₁₀P−6)/10 本身是对数压缩，一根尺子同时装下 10⁶→10¹⁶ W 的十二个数量级——它是唯一能承载"全部文明"的信息结构。教育上，玩家在操作中本能学会"每进一格就是 ×10"（对数直觉，为轨道力学/天文数量级打底）。

#### 3.B.3 因果链事件可视化（供 M04 使用）

- **视图**：有向图（节点 = 状态/事件，箭头 = 因果），用 `mermaid`-类结构在代码层实现，渲染为"星图"风格。
- **实时流**：正在发生的因果链以"火花沿箭头流动"呈现（如：煤矿枯竭 → EROI↓ → 盈余↓ → 科研停摆，一条火花链在界面上"点燃"）。
- **回放模式** `[设计自由]`：可回放任意历史因果链（教学价值最高的功能之一——让学生看到"一个决策如何在 30 分钟后引发崩塌"）。
- **崩塌回放**：文明崩塌（M04 触发）时慢速回放完整因果链，"失败即内容"（P4）的呈现核心。
- **接口协议**：M04 输出 `{事件id, 类型, 前因[], 后果[], 权重, 时间戳}`，M05 渲染组件并支持 M04 直接 push 新事件进图（详见 §4）。

#### 3.B.4 信息层级（不堆砌电子表格）

- **铁律**：主界面常驻信息块 ≤ 7±2（对标 Universal Paperclips——极简但每个数字都有分量）。
- **三层结构**：
  - L0 主界面：3 个核心数字（P、S、科研速率）+ 标尺 + 纪元标签 = 信息极简。
  - L1 单点展开：点任意数字块浮出详情（能源明细/人口/设施）。
  - L2 聚合面板：科技树、百科、因果链图（都是"可随时打开但默认关着"的）。
- **数字纪律**：一律 SI 前缀自动转写（W→kW→MW→GW→TW→PW→EW）；显示最多 3 位有效数字；每个数字悬停可问"这是什么"（1 行解释）。
- **教育分级显示** `[设计自由]`：设置里"显示复杂度"滑块（学生版默认满，休闲版默认精简）。

#### 3.B.5 音效/反馈设计方向

| 类别 | 设计方向 | 目的 |
|---|---|---|
| 能源音轨分层 | 13 种能源各有环境音（薪柴噼啪/水车汩汩/蒸汽嘶鸣/电气嗡鸣/聚变低鸣）；能源切换时**音轨渐变** | 用耳朵辨识纪元，能源升级的音效即里程碑反馈 |
| 标尺音调 | K 每 0.1 提升半音；盈余为负时叠加低沉警告音 | 音高=文明"体温" |
| 里程碑演出 | 触发瞬间静默 0.8s → 专属和弦 | 戏剧性对比（参照电影级音效设计） |
| 手动手感 | 每次操作点击音 + 触觉反馈（移动端） | 操作满足感 |
| 警告音 | 盈余为负/资源枯竭预警音（非灾难，是"机会"） | 传递"失败即内容"而非惩罚 |

音效总原则：**声音是第二条因果链**——玩家闭上眼也能听出"文明发烧了还是健康"。

#### 3.C.2 科学卡片模板（附完整示例）

**模板字段**（所有卡片强制）：`标题 / 难度(★–★★★) / 解锁纪元 / 公式 / 变量表 / 数值示例 / 游戏中的体现 / 简化说明 / 参考文献`。

**示例卡 042：齐奥尔科夫斯基火箭方程**（供 M03 手感层引用）：

```
# 科学卡片 042：火箭方程
难度：★★☆    解锁：K=0.6 原子能纪元（首枚火箭发射前）
公式：Δv = Isp · g₀ · ln(m₀ / mf)
  Δv   速度增量 [m/s]      —— 轨道转移的"预算"
  Isp  比冲 [s]             —— 燃料效率（化学约 300–450，核热约 800–900）
  g₀   9.80665 m/s² 地球标准重力加速度  [硬数据]
  m₀   起飞质量；mf 干质量（燃料烧尽后）
数值示例：Isp=300s，m₀/mf=4 → Δv=300×9.80665×ln4 ≈ 4079 m/s
  （对比：地球低轨道 Δv≈9400 m/s，含重力/大气损失 → 这就是"火箭方程暴政"）
游戏中的体现：你的火箭 Δv 显示在轨道面板；Δv < 需求则转移失败，
  必须靠分级/轻量化/换高比冲燃料解决。
简化说明：本游戏忽略大气阻力与多级火箭的复杂堆叠，取单级近似。
  真实推导见：Tsiolkovsky (1903) 《利用喷气装置探测宇宙空间》。
参考文献：NASA GRC, "The Tyranny of the Rocket Equation",
  https://www.grc.nasa.gov/www/k-12/rocket/rocket.html
```

**教育版额外字段**（阶段 2 启用）：`课堂讨论问题 / 教师备注`。

#### 3.C.3 "透明简化"标注机制（P2 落地）

- **机制**：每个词条/卡片/数值旁有可展开的"🔬 已简化"徽标；点击展开固定模板：

#### 3.C.5 如何让玩家"顺路学会"

核心方法论：**教在需要时（just-in-time）+ 玩法内嵌（mechanics-as-teacher）+ 好奇驱动**。

| 学科 | 顺路路径 | 关键机制 |
|---|---|---|
| 轨道力学 | M03 手感层：玩家必须凑够 Δv 才能入轨 → 被迫理解火箭方程 → 卡片 042 弹出 | "Δv 预算表"在轨道面板常驻；失败即回放因果链 |
| 热力学 | 蒸汽机纪元：效率 η=1−Tc/Th 直接决定玩家发电收益 → 选高 Tc 低 Th 能源 = 优化效率 | 蒸汽机界面显示"卡诺极限 η=32%，你当前 η=28%" |
| EROI | 每个能源标签带 EROI 徽标；EROI<1.5 触发"能源陷阱"警告 → 玩家被迫权衡 | 能源组合面板按 EROI 排序，切换动画标出净得 |
| 对数/数量级 | 一根刻度尺 = 每格 ×10 → 形成对数直觉 | 标尺格内标注 10 的幂次 |
| 熵/资源枯竭 | 煤矿储量随开采下降，曲线可视化 → "熵增"的具象化 | 储量曲线 + 卡片"峰值理论" |

**教育闭环**：玩法困惑 → 卡片解释 → 玩家重试验证（学了立刻能用）→ 掌握度徽章（非强制）→ Prestige 时回望"知识遗产"。教育不打断心流，而是成为心流的奖励。

### 3.E 教育版设想（KerbalEdu 模式，方向性）

> 阶段 2 由 M06 细化，此处只给方向与接口预留。

- **课堂场景**：教师启动"同步模式"——全班同纪元同进度，事件由教师统一触发；学生可自由探索百科（学生端 = 本模块的完整百科 + 卡片 + 因果链回放）。

## 5) 风险与开放问题

### 5.1 风险

| 风险 | 描述 | 缓解 |
|---|---|---|
| 离线收益失衡 | 离线过强→"上线即无敌"毁掉在线动机；过弱→挂机无意义 | 三重天花板（时间/衰减/按离线时刻结算）+ 手动火花差分 |
| 教育内容过载 | 300 条百科做成"没人打开的课本" | 解锁与进程绑定（just-in-time）+ 顾问卡引导 + 收集欲 |
| 单屏信息爆炸 | 一根尺 vs 海量信息的矛盾 | 7±2 铁律 + 三层结构 + "显示复杂度"滑块 |
| 科学准确性事故 | 常数/公式错一处毁全部信任（P1） | 全部 `[待核实]` 走科学顾问；卡片强制参考文献 |
| 留存目标落空 | 目标值对标行业但未实测 | 阶段 1 数值原型即跑留存模拟（A/B 离线曲线） |
| 演出打断心流 | 里程碑演出太长/太多 | 演出可跳过、只读、节奏锚点 ≤1 次/会话 |

### 5.2 开放问题（提交用户裁决的倾向性答案，详见 §6.2 之外的汇总）

1. 离线收益是否允许"购买扩展"（商业化将触碰"防无敌"承诺）？→ 倾向：允许但只延时间上限，不提升效率（见 M06）。
2. 教育版"同步模式"是否允许学生离线挂机？→ 倾向：允许，但进度由教师统一冻结。
3. 因果链回放是否开放给所有玩家（怕剧透/怕剧增复杂度）？→ 倾向：开放，它是核心教育功能。
