# Kardashev — The Exponent（《文明指数》）

> 把整个文明的进化压缩成一根功率标尺，让玩家亲手把卡尔达肖夫指数 K 从 0.0（火种）推到 1.0（T1 行星文明）。
> 一款"科学真实 × 可玩"的太空背景文明进化增量游戏设计项目。

## 项目定位

- **灵魂指标**：K = (log₁₀P − 6) / 10（萨根公式），主指标 = 文明总功率 P(W)
- **起点**：K = 0.0（P ≈ 10⁶ W，火种部落）｜**通关**：K = 1.0（P ≈ 10¹⁶ W，T1 行星文明）
- **核心约束**：EROI（能量回报率）是物理硬约束；散热在 K0.8+ 成为瓶颈（戴森云的"面积竞赛"）
- **主循环**：开采 → 提炼 → 发电 → 维持 → 盈余 → 科研 → 自动化 → 更大开采
- **设计铁律**：模糊正确 > 精确错误；透明简化；分层真实；失败即内容；数字必须有依据

## 设计原则（P1–P5）

1. 模糊正确 > 精确错误（受众会验证常数）
2. 透明简化（简化挂牌说明，KSP 式）
3. 分层真实（战略层数值结算 / 手感层轨道+热力学 / 表现层艺术化）
4. 失败即内容（文明崩溃是因果链事件，可回退学习）
5. 数字有意义（每个游戏数字背后有物理或历史依据）

## 阶段 1 数值原型结论（prototype_v01）

- **数值闭合成立**：加速因子 1140 → 0.052 连续递减，无发散/死锁
- **科研曲线健康**：闭合比全部 >1（1.21~3.03，前松后紧）
- **节奏达标**：前段教学 0.4h（目标 <1h）；推荐"慢"流速方案 → 25.7h 活跃 + 挂机 = 30–60h
- **流速方案建议**：末段 5–12 模拟年/现实小时（与 M02/M03 三方吻合）
