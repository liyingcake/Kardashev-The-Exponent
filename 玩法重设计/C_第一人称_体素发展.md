# 玩法重设计 C：《文明指数》第一人称体素建造方向分析

> 角色：玩法架构师（重设计专项）
> 动因：用户反馈——现有教学 demo（纯点击挂机）"玩法有限"，要求多资源互动、规划、开采、劳动力/可用工作个体、供需关系，整个玩法逻辑表现形式需要重新设计。
> 候选方向：**Minecraft 第一人称体素建造式**——玩家在 3D 世界里手动开采、建造、搬运、发展文明。
> 依据：《00_总指标与设计锚点》v0.6、《03_综合设计总纲》v0.3、`原型\demo\README.md`、M01–M05、《批判审查\02_杠精审查报告》（杠点 4、5）。
> 立场声明：本文件**不预设"主玩法"结论**，先诚实做适配性分析，再给设计、再给成本与风险，最终给出明确结论。任何与本文件冲突的既有裁决以 00/03 为准。

## ① 总纲

### 1.1 一句话定位（候选方向）

> **把《文明指数》做成"第一人称 Minecraft"：玩家亲手挖第一块煤、亲手铺第一条路、亲眼看着部落长成戴森云文明。**

### 1.2 本项目"不可动摇"的锚点（评审任何方向的红线）

先钉住红线，再谈设计——任何玩法方向若动摇下列锚点，即为致命冲突：

| 锚点 | 出处 | 内容 |
|---|---|---|
| A1 灵魂指标 | 00 §1 | K=(log₁₀P−6)/10，唯一主指标，P=10⁶→10¹⁶ W，**每 ×10 升 0.1，共 10 个纪元** |
| A2 铁律 | 00 §4 / M01 | 文明不能凭空造功率；每单位功率必须回溯到某条被模拟的能源链 |
| A3 EROI 硬约束 | 00 §3 / DC4 | EROI<3 不可持续（触发危机）、<1.5 立即崩塌；高 EROI 伴随高资本/科研门槛 |
| A4 增量骨架 | 00 §6 / M05 | 单局 30–60 现实小时；挂机/离线/自动化/Prestige；末段以挂机+决策型手动为主（DC2） |
| A5 十次脱胎换骨 | M02 §1 | 10 个纪元各引入**新玩法范式**，杜绝"中后期只是数字变大" |
| A6 分层真实 P3 | 01 / 03 | 战略层数值结算 / 手感层只深度模拟一个物理系统 / 表现层艺术化 |
| A7 教学闸门 | M03 / 杠点4 | 关键机制"首飞强制手动"，教学时刻锚定**主动段**，失败即教学（P4） |
| A8 范畴外 | 02 §2 | 不做多人/社交/对抗；不做逐国逐人历史复刻；不做仿真器级保真 |
| A9 资本计价 | DC6 | 设施成本=能量投资（年输出倍数），无独立货币 |
| A10 工具清空/范式保留 | DC10 | 纪元更替清空工具卡，范式成果保留（体素化后=蓝图库保留） |

### 1.3 本文件结构

②适配性分析（兼容/冲突清单）→ ③若采用如何设计 → ④与 K/EROI 的结合点 → ⑤分层折中建议 → ⑥实现工作量 → ⑦风险与对策 → ⑧一句话结论。

## ② 适配性分析：兼容与根本冲突

### 2.1 兼容清单（第一人称体素"能做得好"的部分）

| # | 兼容点 | 强度 | 理由 / 对应锚点 |
|---|---|---|---|
| C1 | **手动→自动化的教学弧线** | ★★★ | "首采强制手动→指派 NPC→自动化机器"完美落实 M03 的"首飞强制手动"教学闸门（A7）；也顺带回应杠点 4"教学必须锚定主动段"——没有比亲手挖矿更主动的段 |
| C2 | **EROI 的具身化教学** | ★★★ | 玩家亲眼看到"为了挖煤先烧掉了木头"：每块方块带能量账本，EROI 从标签变成"看得见的手"（详 §4.2），是本方向最强教育卖点 |
| C3 | **多资源 / 供需 / 劳动力落地** | ★★★ | M01 五层资源链（生物质→矿物→金属→能源载体→高级材料）天然对应体素分层矿脉；村民=劳动力=N；仓储网络=供需（详 §3）——**这正是用户抱怨 demo 缺的东西** |
| C4 | **规划感的强化** | ★★★ | 蓝图 + 区域规划 + 俯视规划图，把"点按钮"升级为"做建设"，对应 M02"每纪元新玩法范式"的物理承载 |
| C5 | **首段"手感峰值"** | ★★★ | 前 4 纪元 30–60 分钟教学段（00 §6）若以第一人称呈现，能兑现 demo《玩法体验与艺术设计》想要的"看得见的文明"：火堆→麦田→熔炉→烟囱 的成长是**空间可见**的 |
| C6 | **危机手动降级** | ★★ | M03 的"危机强制降级为手动"（自动失效必须人上）在体素里特别有戏：矿机瘫痪→"你必须亲自下去挖" |

### 2.2 冲突清单（根本冲突，诚实列出）

| # | 冲突 | 严重度 | 为什么是"根本"冲突 |
|---|---|---|---|
| X1 | **空间建造 vs 时间×10 指数增长** | ★★★ 致命 | 灵魂指标要求每纪元功率 ×10、共跨越 10 个数量级（A1）。体素建造的核心循环是"**在空间里摆东西**"，产出近似线性/二次方；而 K 要求**时间上的指数**。Minecraft 的乐趣来自空间探索与建造密度，不来自"数字 ×10"。手挖煤永远挖不出 10¹⁶ W——功率必须靠设施/自动化/科技（战略层）涨，那么"手动挖"在指数曲线上只占开头几分钟。**玩法表层（手动建造）与灵魂节奏（指数挂机）在结构上反向**。 |
| X2 | **增量挂机 vs 第一人称常驻** | ★★★ 致命 | A4 要求"末段以挂机/离线为主"，M05 有完整离线收益体系。第一人称需要玩家**一直在场**；挂机需要游戏**自己玩**。两者并存只有一种解：玩家挂机时第一人称部分空转——那玩家挂机时在干什么？如果答案是"看战略层数字"，第一人称就降级成了教学段的皮肤（这正是 §5 的结论）。若强行把手动建造当主循环，则 30–60h 里 40h 是手工重复劳动，与"挂机"承诺直接冲突。 |
| X3 | **成本失控（10–30×）** | ★★★ 致命 | 体素引擎、3D 渲染、碰撞、存档、NPC 寻路、物流——每一项都是无底洞（详 §6）。当前可玩 demo 是一个 JS 点击挂机文件；本方向等于换一条 3–5 年独立游戏的研发管线。对 A4/A5 的全内容量（10 纪元 × 每纪元新范式），体素版工作量是节点/产线式的 10–30 倍。 |
| X4 | **Prestige/纪元更替 vs 建造依附感** | ★★★ | A5/A10：纪元更替要"重置资源、清空工具卡"。体素玩家的核心快感是**建造物的永存**——把玩家辛辛苦苦盖的城镇每 1–3 小时重置一次，等于亲手摧毁玩家最珍视的东西（Minecraft 玩家对"炸图"零容忍）。"文明特质保留"在体素里救不回被推平的世界。 |
| X5 | **功率量级无法物化** | ★★ | 10⁶→10¹⁶ W 是 12 个数量级，体素世界里"一座 1 MW 矿场"和"一座 1 GW 电站"都是几个方块。**世界无法用方块数表达 ×10¹⁰**——最终功率还是得靠战略层数字结算（A2 铁律），那么"看得见的手"只覆盖了早期几个数量级，末段依然是抽象数值。 |
| X6 | **每纪元玩法范式的换皮陷阱** | ★★ | M02 警告"防中后期只是数字变大"。体素建造的范式"挖→造→运"在每个纪元完全一致——农耕的稀缺取舍、工业的集中/分布抉择、聚变的轨道物流，在方块里全是**换皮**（木材换成铁矿再换成硅晶圆）。要每纪元真换范式，等于每纪元做一个新游戏，成本再×10。 |
| X7 | **与 DSP 正面相撞** | ★★★ | 杠点 5 已核实：Dyson Sphere Program（戴森球、3D 亲手搭建、能量扩张——与终局一模一样的题材）EA 首周 35 万份、累计 170 万份、好评 96%、仍在更新。**"3D 亲手搭建"正是 DSP 的肌肉**。第一人称体素做主玩法=用 1/10 的预算玩 DSP 最擅长的游戏，且丢掉本项目唯一差异化（增量挂机+科学教育+功率标尺）。 |
| X8 | **科学教育承诺被稀释** | ★★ | 体素擅长教"物流与空间"，不擅长教"轨道力学/热力学/对数"（M03 的 2D 手感层才是物理课）。若第一人称成为主界面，玩家 80% 时间在搬方块而非读科学卡，教育 KPI（D1/D7/D30、≥300 百科）没有新增载体支撑；挂机段玩家不在场，体素世界不教任何科学（杠点 4 场景复现）。 |
| X9 | **受众与平台收窄** | ★★ | 第一人称 3D = 晕 3D 门槛、PC 独占、无法移动端触达；对 M05 的 D1≥45% 留存目标不友好（体素建造留存曲线也不等于挂机留存曲线）。 |

### 2.3 结论（适配性）

- **兼容面集中在"教学段 + 手感峰值"**：C1–C6 全部落在前 4 纪元 30–60 分钟、危机手动、EROI 具身教学。
- **冲突面集中在"主玩法"**：X1/X2/X3/X7 四条致命冲突，任何一条都足以否决"第一人称体素当主玩法"。
- **因此适配性的诚实答案**：体素只配做"手感层"（教学段限定），不配做"主玩法"。§5 给分层方案。

## ③ 若采用，如何设计（完整设计稿，供裁决时参考）

> 本节按"若玩家确实要求体素手感"为前提完整设计。即使采纳 §5 的"手感层"折中，本节的机制蓝图也可整体缩小移植。

### 3.1 多资源体素（世界生成与五层资源映射）

**世界观定标**：固定有限大陆（不搞 Minecraft 无限世界）——文明是"地球的一部分"，有限边界让"资源耗尽"真实发生（A2 铁律的物理化）。单纪元地图建议 4096×4096×256 方块，纪元更替扩展新大陆（§3.6）。

**资源分层**（映射 M01 §3.4 五层链）：

| M01 层 | 地表/浅层方块 | 深层方块 | 现实教学点 |
|---|---|---|---|
| L0 生物质 | 森林（原木/薪柴）、麦田、牲畜 | — | 森林再生速率=枯竭曲线（M04 森林枯竭事件可视化为树冠消失） |
| L1 矿物 | 石/砂/黏土 → 砖/水泥/玻璃 | 深石、大理石 | 建材链起点 |
| L2 金属 | 铜、锡（浅层） | 铁、铀（深层） | 品位递减：越深越难挖、能量成本越高 |
| L3 能源载体 | 木炭（窑） | 煤（中深）、石油、天然气 | **深度=EROI 梯度**：浅层露天煤 EROI 高，深层煤 EROI 低（现实"品位下降"，呼应 M01 枯竭曲线） |
| L4 高级材料 | 硅砂 → 晶圆 → 芯片 | 稀土、稀有金属 | 高纯工艺=隐形功率税（P2 挂牌） |

**对数层设计**（把 K 的 ×10 直觉嵌进地形）：矿床按深度分 10 个"品位带"，每下 1 带，单块矿物产量 ×10、单块挖掘能量成本 ×10——玩家在挖矿中**用身体感受"每深一层就是 ×10"**（为对数直觉打底，服务 M05 教育目标）。这是体素方向唯一能"物化对数"的点，必须保留。

### 3.2 方块加工链（工作站=设施）

- 工作站 = M01 设施（窑炉/熔炉/高炉/蒸汽机/电站…），消耗输入方块，产出输出方块+功率。
- 加工链走 M01 示例链：`铁矿→高炉(焦炭)→生铁→转炉→钢→合金`；每步显示能量损耗（冶金 EROI 附加惩罚）。
- 每个方块/设施携带**能量账本**（内含能量 MJ、开采已耗能量 MJ、EROI 徽标），§4.2。
- 所有设施成本用**能量投资计价**（DC6：年输出倍数）——体素里"资本"= 玩家预先囤积的能量方块/燃料库存，而非货币。

### 3.3 劳动力（村民 = 自动化 NPC）

**三态弧线**（教学闸门，A7 落地）：
1. **手作态**：玩家亲手做（首次挖煤/首次冶炼必须手动，失败即教学 P4）。
2. **指派态**：玩家给村民"示范"一次 → 村民学会该任务并持续执行（复制式自动化）。
3. **机械态**：造自动化机器（消耗功率，功耗 +10–30%，移除劳动力占用——M01 S8 原文）。

**村民系统**：
- 村民 = M01 人口 N 的化身：住房（床）+ 食物盈余 → 逻辑斯蒂增长（M01 §3.3 公式），新居民以"走进村庄的 NPC"呈现。
- 岗位分配：点村民 → 职业（樵夫/矿工/冶炼/搬运/耕种）；或点工作站 → 空缺岗位 → 系统自动补员（ONI 式优先级，可设 1–5 级）。
- 每个村民 = 1 单位劳动力 L，参与劳动参与率与教育占比（M01 §3.3.6）；"可用工作个体"直接可见：失业村民在广场闲逛，点选可分配。

**自动化边界**（防 X2 恶化）：村民只做"体力活"（挖/搬/种/烧）；**决策永远归玩家**——能源切换、科研、纪元更替、危机应对仍为手动（对齐 M03 干预频率上限 3.4.3）。

### 3.4 规划（蓝图 + 区域规划）

- **蓝图系统**：框选方块组 → 存为蓝图（消耗纸张/图纸）→ 一键放置（需建筑预算=能量投资）；纪元更替时**蓝图库保留**（=DC10"范式成果保留"的体素化）。蓝图是本方向"规划感"的命根子。
- **区域规划**：地图上划区域（矩形/多边形套索），类型=农田/矿区/工业区/居住区；区域内自动排班、自动补料、供需汇总（该区输入缺口/输出溢出红黄绿显示）。
- **规划视图**：第一人称之上叠加**俯视 2D 规划图**（区域笔刷/蓝图对齐），玩家"在 2D 图里做规划、在第一人称里做执行"——这是连接 §5 分层的关键桥。

### 3.5 供给（仓储网络，明确不做实体传送带）

**核心决策：不做 Factorio/DSP 式实体传送带。** 3D 实体物流（带速、吞吐、分流、并行、拥堵）是独立游戏最贵的无底洞之一，且与"数值结算在战略层"（P3）矛盾。改为：

- **仓储网络**（ONI 式节点）：每个区块建"仓储站"，有容量与覆盖半径；站与站自动互联成物流网。
- **自动搬运**：网内物资按需自动调度（隐藏实体运输，用"物流线"覆盖层可视化——橙色线=正在运什么、绿色=充足、红色=缺料）。
- **运输表现**（可选轻量）：矿车轨道/手推车作为视觉点缀，不参与结算（透明简化挂牌）。
- **供需表**：每个工作站显示 输入队列/输出库存/缺料警告 + 全图物流热力图。缺料=红色脉冲→玩家顺藤摸瓜找到断点——这是本方向"供需关系"的核心玩法闭环。

### 3.6 人口增长与纪元呈现

- **人口增长呈现**：住房区亮灯数=人口（M05"夜晚被征服了"的体素版）；新居民从村口走进来；食物盈余时村庄扩张（新屋自动落成），盈余为负时村庄暗淡（M04 饥荒事件可视化）。
- **纪元更替呈现**（解决 X4 的关键设计）：
  - 非破坏方案：**时代跃迁动画**——世界视觉重皮肤（木→砖→钢→混凝土→玻璃→合金），既有设施吞吐自动升级；玩家不丢任何建筑。
  - Prestige 则用 **"文明迁址"叙事**：旧大陆定格为缩微纪念模型（存入"文明年表"回望页，M05 协议），保留蓝图库+文明特质，新大陆开图重建——"薪火相传"的史实包装（Q8），且把"重置"变成"迁徙"的仪式而非"摧毁"。
- 每纪元新范式（M02 §3.1.3）在体素里如何兑现：农耕=土地互斥（同一块地种田/放牧二选一）、工业=集中/分布（工厂集中省维护但造物流瓶颈）、聚变=轨道物流（地面→轨道货舱，接 M03）——每个都做**机制差异化**而非换皮，但成本按 §6 估算。

## ④ 与 K 指数 / EROI 的结合点

### 4.1 功率从"玩家手挖煤"到"文明功率"的桥

**铁律回答（A2）**：玩家手挖煤**不直接等于文明功率**。功率链是：

```
玩家手动挖煤（火花）→ 造出 矿工/矿车 → 煤以方块流进入 工作站（发电）→ 工作站输出 P(W)
→ P 汇入战略层 P_total → K = (log₁₀P−6)/10 上升
```

- **手动 = 火花**（M05 §3.A.3 手动火花机制原文）：玩家的每一次手动挥镐/放置，直接产生"手动火花"（短暂全局倍率/顿悟加速/离线上限），让"回来玩比挂机赚"成立——第一人称操作天然就是火花发生器，这是本方向与增量骨架**唯一顺畅的接口**。
- 基准 P 永远来自设施与自动化；手动只在教学段、危机降级、火花爆发三点出场（对齐 DC2"决策型手动"精神：把操作收束到"关键时刻"）。

### 4.2 EROI 第一人称教学（本方向最强教育卖点）

**能量账本机制**：每个方块/设施带两栏——"内含能量 MJ"与"开采+加工已耗 MJ"，EROI=前者/后者，全图徽标显示。

**教学序列**（M03 5 阶段事故模板落地，P4）：
- 情境：玩家第一次深挖煤矿，为挖煤消耗了大量木炭（燃料+食物）。
- 事故：矿坑里显示"本矿 EROI=2.1"并开始预警（红闪）。
- 侦探回放：回放每块煤的账本——"挖 1 吨煤烧掉 0.5 吨木炭 + 你吃了 0.3 吨粮食"。
- 科学卡：弹出 EROI 卡（Hall 2009 最小 3:1，已核实）+ 解锁"能量账本面板"工具。
- 无痛重试：回检查点；第二次玩家用"更高效的开采方式"（先造矿机，别手挖）。
- **红线具身化**：EROI<3 的能源全网泛红、<1.5 立即崩塌（00 §3 原文）——玩家"用身体"记住了红线在 3，不在 1.5。

**诚实标注**：体素教得好的是 EROI 与对数直觉；**轨道力学/热力学不归体素教**，仍归 M03 的 2D 手感层（防 X8 恶化）。边界写进透明简化挂牌。

### 4.3 K 指数的呈现

- 主界面顶部 K 刻度尺**永不消失**（M05 灵魂），体素世界里加"文明天线"：头顶天际线的信号柱随 P 上升（1 根→10 根→百根，每次 ×10 亮一根），把对数尺"长"进世界。
- 世界的"地平线扩展"随纪元解锁（新大陆=新 K 档），P 量级差异在战略层结算（X5 承认：体素物化不了全部 12 个数量级，只物化前 4–5 个）。

## ⑤ 分层折中建议（我作为架构师的推荐结构）

> 结论先行：**第一人称体素 = 第三手感层（教学段限定），战略层保持节点/产线/数值。** 这不是"妥协"，而是让 C1–C6 兼容面全部生效、X1–X9 冲突面全部绕开的唯一结构。

### 5.1 三层架构（在 P3 基础上扩展）

| 层 | 内容 | 技术形态 | 承担 30–60h 的时段 |
|---|---|---|---|
| **战略层（主玩法，不变）** | K 刻度尺、资源流图、产线/节点、科技树、Prestige、离线/挂机、10 纪元 | 2D 节点图 + 数值（现状 demo 的增强版） | 全程，中段/末段为主 |
| **手感层 A（现有 M03）** | 轨道力学、殖民地热力学 | 2D 平面 + 倾角滑条 / 2D 网格 | K0.5–0.7 教学、K>0.8 决策型手动 |
| **手感层 B（新增，本方向）** | **第一人称体素建造（教学段限定）** | 低模 3D 体素 | **前 4 纪元 30–60 分钟 + 危机手动降级** |
| **表现层** | 艺术化（现有 demo 的 Canvas 场景升级） | — | — |

### 5.2 手感层 B 的硬性边界（防 X1/X2/X3 蔓延的"纪律清单"）

- 地图 ≤ 256×256×64 方块（教学大陆，非无限世界）。
- **无 NPC 寻路**：村民移动用"异步队列结算"（点 A→点 B 的搬运直接走库存，不逐格走路；仅村口/广场做行走表现）。
- **无实体传送带**：仓储网络节点式物流（§3.5）。
- **无物理模拟**：方块静态放置/破坏，无重力/流体/爆炸物理（爆炸事件只做特效+结算）。
- 不出场内容（明列范畴外）：挂机/离线、Prestige 重置、科技树全文、轨道/殖民地、戴森云——**全部在战略层/手感层 A**。
- 干预频率硬上限（对齐 M03 §3.4.3）：教学段 ≤1 次操作/2 分钟；之后体素世界"自动运转"，玩家只在火花/危机时进入。

### 5.3 更便宜的替代（若手感层 B 的预算都拿不出）

**2D 顶视角建造层**（RimWorld/Dwarf Fortress 式，像素/低模俯视）：多资源、劳动力、供需、规划感**一个不少**，成本约为第一人称的 1/10–1/15（无 3D 引擎、无相机、无碰撞），且天然支持移动端与挂机共存。**若用户反馈的核心痛点是"多资源/规划/劳动力/供需"而非"第一人称"本身，顶视角是性价比最优解**——把第一人称降级为"表现层的镜头预设"（俯视+近景推拉）。

### 5.4 用户反馈如何在折中方案里被满足

| 用户要的 | 手感层 B（体素） | 战略层（2D） |
|---|---|---|
| 多资源互动 | 挖矿/采集的触感 | 五层资源链节点图 |
| 规划 | 蓝图+区域笔刷（教学段） | 产线规划器、资源流图 |
| 开采 | 手动挥镐（火花） | 矿区节点+枯竭曲线 |
| 劳动力/可用工作个体 | 村民指派（教学段） | 人口/劳动力/自动化结算面板 |
| 供需关系 | 仓储网络+物流热力图 | 资源流图供需仪表 |

## ⑥ 实现工作量（诚实评估）

### 6.1 三类形态的对比估算（独立开发/小团队口径，人月）

| 形态 | 引擎 | 核心模块 | 估量（人月） | 相对节点式 |
|---|---|---|---|---|
| **A 战略层节点/产线式（2D）** | 现状 JS/或 Godot 2D | 数值结算、2D 资源图、科技树、离线、UI | **8–15** | 1× |
| **B 教学段限定第一人称体素（手感层）** | Godot/Unity 3D | 低模体素引擎（网格/碰撞/放置）、教学大陆、蓝图、仓储网络（无寻路无传送带）、存档 | **15–30** | **2–4×** |
| **C 第一人称体素主玩法（全内容）** | Godot/Unity 3D | B 全部 + 无限或超大世界、NPC 寻路、实体物流、10 纪元全内容、危机系统、戴森演出 | **80–160+** | **8–15×**（按单人可能 10–30×） |

### 6.2 分项清单（C 形态的恐怖明细，逐一诚实列出）

| 模块 | 估算 | 备注/主要坑 |
|---|---|---|
| 体素引擎（渲染+网格+碰撞+射线拾取+区块） | 8–16 人月 | 在浏览器 JS 里做体素（Three.js 可行但存档/寻路/物流会压垮）；建议原生 |
| 地形生成 + 对数品位带设计 | 3–6 人月 | 品位带=每层 ×10 的平衡工作 |
| 方块加工链 + 工作站 + 库存 UI | 4–8 人月 | 清单/合成/插槽 UI 极耗工时 |
| NPC 村民（寻路/AI/住房/岗位） | 6–12 人月 | **3D 体素寻路是业界著名无底洞**（B 方案直接砍掉寻路=省 6–10 人月） |
| 实体传送带物流 | 6–12 人月 | 吞吐/分流/拥堵/掉帧；B 方案砍掉=省全部 |
| 蓝图系统 | 2–4 人月 | 序列化/对齐/预算 |
| 3D 存档（体素世界压缩存档+热备份） | 1–3 人月 | 无限世界存档是另一坑；有限地图可控 |
| 3D UI/引导/晕 3D 适配 | 3–6 人月 | 教学段"别把玩家劝吐" |
| 性能优化（渲染批次/帧率） | 持续 | 无底洞 |

**结论**：全内容体素主玩法≈一次 3–5 年独立游戏级投资；即使"教学段限定体素"也需要 15–30 人月，超过战略层整个游戏（8–15 人月）。**对一个今天可玩体是单文件 JS 点击挂机的项目，这是阶段 3+ 级别的工程，不是本轮重设计能吞下的。**

### 6.3 对本项目 Roadmap 的影响

- 01 §5 阶段 2 垂直切片 = "火种→农耕 15 分钟可玩"。若切到体素，垂直切片先做 3D 引擎而不是玩法——**里程碑倒退**。
- 平台收窄为 PC（Steam）；移动端、网页端（当前 demo 形态）放弃。

## ⑧ 一句话结论

**第一人称体素只配做"手感层"（教学段限定 + 危机手动 + EROI 具身教学），绝不配做"主玩法"——因为空间建造与指数挂机在结构上反向、全内容体素成本是节点/产线式的 10–30 倍、且会正面撞上已占领该赛道的 DSP；用户要的"多资源/规划/开采/劳动力/供需"应主要交给 2D 战略层（产线+节点+资源流图）去实现，体素作为其手感前缀。**
