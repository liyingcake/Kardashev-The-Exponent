# v4 改法 —— 统合节点 × 窗口乘数 × 能量利用

> 日期：2026-08-13 ｜ 定位：v4 主设计。**保留 v3 的"上帝视角"交互层**（国策/权重/探索/裁决），**重铸数值层骨架**为"功能管线 + 统一乘数 + 能量利用"。
> 依据：`v4_01_反思` 的五病灶。

---

## 0. 一句话

> 把"并列堆量 + 烧燃料"的加法引擎，换成**一条有目的的产业链**：采集→加工→定居点消费→收集。成长来自**一个统一的乘数**（规模×技术×国策），能量是**被利用来做加工的中介**，不是被烧掉的终点。

---

## 1. 新的节点模型：功能管线（不是并列堆量）

### 1.1 五类功能节点（替换 v3 的"源/农场/能源/科研"并列分类）

| 类型 | 职责 | 输入 | 输出 | 关键语义 |
|---|---|---|---|---|
| **采集 Gather** | 获取原料 | 劳动力 | 生食/木柴/矿石/纤维 | 文明的第一手物质 |
| **加工 Process** | 消耗原料+燃料，产出加工品 | 原料 + 燃料 | 熟食/木材/金属/布 | **能量在此被"利用"**（烹饪/冶炼） |
| **分配 Logistics** | 运输，带吞吐容量 | 上游产物 | 下游原料 | 连线即玩法（Upload Labs），瓶颈可视化 |
| **消费 Settle** | 定居点消耗加工品 | 加工品 | **劳动力 + 科技点 + 人口** | 消费端 = 需求 + 劳动力源（维3 POP） |
| **收集 Collect** | 汇总所有产出，承载"窗口 + 乘数" | 劳动力/科技/文化 | **乘数总览** | 用户点名的"收集节点" |

> 关键转变：**节点之间是"串联"关系，不是"并列"关系**。玩家规划的是"这条链通不通、最慢一环在哪"，而不是"我堆了几个森林"。

### 1.2 一条最小闭环（MVP）

```
森林采集(生食+木柴) ──┐
农田(生食) ──────────┼─→ 灶火烹饪(生食+木柴 → 熟食) ─→ 定居点(熟食 → 劳动力+科技) ─→ 收集台(乘数窗口)
                     └──────────────────────────────────────────────────────────────────┘
```

## 2. 能量 = 利用，不是消耗（EROI 语义重构）

### 2.1 旧语义（v3，错）

```
烧木头 → 变瓦特。EROI = 发电功率 / 燃料等效功率（"我烧得够不够高效"）
```

### 2.2 新语义（v4，对）

```
燃料(木柴) + 原料(生食) →[烹饪加工]→ 加工品(熟食) →[定居点消费]→ 劳动力 + 科技
```

- 能量的作用是**中介**：它把"不能直接用的原料"变成"能被社会消费的加工品"。
- **EROI 新定义**：加工节点的 `EROI = 加工品的可用能量价值 / 投入燃料能量`。烹饪：木柴(燃料)让生食变成更易吸收的熟食 → 净利用为正（EROI > 1）。
- **K 指数的新 P**：不再是"发了多少电"，而是**全链的"有用能量流"** = 定居点真正消费掉的加工品所承载的能量价值。文明强不强，看它**把能量用到了多少件有意义的事上**，而不是烧了多少柴。

### 2.3 对玩家的效果

- 建一堆篝火（没有加工目标）**不产生价值**——能量无处可去。
- 只有"采集→加工→定居"完整闭合，能量才被真正利用，P 才涨。**这就是"统合"的物理动机。**

## 3. 窗口 + 乘数（统合的核心）

### 3.1 窗口（经济总览，唯一主面板）

一个面板统合所有数字，替代 v3 的散落 UI：

```
┌─────────────────────────────────────────┐
│  🔥 文明指数 K 0.12 ｜ 有用能量流 1.5 MW  │
│  生食 12/s → 熟食 6/s → 消费 5/s        │  ← 管线流量
│  👷 劳动力 8/10 ｜ 🧪 科技 +3/s         │
│  ───────────────────────────────────     │
│  总乘数 ×3.4  [展开]                     │  ← 小乘数
│    基础 ×1.0 · 整合 ×1.5 · 规模 ×1.3 ·  │
│    技术 ×1.2 · 国策 ×1.45               │  ← 可分解
└─────────────────────────────────────────┘
```

### 3.2 小乘数（可分解的乘数）

玩家的成长不再靠"节点数量"，而靠**一个总乘数的增长**，且每个因子可点开追问：

| 乘数因子 | 来源 | 含义 |
|---|---|---|
| **基础** | 节点自身的等级/配方 | 单节点的产出量 |
| **整合** | 产业链完整度 | 采集→加工→定居→收集每闭合一环 +加成；**奖励统合，惩罚摊大饼** |
| **规模** | 吞吐量阈值 | 同一条链吞吐越大越高效（维3 规模经济） |
| **技术** | 已研发科技 | 换配方/提效率 |
| **国策** | 已激活国策 | 人格倾向 |

> 一句话：**"小乘数"就是文明的效率名片**——K 涨不涨，看的是"这一串乘起来多大"，而不是"我有几个节点"。

## 4. 供需与规模效应

### 4.1 供需闭环（维3 + Upload Labs）

- 定居点有**需求**（消耗熟食）；供<需 → 劳动力/科技产出下降（饥荒）；供>需 → 盈余。
- **盈余的用途**：投资升级乘数、研发科技、扩张链——把"运营"变成玩家可决策的东西。
- 连线（分配）有**吞吐容量**，最窄的一环 = 整链瓶颈。玩家的规划 = **找瓶颈、升瓶颈**，而不是盲目加节点。

### 4.2 规模效应（维多利亚3）

- **整合系数**：链越完整，产出越高（闭合奖励）。
- **规模系数**：单条链吞吐超过阈值后，效率递增（集中 > 分散）。
- 两者叠加 → **"集中整合"永远优于"摊量"**，直接消灭病灶 F。

## 5. 与 v3 交互层的关系（保留什么）

| v3 宏观动词 | v4 处置 |
|---|---|
| 定国策 | **保留**，映射为乘数里的"国策因子" |
| 调六支柱权重 | **保留**，映射为"盈余投向"（投资乘数/科技/扩张链） |
| 设探索焦点 | **保留**，但探索解锁的是**新的加工配方/原料**，而非新"能源节点" |
| 裁决危机 | **保留**，危机=某条链的供需断裂 |

> 结论：**交互层不动，数值层全换**。上帝视角依旧，但你看的是一张"会呼吸的经济体"，不是一堆堆数字节点。

## 7. 一句话裁决

> **把《文明指数》从"堆节点的加法"重铸为"经营一条产业链的乘法"：节点是串联的工序，能量是被利用的中介，一个可分解的小乘数（整合×规模×技术×国策）是文明效率的名片，定居点是消费端也是劳动力源，收集台是这一切的窗口。**
