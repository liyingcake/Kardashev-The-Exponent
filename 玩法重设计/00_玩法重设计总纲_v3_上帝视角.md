# 《文明指数》v3 — 上帝视角·宏观引导 玩法重设计总纲 v0.1

> 日期：2026-08-13 ｜ 触发：用户定调——"玩家应是上帝视角而非微观控制，在宏观上引导整个文明发展、探索世界、进展"；并明确"不要被旧项目玩法限制，节点机制还不错可以保留"。
> 定位：本文档是 v3 的主决策文件，**取代《00_玩法重设计总纲 v0.1》作为当前主玩法方向**；旧文档（A/B/C/D 方案）与 demo-v2（节点-lite）归档为"v2 微观层"，其结算引擎与技术结论继续被 v3 复用（见 §5、§7）。

---

## 0. 一句话定位（v3）

> **玩家不再是"搭链的工程师"，而是"塑造文明意志的神"。**
> 你通过 **定国策、设战略目标、分配文明资源的优先级、裁决关键时刻** 四条宏观指令，引导一个**会自己生长、自己探索、自己崩溃又重生的文明**，从火种部落一路进化到 T1 行星文明；节点供需网络从"你要一格一格搭的东西"降级为"文明的活体解剖图"——你**看它**怎么跑、怎么红、怎么在纪元更替中自我换代，只在你想看清因果、或想俯身微调时，才落下去摸一摸。

## 1. 为什么从 v2（微观节点）转向 v3（上帝视角）

| 维度 | v2（节点-lite，2026-08-12） | v3（上帝视角，本文件） |
|---|---|---|
| 玩家身份 | 工程师/工头：放节点、连线、升级、雇工 | 引导者/神：定方向、设目标、分资源、裁命运 |
| 最小操作单位 | 一个节点、一条边、一个工人 | 一条国策、一个战略目标、一次投资配比、一次裁决 |
| 文明的"主体性" | 被动的——你不搭它就不长 | **主动的——它按你的意志自我生长、自我探索** |
| 节点图定位 | 主操作对象 | 观察层/教学层/可选微调层（解剖图） |
| 核心情绪 | 规划爽、算账爽 | **史诗感、因果感、有限的上帝权力带来的张力** |
| 探索世界 | 无（地图是背景） | **一等公民**——地图/星图逐步揭开，探索由文明派出 |

**判断依据（为何不是"更微观"而是"更宏观"）**：
1. 用户明确"不要那么多微观控制"——v2 的放节点/连线/升级/雇工本质仍是微观，虽比点击挂机强，但操作密度与"神"的代入感相悖。
2. 8000 年跨度、11 档功率阶梯、10 次纪元更替的叙事，需要的是**"文明在长大"的体感**，而非"我在搭积木"的体感；前者靠宏观引导，后者靠微观建造。
3. EROI/能量守恒这些科学锚点，在 v2 里要靠玩家亲手算账才成立；在 v3 里可以变成**"你下了一条错误的国策，于是你看见森林枯竭的红从图上一路蔓延"**——科学教育从"读数字"升级为"看后果"，这正回应了杠精审查"挂机如何教科学"的质疑，且更省认知负荷。

## 2. v3 想表达的效果（体验目标）

这是本次重设计的灵魂，逐条说明"玩家应该感到什么"：

### E1 · 俯瞰者的史诗感
玩家是一双悬在时间之上的眼睛。火种点燃、城市兴起、蒸汽翻涌、电网铺开、火箭升空、戴森云首环闭合——**这些不是玩家一格一格搭出来的，而是玩家看着文明在自己的意志下自己长出来的**。每一次纪元更替，旧的文明形态风化褪色，新的文明形态在你的指令下点亮。

### E2 · 因果可见（"我的意志长成了这个样子"）
玩家的每条宏观指令都要在世界上**长出看得见的后果**：
- 下"重农"国策 → 麦田/灌溉节点在图上蔓延、人口曲线抬头；
- 把盈余优先投给"探索" → 地图迷雾被推开的面积变大、新资源点被发现；
- 下"尚武"国策 → 冶金链膨胀，但科研节点因被抽走资源而熄灯。
**玩家看到的是"我的选择如何塑造了文明"，而不是一堆数字在涨。**

### E3 · 有限的上帝权力（张力的来源）
玩家**不是全能**：只能影响"倾向"，不能直接搬运一吨煤、不能凭空造一个节点。文明会犯错、会违背你的意愿崩掉——而这正是"失败即内容"（P4）的戏剧来源。**神的挫败感，比工程师的挫败感更有史诗性。** 有限的"意志槽"与有限次数的"裁决干预"保证这份权力永远稀缺。

### E4 · 探索世界的驱动力
世界（早期是大地图，末段是星图）**从迷雾开始**，探索是文明自动派出的探险队/探测器，玩家决定"往哪探、探多快、投多少资源"。未知本身就是最强的牵引力：地图边缘的未知资源点、宜居带、拉格朗日点、未知文明遗迹，驱动玩家不断"让文明去探索"。

### E5 · 文明是有"性格"的
国策与战略目标组合出一套**可辨认的文明人格**（重农的田园帝国、尚武的军工帝国、崇尚科学的启蒙共和国……）。一局结束回看编年史，玩家看到的是"**我养出了一个什么样的文明**"——这是上帝视角独有的、节点搭建给不了的"养成感"。

## 3. 核心玩法循环（宏观）

一句话循环：**定策 → 设标 → 分权 → 看后果 → 裁决 → 换代**。

```
[定国策] 给文明装"人格"（长期倾向，低频）
   ↓
[设战略目标] 给文明一个"大方向"（中期目标，中频）
   ↓
[分配资源权重] 把文明盈余投给六大支柱（高频，核心手感）
   ↓
[观察后果] 世界地图 + 节点解剖图实时反映文明自我生长
   ↓
[裁决关键时刻] 危机/机遇/纪元更替时，有限次数干预（手动火花）
   ↓
[换代 Prestige] 旧文明风化 → 文明印记结算 → 特质 3 选 1 → 新纪元点亮
```

对比 v2 的循环（开图→补链→闭合→换代），v3 把前三步从"物理操作"抽象为"意志指令"：**玩家不再逐节点操作，而是给文明下达"我要它变成什么样"，由文明的自动体（autonomous agent）把指令翻译成节点网络的自我重组。**

## 4. 三种宏观动词（交互骨架）

> 这是 v3 的"手"。所有高频到低频操作收敛为三个动词 + 一个低频裁决，共四类。设计原则：**操作次数少、语义重、后果可见。**

### 4.1 定国策（Creeds / Policies）—— 装人格，最低频

- **是什么**：文明级长效倾向开关，共 8–12 条，同时最多激活 2–3 条（"意志槽"受限，制造取舍）。
- **示例**：
  | 国策 | 效果（宏观→微观翻译） | 代价/倾向 |
  |---|---|---|
  | 重农 | 农业类节点自动生成倾向↑、人口增长×1.3 | 工业/科研权重被挤占 |
  | 崇尚科学 | 科研节点自动生成↑、科技成本−15% | 短期盈余收缩 |
  | 尚武 | 冶金/军工链膨胀 | 抽走农业与科研资源 |
  | 扩张 | 探索派出的探险队规模×2 | 后勤/维持消耗↑ |
  | 内敛 | 损耗−10%、稳定度↑ | 探索范围缩小、增长放缓 |
  | 囤积 | 储能上限↑ | 即时功率增长变慢 |
- **机制本质**：国策是**自动体（节点网络生成器）的偏好参数**——它改变节点网络的"自然生成倾向"，而不是直接改数值。这样既保留"功率逐源追溯"的铁律，又让宏观指令有物理后果。

### 4.2 设战略目标（Agendas）—— 给方向，中频

- **是什么**：给文明一个可完成的大目标（"征服这片大陆""发明蒸汽机""跨过海峡去探索新大陆""建成第一座大坝"），文明会把它的节点网络**朝目标自我重组**，完成后给里程碑 + 永久文明印记。
- **机制本质**：战略目标 = 给自动体一个**目标函数**，节点网络在若干 tick 内朝它演化。这是"上帝引导"最直观的体现——你指一个方向，文明自己想办法走过去（它的"办法"就是图上可见的节点重组）。
- **里程碑演出**：目标达成触发一次 30 秒演出（新节点点亮、地图迷雾推开、编年史写入一条）。

### 4.3 分配文明资源权重（Priorities）—— 分权，最高频

- **是什么**：把**文明盈余**按比例投给六大支柱：`探索 / 科研 / 农业 / 工业 / 文化 / 国防`。这是玩家每 1–3 分钟调一次的**核心手感**，替代 v2 的"放第 10 个篝火"。
- **为什么这是核心**：它把 v2 里"养大一个节点"的成长感，升维为"养大文明的一个能力维度"。调一次配比 = 文明增长曲线在 30 秒内肉眼可见地转向。
- **界面**：一条六段式"文明血脉"条（每支柱一段），拖拽即重分配，总和=100%；紧邻它的是一张"世界地图 + 节点解剖图"，实时显示哪条链在膨胀、哪条链在萎缩。

### 4.4 裁决关键时刻（Judgments）—— 有限干预，最低频手动火花

- **是什么**：危机/机遇/纪元更替时，上帝做**有限次数**的"干预"，通常 3 选 1：
  - 例：森林枯竭危机 → ① 转水车（引导转型）② 加大伐木（续命，边损耗↑）③ 不干预（看文明自己扛，扛过去得韧性印记）。
- **与 DC1 时间信标的关系**：保留"每纪元 3 信标"的倒流权，但倒流本身就是一种"神迹"叙事——"神回拨了时间"。硬核模式关闭信标，只保留"观察"。
- **机制本质**：这是 v3 保留的"手感火花"（对应 M05 手动火花 / M03 决策型手动）。它让玩家**关键时刻仍在场**，但不要求平时在场。

## 5. 节点机制的保留方式（从"操作对象"到"解剖图"）

> 用户明确"节点机制不错可以保留"。v3 的做法是：**结算引擎 100% 保留，交互定位改变。**

### 5.1 保留什么（底层，零推翻）

- **节点模型**（9 类：源/采集/加工/物流/存储/能源/科研/消费/防御）、**连线（资源管道）**、**逐 tick 供需平衡求解器**、**EROI 硬约束**、**拓扑排序/无死锁保证**、**K 指数逐源追溯**——这些是 v2 已跑通的核心，v3 **原样复用为结算引擎**。
- **科技三重映射**（解锁节点/连线/属性）保留，但解锁动作由"玩家点科技卡"改为"文明在国策+目标驱动下自动点，或玩家在战略目标里指定"。

### 5.2 改变什么（交互层，三个新定位）

1. **节点网络 = 文明的解剖图（观察层）**：默认不显示全图，只显示"世界地图"；玩家点某地区/某产业，**下钻**进该处的节点子图，看它怎么跑、EROI 哪里红、瓶颈在哪。
2. **节点由文明自动生成（自动体）**：玩家不再逐格摆放节点。国策/目标/权重 → 自动体在图上生成/重组/删除节点与边。玩家若想，可以**俯身微调**（可选，不影响通关），但鼓励宏观。
3. **节点图 = 科学教育的入口（教学层）**：EROI 红了、卡诺效率不足、散热子节点顶到上限——这些科学时刻依然发生在节点图上，玩家下钻即见"为什么"，但它**不再是操作负担**，而是"看后果"的地方。

### 5.3 一句话

> v2 让玩家"亲手连一张文明血管图"；v3 让玩家"**给文明一颗心，然后看这张血管图自己长、自己跳、自己生病、自己换血**"。图还在，但它是**活的**，不是玩家拼的积木。

## 6. 可玩性分析

### 6.1 三条深度轴（替代 v2 的"放/连/升级"）

| 轴 | 内容 | 玩家在做什么 | 对应的旧设计 |
|---|---|---|---|
| **策略轴** | 国策 × 目标 × 权重的组合取舍 | 在有限的意志槽里抉择"我要一个什么样的文明" | v2 的拓扑抉择（集中 vs 分布式）升维为"文明路线抉择" |
| **叙事轴** | 8000 年编年史 + 文明印记 | 回看"我养出的文明的一生"，一局一个独一无二的历史 | M02 编年史 + 文明印记，v3 里成为主体验而非附赠 |
| **探索轴** | 地图/星图迷雾揭开 | 决定"往哪探、投多少"，被未知牵引 | 新增（回应用户"探索世界"），末段升级为星图 |

### 6.2 节奏目标（对齐 00 §6，不推翻）

| 现节奏锚点 | v3 如何达成 |
|---|---|
| 前 4 纪元 30–60 分钟快进 | 每 2–3 分钟一个"定策/设标"决策点，教学密集，文明生长快 |
| 中段每纪元 1–3 小时手动高峰 | 调权重 + 裁决危机 + 探索抉择 = 手动高峰 |
| 末段挂机 + 决策型手动 | 自动体自我平衡，3–5 分钟一次轨道/探索决策（DC2） |
| 每次会话 ≥1 里程碑 | 目标达成/纪元更替/探索发现/危机化解均可触发表演 |
| 单局 30–60 现实小时 | 自动体把微观操作压缩掉，把时长还给"观察与决策" |

### 6.3 留存钩子（上帝视角特有的爽点）

1. **"明天回来看看它长成什么样"**——离线期间文明自动生长，上线看到的是"你的文明自己走了多远"，比 v2 的"回来收链"更有期待感（对应 M05 离线收益 + 离线结算升级为"离线演化"）。
2. **编年史回放**——每次上线弹一条"你不在时，文明发生了什么"的缩略年表，制造"我错过了历史"的牵挂。
3. **里程碑演出**——目标达成/新纪元/探索发现的三层演出（M05）在 v3 里是主菜，因为"文明自己长出来的大事件"比"我点出来的大事件"更动人。

### 6.4 门槛与风险（见 §9）的核心：别做成"第二张电子表格"，也别做成"看动画挂机"

## 7. 与既有锚点的关系（保留 / 降级 / 新增）

### 7.1 原样保留（不可动摇的锚点）

- K 指数 = (log₁₀P−6)/10 唯一灵魂指标（00 §1）；
- EROI 硬约束（<3 不可持续、<1.5 立即崩塌）（00 §3）；
- 功率逐源追溯、无凭空功率铁律（00 §7）；
- 分层真实 P3、失败即内容 P4（01 §1）；
- DC1–DC10 全部裁决（03 §3）——特别是 DC2 决策型手动、DC6 能量投资计价、DC9 单局 8000 模拟年、DC10 工具卡清空/范式保留；
- 11 档功率阶梯与节奏目标（00 §2、§6）。

### 7.2 降级（从主玩法 → 引擎/表现）

- **节点供需网络（B 方案）**：从"主玩法交互层"降级为"**结算引擎 + 观察层 + 教学层**"（§5）。A 产线视觉化继续作为节点内部表现层，C 第一人称继续只在关键时刻做手感层（裁决的"一层主+两层辅"结构不变，只是"主"从图操作换成宏观指令）。
- **M01 八态状态机 / M02 科技树 / M04 因果链 / M05 资源流图**：全部保留为**自动体的内部机制与可视化**，玩家不再逐项操作，但系统照常运转。

### 7.3 新增（v3 独有）

- **文明自动体（autonomous agent）**：把宏观指令翻译为节点网络自我重组的引擎——这是 v3 唯一的新核心系统。
- **世界地图 / 星图 + 迷雾探索**：一等公民的探索层，早期大地图、末段星图。
- **文明意志槽 / 国策系统 / 支柱权重**：宏观交互的载体。
- **编年史回放与"离线演化"**：上帝视角的留存叙事层。

## 8. 演进计划（v3 MVP → Alpha → Beta）

> 遵循"反思文档 → 新文件夹"流程，v3 实现于 `原型\demo-v3\`（demo-v2 归档保留）。

### 8.1 v3-MVP（宏观指令 + 自动体 + 世界地图 + 观察下钻）

**范围**：
- 文明自动体内核：国策（4 条）→ 节点网络自动生成/重组（复用 v2 供需求解器）；
- 支柱权重分配（六段"文明血脉"条）→ 盈余流向六支柱 → 自动体定向扩张；
- 世界地图（迷雾 + 3 块可探索区域）+ 节点解剖图下钻（点地区看子图）；
- 1 个战略目标 + 1 次危机裁决（森林枯竭）+ 编年史缩略回放；
- 保留：K 刻度尺、EROI 仪表盘、能量投资计价、debug 工具。

**验证目标**：
1. 新玩家 10 分钟内"只靠定策 + 设标 + 调权重"让文明跨过 K0.1（不碰任何节点微调）。
2. 一条错误的国策在 30 秒内产生**可见后果**（图变红 / 地图出现枯萎）。
3. 玩家能复述"我的哪条指令导致了哪个结果"（因果可追溯 ≥80%）。
4. 求解器在 200 节点自动演化下 tick <5ms、无死锁。

### 8.2 v3-Alpha（全教学段 + 中段骨架，K0→0.6）

- 国策扩到 8–12 条、战略目标 6 个、六支柱完整化；
- 探索轴落地：探险队自动派出 + 探索方向决策 + 未知资源点/遗迹；

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| **做成"看动画挂机"**——指令下完就没得玩 | 权重分配是高频、可持续的微观张力；裁决关键时刻保证玩家必须在场；战略目标有完成窗口，超时失败 |
| **做成"第二张电子表格"**——宏观指令退化成改参数 | 7±2 信息铁律：国策≤3 条、支柱 6 段、每次只呈现 1 个焦点；每条指令必须在地图/图上长出**视觉后果**（图变红、迷雾推开、节点点亮），而非只改数字 |
| **失去 v2 的"规划爽感"** | 规划不消失，只是从"空间布局"迁移到"路线抉择 + 支柱配比 + 探索方向"；想微调仍可下钻节点图（可选深度） |
| **自动体演化无聊/失控** | 自动体受国策+目标强约束，演化结果**可预测可解释**；提供"暂停演化/单步演化"调试与硬核观察模式 |
| **上帝视角削弱代入感（离文明太远）** | 保留关键时刻的手感层（C 层：划火、首飞、抢险）作为"神降身"；编年史用具体个体的口吻写，拉近情感距离 |
| **实现成本** | 自动体 = 现有供需求解器上加一层"生成策略"，增量可控；地图/星图用 2D Canvas 迷雾，不碰 3D |

## 10. 一句话裁决（v3）

> **把《文明指数》从"你亲手搭一张文明血管图"重铸为"你给文明一颗心，看它自己长大、探索、崩溃、换血"——上帝视角的宏观引导取代微观建造，节点供需网络保留为文明的活体解剖图与科学教学的因果之眼，让 K 指数从"一根标尺"变成"一个你在远方眺望的、活着的文明。"**
