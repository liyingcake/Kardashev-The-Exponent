## ① 评审官总纲

### 1.1 本次评审的裁决对象

不是"要不要多资源"——那是用户已拍板的动因（要）。本次评审裁决的是**玩法逻辑的表现形式**：用什么交互骨架把"开采→提炼→发电→维持→盈余→科研→解锁→自动化"这条唯一主循环（00 文档 §4）变成玩家**看得见、摸得着、玩得动**的东西。

### 1.2 评审的一把尺子（锚定不变项）

重设计不得违反既有锚点。以下四项是本评审判断方案的**硬边界**：

1. **K 指数是唯一灵魂指标**（00 §1）：任何玩法必须让 P 的增长"可逐源追溯"，禁止凭空功率。
2. **EROI 是硬约束**（00 §3）：EROI<3 不可持续、<1.5 立即崩塌；EROI 必须是玩家**可感知的博弈量**，不是后台常数。
3. **增量挂机是骨架**（00 §6 + M05）：单局 30–60h、前 4 纪元 30–60 分钟快进、中段手动高峰、末段挂机+决策型手动、离线三重天花板防"上线即无敌"。新玩法**不能把骨架推翻**，只能把骨架"长肉"。
4. **分层真实 P3 + 失败即内容 P4**（01 §1）：战略层数值结算、手感层只深度模拟轨道+热力学、事件是因果链剧场。

### 1.3 我对三个方向的预判（评审假设）

评审基于对三方向共性规律的独立分析，**不预设 A/B/C 文档内容**，只针对"这种表现形式本身"打分。分析时假设各方案都能做到"打磨良好"的成熟形态，避免被实现草率与否干扰。

## ② 三种模式对比矩阵

> 计分：1–5。**实现成本**与**上手门槛**两格为"分越高越有利"（成本低/门槛低给高分），其余为"分越高越强"。

| 判据 | A 产线（DSP/异星工厂式） | B 节点式（UE Blueprint 式） | C 第一人称（MC 式） |
|---|---|---|---|
| **多资源表达** | **5** — 资源链+物流带+工厂是"多资源互动"的原生形态，供需直观。 | **4** — 供给/需求边天然承载多资源流，缺的是空间感但拓扑感更强。 | **4** — 背包/合成/方块是多资源的经典表达，但偏"物品"而非"流动"。 |
| **规划深度** | **5** — 吞吐配比、产线布局、物流规划是三类硬核规划纵深。 | **4** — 拓扑优化（改边、改节点、平衡供需）是实打实的规划，但无空间/布局维度。 | **3** — 空间建造规划强，但缺系统性因果纵深（多为单点组合）。 |
| **劳动力呈现** | **2** — 产线游戏无原生劳动力概念，需硬造"工人占用产线"规则。 | **3** — 劳动力可建模为"节点占用数/工人流"，与 M01 的 L_available 天然对接。 | **5** — 玩家第一人称就是劳动力，代入感最强，但无法表达"人口规模"。 |
| **科学教育契合度** | **3** — 能量平衡/电力网络可教 EROI，但传送带吞吐是纯数学，教育漏勺大。 | **5** — 能量流、EROI、卡诺效率、因果链全部"可视化"于图上——这正是 M04/M05 要的。 | **2** — 挖矿建房不教物理；靠 mod/科技改造才能碰 EROI，摩擦大。 |
| **实现成本（越高越省）** | **2** — 物流寻路+吞吐模拟+实体渲染，小团队 Web 端成本高企。 | **4** — 图模型最省：无寻路、无碰撞、无空间约束，纯数据结构+渲染层。 | **1** — 3D 第一人称引擎成本超出小团队上限（现项目还是浏览器 demo）。 |
| **与增量挂机融合** | **2** — 产线游戏是主动玩法，挂机违和（DSP 挂机≈停产，与 30–60h 骨架冲突）。 | **4** — 节点图可自动平衡，"闭合回路=自动化=挂机"，挂机是图的自然状态。 | **1** — 第一人称无法挂机；离线收益无从谈起（人不在就没有世界）。 |
| **上手门槛（越高越易）** | **3** — 皮带概念 30 秒懂，但"最优布局"深水区极深，教学段易劝退。 | **4** — 连线即懂、改边即改逻辑，比皮带更接近"直觉因果"。 | **3** — 全民认知度最高，但 3D 操作/视角/移动本身是门槛，且与挂机相悖。 |
| **"文明 8000 年跨度"叙事契合** | **2** — 产线是"一个持续运转的工业殖民地"，纪元重置/Prestige 与固定工厂强冲突。 | **4** — 纪元=图模板换代，"科技忘了、范式长进"（DC10）天然映射为"节点模板换代+边结构重置"。 | **2** — 第一人称身体在场感与"万年跨度"互为悖论；建巨构=另一款 MC。 |
| **合计** | **24** | **32** | **21** |

**一句话读表**：A 强在"深度"但贵且反挂机；C 强在"代入"但最贵且反挂机反叙事；**B 是唯一在"成本可控 × 挂机兼容 × 科学可视 × 8000 年叙事"四象限同时高分**的方案。

## ③ 推荐与理由

### 3.1 裁决

> **主玩法选 B：节点式供需网络（Blueprint 式节点编辑器）**，融合 A 的产线视觉化为"节点内部表现层"，保留 C 的第一人称"手感层"仅在轨道/殖民地关键时刻（即既有 M03 的手感层定位，绝不扩展为全程 3D 第一人称）。

### 3.2 理由（逐条对照用户要求）

**(a) 多资源互动深度 —— 通过"图"而非"地图"实现**
M01 §3.4 的五层资源链（生物质/矿物/金属/能源载体/高级材料）本就是**节点网络**的教科书结构（示例：铁矿→高炉→生铁→转炉→钢→合金）。节点式把它从纸面公式变成可玩对象：每个资源是节点，每条转化是带损耗的边，供需差由求解器逐 tick 平衡。多资源互动不是"三个数字相乘"，而是"改一条边，整条链连锁反应"——这正是用户要的"互动、规划、开采、供需关系"。

**(b) EROI 与科学教育 —— 图上每个数字都是科学卡片入口**
- EROI 在节点式里是"每个能源节点的净输出标签"，EROI<3 时节点**变色闪烁**、<1.5 时节点崩坏触发 M04 危机——EROI 从"后台常数"变成"玩家天天盯的博弈量"。
- M04 因果链事件（峰值石油：轻质原油枯竭→油价×3→运输成本↑→通胀→科研收缩→功率−20~40%）**本身就是一张节点图**。事件=图上覆盖一层高亮链，玩家在"节点的世界"里看危机在"图上蔓延"——这是 M04 §3.2 数据结构的原生呈现，零改造。
- M05 §3.B.3 的"因果链可视化、火花沿箭头流动"需求直接命中：节点图就是那个 UI。科学教育从"弹出卡片"升级为"卡片弹在你要的东西上"。
- 卡诺效率/散热（M01 §3.2.1）同理：蒸汽机节点显示"卡诺极限 η=32%、当前 28%"，选高热源=改节点的温度参数。教育是玩法的副产品。

**(c) 实现成本可控（小团队）—— 图模型是三种方案里最便宜且最贴合现技术栈**
- 现 demo 是纯浏览器 HTML/JS/CSS + Canvas（无引擎、无构建）。节点式 = 状态表 + 边表 + 逐 tick 流平衡求解器 + DOM/Canvas 渲染层。**无寻路、无碰撞、无 3D、无实体模拟**，唯一新增的核心算法是"供需平衡求解"（比 DSP 的物流吞吐模拟低一个量级）。
- M01 的 8 态状态机（S1 开采→S2 提炼→…→S8 自动化）可以直接映射为**节点类型**：开采节点、提炼节点、发电节点、维持节点、科研节点、自动化开关——状态机变成节点模板库，不是重写而是落地。
- 规划测算：节点编辑器内核（拖拽/连线/平衡/存档）约等于现 demo 代码量的 2–3 倍，而产线方案是其 10 倍以上。

**(d) 保留增量挂机的爽感 —— 挂机就是图的"自动平衡态"**
- 增量爽感的来源是"大数字 + 自动成长"。节点式下：玩家搭好一条链→链自动跑→盈余转正→科研节点自动累积→解锁新节点模板→搭更大链。**闭环闭合=自动化=挂机**，与 M05 自动化节奏（畜力自动灌溉→水车水力→蒸汽产线→电气→AI）逐一对应。
- 手动火花（M05 §3.A.3）可以具象为"手拖一条边""手点一个溢出节点"——手动操作的**单位**从"点按钮"变成"调图"，操作感不降反升。
- 离线收益三重天花板（24h/效率衰减/按离线时刻结算）全部保留：离线快照里多存一张"节点+边状态表"，结算仍是逐 tick 跑图。

**(e) 与 K 指数灵魂指标契合 —— 图是功率守恒的**物理容器**
- 铁律"文明不能凭空造功率"在图上**自动成立且可见**：P_total = 图上所有发电节点净输出之和，玩家看着图就知道"功率从哪来"。违反铁律的乘数（文明特质只能作用于分配型系数，M01 §4.1 契约）在图上一眼可见——特质改的是"边损耗"，不是"凭空造节点"。
- K 每 0.1 一格 = 图的一次"换代"：节点模板集、边损耗参数、可解锁边类型整体升级。纪元演出（M02 §3.1.2）的"接管/交接"就是"旧图风化、新图点亮"——8000 年跨度在图上表现为**图本身在长大**：从火种部落的 4 节点小图，到戴森云阶段的行星-轨道双层超图。
- 散热悖论（K0.8+ 瓶颈）在图上有完美表达：每个发电节点带散热子节点，散热子节点上限=面积（斯特藩-玻尔兹曼），戴森云=把散热节点"甩到太空中加面积"——面积竞赛变成图上的拓扑竞赛。

### 3.3 对 B 的两个公认弱点，给出缓解

| B 的弱点 | 缓解 |
|---|---|
| 缺乏"空间/布局"深度（相比 A 的产线布局） | 不硬造空间；把"空间"迁移到**图的层级结构**（星域→行星→城市→街区，每层一张子图），规划纵深从"布局"换成"架构"。M03 的轨道层/殖民地层天然提供空间纵深感 |
| 节点图可能被做成"第二张电子表格" | M05 §3.B.4 的 7±2 信息铁律 + 图默认只显示主链、细节折叠进节点详情；主界面永远是"一根功率标尺 + 一张活图" |

## ④ 融合方案

### 4.1 融合结构（一层主 + 两层辅）

```
主玩法（B）节点式供需网络
   ├── 表现层（A 产线视觉化）——节点内部的"工厂特写"
   └── 手感层（C 第一人称氛围）——轨道/殖民地关键时刻的"在场感"
```

### 4.2 各层职责与接口

**层 1 · 主玩法：节点式供需网络（B）**
- 承担全部战略结算。玩家在"文明图"上放节点、连线、设配比、看供需差、调自动化。
- 数据模型：`node = {类型(采集/提炼/发电/维持/科研/仓储/自动化), 输入边[], 输出边[], 劳动力占用, 能耗, EROI, 储量}`；`edge = {从→至, 载量, 损耗率}`。逐 tick 求解：沿图做流平衡（有向无环为主，允许环路但环路必须消耗能量——闭环即自动化）。
- 接口：向 M01 输出 P/S/R 结算量；向 M02 输出科技解锁=新节点模板/新边类型；向 M04 提供"危机在图上的传播路径"；向 M05 提供"图→渲染层的节点/边状态快照"。

**层 2 · 辅表现：产线视觉化（A）**
- 作用：把"图上的每个节点"从方框变成**微型工厂特写**——节点点开是 DSP 式小产线/异星工厂式的小生产格（原料滑槽、机器、输出口、吞吐数字），节点的供需差=产线的"红灯/绿灯"。
- 定位：**纯表现层，零结算**。产线动画不参与数值（遵守 P3：表现层艺术化）。节点详情是"科学卡 + 微型产线动画"的组合，教学时看细节、玩战略时收起来。
- 好处：用最小的 2D 成本拿到"异星工厂的爽感"（视觉上丰饶、机器在动），同时避开 A 的物流模拟成本。这是**成本/爽感比值最高**的偷法。

**层 3 · 辅手感：第一人称氛围（C，仅关键时刻）**
- 作用：MC 式"在场感"只保留在**少数手动关键时刻**——火种开局"捡第一根柴、划第一下火"、轨道首飞（M03 轨道层）、殖民地抢险（M03 热力学层）。这些时刻用**第一人称视角的 2D/伪 3D 场景**（现 demo 已有 Canvas 场景层，直接增强为可交互场景）。
- 定位：**不建真 3D 引擎、不做开放世界**。它是 M03 手感层的"皮"，手感层的"核"（轨道平面拖拽、殖民地网格建造）保持不变。玩家平时的角色是"俯瞰文明图的指挥者"，关键时刻"落下去亲手推一把"（呼应 DC2 决策型手动 + M05 手动火花）。
- 红线：全程第一人称被否决——与挂机骨架冲突（玩家下线=文明停止）、成本超限、8000 年跨度叙事无法承载。C 只做"手感调味料"。

### 4.3 融合后的信息流示例（一局的关键一刻）

火种开局 → 主界面是一张 4 节点小图（柴薪采集→篝火→部落维持→原始科研）→ 玩家点篝火节点，弹出"科学卡+微型柴火动画（层 2）" → 采集节点快满负荷，提示"可用劳动力不足" → 玩家点"围猎协作"科技解锁新节点模板 → 按下"首座窑炉"时触发一次 10 秒的"第一人称划火"小场景（层 3）→ 之后回到图。

## ⑤ 玩法重塑后的核心循环

### 5.1 循环总览（一句话）

**开图 → 补链 → 闭合 → 换代**：玩家在文明图上不断"补上缺口、闭合回路、自动化，然后在纪元更替时看着图整体换代"。

### 5.2 文字版完整流程

**① 开局（K0.0 火种，0–10 分钟）**
- 一张 4 节点小图：`柴薪采集 → 篝火(发电) → 部落(维持) → 原始知识(科研)`。
- 教学：前三个节点由引导任务带建（"点柴薪节点→拉一条边到篝火"），首个手动"划火"小场景（层 3）。玩家学会三件事：节点=做什么、边=资源流向哪、供需差=图上的红绿。P 开始自涨，K 刻度尺动起来。

**② 首节点/首设施（K0.0→0.1）**
- 玩家亲手建第一个**自主决策节点**：在"农田"与"畜力"之间选（农耕纪元首次稀缺取舍，M02 §3.1.3）。每建一个节点=花能量（DC6 能量投资计价）→ 节点点亮 → P 跳升。
- 验证时刻：首座节点落成的"小里程碑"演出（M05 三层里程碑）。

**③ 首条链（K0.1→0.2）**
- 目标：从"单节点"到"完整链"：`伐木场 → 炭窑 → 冶炼坊(铜) → 工具 → 采集效率↑`。玩家第一次理解"损耗"：边上的损耗率让"中间产物"变少，M01 §3.4 的金属链变成玩家亲手搭的东西。
- 首次"供需失衡"教学：炭窑吃薪柴太快，柴薪边变红——玩家学会看**供给边**，学会**扩容节点 vs 加边**的权衡。

**④ 首自动化（K0.2→0.4，前 4 纪元 30–60 分钟收尾）**
- 劳动力上限（M01 公式 6）首次卡住扩张：所有节点都占劳动力，新链没手建。→ 触发"自动化"教学（M01 §3.1.3 规则 D）：把采集节点切换为自动化（+10~30% 功耗换劳动力归零）——**首个闭环回路**形成，玩家第一次体验"闭合=解放"。
- 里程碑：首条闭环的演出 + "首环闭合"成就。教学段以"玩家能独立搭出 3 条并行链"为达标。

**⑤ 首危机（K0.3–0.4，森林枯竭/小冰期）**
- M04 事件以**图上高亮因果链**登场：森林节点储量红线 → 边变红 → EROI 标签从 12 掉到 8 → 盈余变负 → 科研节点熄灯。玩家在"延迟窗口"内选择：转型（换水车边）或续命（加大伐木，边损耗更高）。
- 教育点：玩家**看着危机在图上蔓延**，记住"EROI 不是数字是命"。失败即内容（P4）：首次失败免费回退，知识保留。

**⑥ 首次更替（Prestige，K0.4 教学段终点）**
- 图进入"换代演出"：旧图风化褪色（M02 进入/离开时刻）→ 文明印记结算 → 特质 3 选 1（M02 §3.4.2，只改分配型系数：损耗−10%、劳动力+15% 之类）→ 新纪元图模板点亮（蒸汽机节点、煤矿节点、高炉节点）。
- 玩家理解：**图会变，但"我对图的理解"和"文明的性格"留下来**——"科技忘了，文明长进了"（DC10）。

**⑦ 中段瓶颈（K0.4→0.7，手动高峰 1–3 小时/纪元）**
- 瓶颈迁移链逐条登场：土地劳动力→燃料资金→储能电网。图上表现为：某类边/节点**系统性变贵或变红**（煤的枯竭曲线、油的峰值危机、间歇源的储能惩罚）。
- 电网纪元的关键决策=**网络拓扑抉择**（M02 纪元专属机制）：集中式（一个巨型发电节点+高压边，省维护但单点风险）vs 分布式（多个小节点，灵活但损耗高）。这是节点式**独有的玩法纵深**——拓扑规划。
- 殖民地/轨道手感层（层 3 + M03）在此段作为"物理课"插入（K0.5–0.7 教学必需，DC3）。

**⑧ 末段太空/戴森云（K0.7→1.0，挂机+决策型手动）**
- 图长成"行星-轨道双层超图"：地上图（电站/工业/生活）+ 轨道图（太阳能卫星、拉格朗日站）。跨层边=微波输电、轨道物流，带传输损耗。
- 决策型手动（DC2）：3–5 分钟一次轨道决策（新卫星放哪、L1 还是 SSO、发射窗口），其余全挂机。离线收益按"双层图快照"结算。
- 散热瓶颈（K0.8+）：发电节点的散热子节点顶到上限 → 玩家把散热面积"甩到太空" → 戴森云=轨道层无限扩散热/收集面积 → 面积竞赛成为终局博弈。
- 通关：K=1.0 达标 30 分钟（M02 §3.4.4 奇点演出，数字失控演出保留）→ 二周目"戴森球相位"彩蛋。
