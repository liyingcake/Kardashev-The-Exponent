# 文明指数 · demo-v5（节点窗口 × 通配符 × 策略权重）

> 双击 `index.html` 即玩（Ctrl+F5 强刷清缓存）。存档键 `exponent-demo-v5`。

## 一句话

节点是**窗口**，资源是**带标签的抽象流**，规则是**通配符**，参数是**策略权重**。你拧每一个窗口的旋钮，就是在设计文明如何对抗熵增。

## 核心抽象

- **流（Stream）**：`domain:stage`，如 `matter:raw`（物质·原料）、`energy:useful`（能量·有用）。
- **通配符（Wildcard）**：`*` 任意 / `matter:*` 任意物质 / `*:raw` 任意原料 / `energy:useful` 精确。
- **节点窗口**：五类（采集/加工/路由/消费/收集），每个窗口有"输入/输出通配符选择器 + 策略权重滑块"。
- **能量利用 = 逆熵**：加工窗口把低阶流（raw）逆熵为高阶流（useful），必然产生废热（熵增），EROI = 逆熵效率。

## 怎么玩

1. 开局已有 采集 → 加工 → 消费 → 收集 四个窗口，逆熵链自动跑。
2. **点左侧"加工窗口"** → 展开配置面板 → **拖"逆熵效率 vs 吞吐规模"权重**，看 EROI 与废热变化。
3. **改通配符**：把加工窗口的输入从 `*:raw` 改成 `energy:raw`，它就不再吃物质原料、只吃能量原料。
4. **新建加工窗口**（左栏金按钮），配不同通配符 = 不同"工艺"。
5. 看右侧"逆熵链"理解流的方向；看中栏"抽象流库存"看哪些流在动。

## 主题

> **文明 = 局部的低熵体。K 指数 = 文明把无序能量转化为有序结构（逆熵）的速率。**
> 呼应 Upload Labs 的"拯救宇宙免于热寂（heat death）"。
