# 文明指数 · demo-v6（可视化节点编辑器）

> 双击 `index.html` 即玩（Ctrl+F5 强刷清缓存）。存档键 `exponent-demo-v6`。

## 一句话

把 v5 的抽象引擎，用**人类审美的可视化节点编辑器**呈现：中间是演示图（窗口式节点 + 连线），下面是节点操作窗口。

## 布局

```
顶部：K 尺 + 文明状态
├─ 左栏：状态 + 新建窗口 + 国策 + 科技 + 里程碑
├─ 中栏：演示图（窗口式节点画布）
│         └─ 节点操作窗口（选中节点后出现）
└─ 右栏：流动中的流 + 逆熵链 + 通配符图例
```

## 怎么玩

1. 看中间**演示图**：四个窗口式节点（⛏️采集 → 🔥加工 → 🏘️消费 → 🗃️收集），彩色连线表示流。
2. **点一个节点**（如 🔥加工窗口）→ 下面出现**操作窗口**。
3. 在操作窗口里：改「吃什么/产什么」、拖「逆熵效率 vs 吞吐规模」权重，看节点 EROI 从黄变绿、或从黄变红。
4. 左栏「＋ 加工窗口」新建窗口，它会自动接到链上。

## 核心对照

| 你的要求 | v6 实现 |
|---|---|
| 可视化节点内置窗口 | 节点 = 窗口式矩形：标题栏（色块+图标+名）+ 数据 + 输入/输出端口 |
| 中间演示图 | 中栏 Canvas 画布：节点 + 贝塞尔连线 + 状态着色 |
| 下面操作窗口 | 底部 `ops-panel`：通配符选择 + 权重滑块 + EROI/废热 |
| 符合人类审美/习惯 | 节点编辑器范式（蓝图/流程图），中文+图标，裸标签全部翻译成人话 |

## 文件

| 文件 | 职责 |
|---|---|
| `data.js` | 复用 v5（引擎数据不变） |
| `game.js` | 引擎复用 v5 + 节点自动布局 + 人类可读命名 + 底部操作窗口 |
| `graph.js` | 演示图：窗口式节点 + 连线 + 状态着色 |
| `index.html` / `style.css` | 中间演示图 + 下面操作窗口布局 |

## 说明（MVP 简化）

- 节点是自动布局，未做拖拽（Alpha 补）；
- 连线是"按逆熵链推断"的，未开放手动连线（Alpha 评估）；
- 数值沿用 v5 [软数据]，节奏靠试玩反馈校准。
