# 《文明指数》demo-v2（节点供需网络重构版）

> 打开：双击 `index.html`（纯浏览器）。设计依据：《00_反思与v2设计.md》。
> 相对 v1 的改动：**UI 精简、玩法三轴（放/连/升级）、数值重调、引导任务**。

## v2 三大改动

### 1. UI 精简（v1 13 区块 → v2 主次分层）
- **中央**：节点图成为唯一主画面（760×560 全高），下方一条 EROI/供给状态条
- **左栏 230px**：状态 + 资源 + 里程碑卡 + 任务 + 科技（列表压缩为小项）
- **右栏 300px**：上下文面板（默认提示/节点库；选中节点→详情），按需出现
- 事件改**顶部横幅弹入**；日志/调试改**折叠悬浮块**（不占正文）
- 移除：场景 Canvas 缩略（节点图即画面）、常驻大调试面板

### 2. 玩法三轴（替代"重复放节点"）
- **广度**：放置新节点（节点库 → 画布幽灵放置）
- **连线**：点源 → 可连目标亮绿 → 点目标（Esc 取消 / 右键断开）
- **深度**：**升级节点**（Lv1→8，每级 +50%，成本 ×1.5）——成长感来自"养大节点"
- **节点框标准**（画布内 128×76，4 行）：①图标+名称+状态徽标 ②核心数据 ③输入/输出端口 ④工人+等级

### 3. 数值重调（修复 v1 失效项）
| 项 | v2 值 | 修了什么 |
|---|---|---|
| 初始能量池 | 10,000 J（种子资金） | 破解初始死锁 |
| 初始模板 | 森林×2 预置＋篝火自动 1 工人 | 开局即增长 |
| 放置成本 | `500×(1+0.1×节点数)` | 不再绑定 P，有相对成长感 |
| 能量池上限 | 50,000 J | 逼玩家花能量建节点 |
| 人口/工人 | 人口=`P^0.5×50`，工人=人口/50 | 前期充裕、中期紧张 |
| 科研 | 基础 `P/2e4`＋研究院 | 科研成为中期瓶颈 |
| **EROI** | 篝火≈6.7/水车≈20/蒸汽≈3.3/工厂≈2.5 | **黄/红状态真实出现**（教育时刻） |
| 任务奖励 | 5 步引导任务（+5k~10k J） | 新手路径 |

## 引导任务（右侧面板可见）
1. 搭建第一条链 → 2. 雇佣工人 → 3. 观察 EROI → 4. 升级节点 → 5. 研究控火术

- 事件按里程碑触发（3 个森林→森林枯竭、进入农耕→小冰期、2 水车→洪水）
