# 《文明指数》demo v1 反思与 v2 重构设计 v0.1

> 日期：2026-08-12 ｜ 对象：`原型\demo\`（节点-lite MVP v1）
> 结论：v1 思路正确（节点图供需网络），但 **UI 臃肿、玩法缺少引导与深度、数值多处失效**——不可玩。本文档诊断问题并定义 v2 标准（节点框规范、玩法循环、数值表），v2 实现于 `原型\demo-v2\`。

---

## 1. UI 反思：臃肿在哪

### 1.1 v1 布局结构（问题：13 个区块全常驻）

```
Header: 标题 + K尺
├─ 左栏(320px)：文明状态(7行) + 资源库存(5条) + 节点库(11按钮) + 科技树(8项)
├─ 中栏：场景Canvas(150px) + 节点图(680×420) + 仪表盘(3框) + 事件面板 + 日志(60条)
└─ 右栏(300px)：知识库(长文) + 节点信息 + 调试(6按钮)
```

### 1.2 问题清单

| # | 问题 | 根因 |
|---|---|---|
| U1 | 一屏 13 区块，中栏需滚动 2 屏 | 无主次分层，所有模块默认常驻 |
| U2 | 双列表操作：节点库 + 科技树两个长列表抢注意力 | 放置与科研混在同一栏，决策载荷过重 |
| U3 | 数字无主次：功率/能量/科研/人口/工人/EROI/燃料 7 组数字同权重 | 未定义"一眼数字"（P/K）与"次看数字" |
| U4 | 场景 Canvas 缩到 150px 后沦为装饰，信息量为零 | 为"有画面"而保留，无玩法耦合 |
| U5 | 事件面板 + 日志 + 仪表盘同在中栏，异常事件视觉权重不足 | 事件应"弹出"而非"内嵌" |
| U6 | 节点信息放在右栏常驻，选中才变——空闲时浪费 300px | 上下文面板应"需要才出现" |
| U7 | 调试工具 6 按钮常驻 | 开发期杂物混入正式 UI |

### 1.3 结论

v1 试图"什么都展示"，结果"什么都看不清"。**v2 原则：单一主画面（节点图）+ 极简侧栏 + 上下文面板按需出现 + 事件横幅弹入**。

## 2. 玩法反思：缺少什么

| # | 问题 | 具体表现 |
|---|---|---|
| P1 | 初始死锁 | 开局 P=0 → 能量池 0 → 放不了节点；篝火需 1 工人但玩家不知道要雇工 |
| P2 | 无引导 | 新手不知道"节点要连线才工作"、"要雇工"、"要等库存" |
| P3 | 连线交互不可见 | 单击进入连线候选态无任何提示，玩家不知道当前状态 |
| P4 | 无深度轴 | 变强只能"再放一个同样的节点"——重复劳动，无升级/改造 |
| P5 | 单目标感弱 | 只有顶部 K 尺，无"下一步做什么"的指引 |
| P6 | 事件随机且无准备 | 随机时间触发，与玩家扩张状态无关 |
| P7 | 无节奏控制 | 无挂机/离线，纯在线，挂机玩家流失 |

## 3. 数值反思：哪里失效（具体算账）

| # | 项 | v1 数值 | 问题 |
|---|---|---|---|
| N1 | 科研速率 | `max(0.5, P/2000)` | P=1e8 时 5e4/s vs 科技成本≤6000 → 永远秒购，科研非瓶颈 |
| N2 | EROI 仪表盘 | wood equiv=1e4 → 篝火 EROI≈20 | 所有能源恒绿，黄/红状态永远不出现 → 仪表盘无戏剧性、无教学时刻 |
| N3 | 放置成本 | `500 + P×3` | 永远等于 15 秒产出，无相对成长感；且与能量池耦合混乱 |
| N4 | 工人颗粒 | `可用=pop/200`，保底 3 | 前期够用、中期糙（200 人才多 1 人），无紧张感 |
| N5 | 人口公式 | `P^0.6×100` | P=1e5→158 人，与"部落"叙事略符但无反馈价值 |
| N6 | 能量池 | 无上限 | 可无限囤积，无"储能瓶颈"设计空间 |
| N7 | 功率梯度 | 篝火 1e5→水车 1e6→蒸汽 2e7→工厂 5e8 | 第 0 纪元（目标 1e7）需 ~10 个篝火，重复劳动 |
| N8 | 源/耗平衡 | 森林产 0.6/s、篝火耗 0.5/s、库存 20 | 单森林勉强养 1 篝火，容量 20≈33 秒缓冲，节奏单调 |

## 4. v2 节点框标准（核心规范）

> 用户要求：设计好节点框的标准和结构，里面有多个元素。

### 4.1 节点框结构（画布内，128×76 固定）

```
┌───────────────────────────────┐
│  🌲 森林        [● 运行/⚠/🔌] │  ← 行1：图标+名称+状态徽标
│  📦 库存 12/20  ▼产出 0.6/s   │  ← 行2：核心数据（按类型不同）
│  ⬅ 输入端口       输出端口 ➡  │  ← 行3：端口（可视"插座"）
│  👷 2/3 · Lv3  [升级按钮]      │  ← 行4：工人+等级+升级（能源/源节点）
└───────────────────────────────┘
```

**元素规范**：
- **标题行**：图标(22px) + 名称 + 右上角状态徽标（● 绿=运行 / ⚠ 橙=缺料 / 🔌 灰=未连线 / 👷 蓝=缺工人）
- **数据行**（按 cat 显示）：
  - source：`库存 x/cap ｜ 产出 r/s`
  - work：`输入 in/s → 输出 out/s`
  - energy：`⚡ 功率 ｜ 耗燃料 r/s`
  - research：`🔬 rps/s ｜ 耗 ⚡`
- **端口行**：左右各一个圆点端口（in=左蓝、out=右绿），选中时发光
- **工人/等级行**：`👷 n/t`（橙=未满）+ `Lv x`（可升级节点）+ 升级所需能量
- **分类色**：source 绿 #2f8f4f / work 琥珀 #b39a3a / energy 红 #c84848 / research 紫 #8f6fd8；未连线整体降饱和

### 4.2 交互规范

- **选中**：描边高亮 + 右侧上下文面板展开（详情/雇工/升级/科学卡/断开）
- **连线**：点源节点 → 输出端口发光 + 全图可连目标高亮（绿描边）→ 点目标完成；Esc 取消；连线=贝塞尔曲线+流向箭头，缺料变红
- **放置**：右侧"＋添加"弹出节点网格菜单（分类分组、锁定显示解锁条件）→ 选中后幽灵跟随 → 点击放置
- **状态颜色全图一致**：绿=OK / 橙=缺料 / 红=崩塌 / 蓝=缺工人 / 灰=未连线

## 5. v2 玩法与数值设计

### 5.1 玩法三轴（替代"重复放节点"）

1. **广度**：放置新节点（规划位置、解锁新链）
2. **连线**：供需关系（物流拓扑，缺料→瓶颈→重连）
3. **深度**：**升级节点**（Lv1→5，每级 +50% 产出/功率，成本 ×1.5^Lv）——成长感来自"养大一个节点"而非"放第十个篝火"

### 5.2 核心数值表（v2 草案 [软数据]）

| 参数 | v2 值 | 修正逻辑 |
|---|---|---|
| 初始能量池 | 10,000 J | 种子资金，破解死锁（P1） |
| 初始模板 | 森林×2 + 篝火×1（自动 1 工人） | 开局即有产出与增长演示 |
| 放置成本 | `500 × (1 + 0.1×节点数)` | 随规模微涨，不再绑定 P（N3） |
| 能量池上限 | 50,000 J | 逼玩家花能量建节点而非囤积（N6） |
| 能量池充能 | P×0.3/s | 前期可玩 |
| 工人 | 可用 = 人口/50（取整）；人口 = `P^0.5×50` | P=1e5→500人→10 工人起步充裕；P=1e7→5000人→100 工人，中期紧张（N4/N5） |
| 节点功率梯度 | 篝火 1e5 / 水车 1e6 / 蒸汽 2e7 / 工厂 5e8（升级 ×1.5^Lv） | 第 0 纪元 1e7 门槛 = 1 篝火升级到 Lv4 或 2-3 个混合（N7） |
| 燃料消耗 | 篝火 wood 0.5/s、水车 water 0.5/s、蒸汽 wood 2/s、工厂 wood 4/s | 蒸汽耗料高体现低 EROI（教学） |
| 库存上限 | wood/food/water 30，ore/metal 10 | 更长缓冲、更明显的满仓堵塞 |
| 源产出 | 森林 1.2/s、麦田 1.0/s、矿脉 0.6/s、河流 1.2/s | 供 2 个篝火有余 → 玩家可扩张 |
| **EROI 口径** | 篝火≈6.7（绿）、水车≈20（绿）、蒸汽≈3.3（黄临界）、工厂≈2.5（黄/红） | **黄/红状态真实出现**（N2 修复）——wood equiv=3e4、water equiv=5e4 |
| 科研速率 | 基础 `P/2e4` + Σ研究院节点 | P=1e5→5/s 起步；P=1e7→500/s；成本 100×10^(0.15n)（40→71→126…）→ **科研成为中期瓶颈**（N1 修复） |
| 事件触发 | 里程碑（首次建第 n 节点/达 K 门槛）+ 时间双轨 | 玩家有准备窗口（P6） |

### 5.3 引导与目标

- **任务清单**（开局 3 步，每步奖励能量）：① 放置一个森林并连到篝火 → ② 给篝火雇满工人 → ③ 观察 EROI 仪表盘变化
- **里程碑卡**（侧栏常驻）：当前目标「功率达到 1e7 W → 进入农耕纪元，解锁 水车/麦田/研究院」+ 进度条
- **事件横幅**：顶部滑入，不占正文空间（U5）

### 5.4 v2 布局（解决 U1-U7）

```
Header: 标题 + K尺（唯一常驻大数字）
├─ 左栏(220px)：状态精简(纪元/功率/能量/科研/工人) + 资源条 + 里程碑卡
├─ 中央(主画面)：节点图(全高) + 底部单行供给/EROI 状态条
└─ 右栏(280px)：按需——「＋添加」节点菜单 / 选中节点详情 / 隐藏时留白
事件横幅：顶部弹入 ｜ 日志：左下角可折叠 ｜ 调试：折叠进「⚙」图标
```
