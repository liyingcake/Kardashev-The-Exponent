# 《文明指数》教学段垂直切片（可玩原型）

> 目录：`原型\demo\` ｜ 打开方式：**双击 `index.html`**（纯浏览器运行，无需服务器/构建）

## 怎么玩（5 分钟上手）

1. **功率自动增长**（每秒 ×），左上角显示 K 指数与功率 P
2. **买科技**（中间列）：点击科技卡，消耗科研点 → 提升增长率 / 解锁新能源
3. **扩建设施**（左下）：花能量（功率×秒）→ 功率跳升 +15~20%
4. **切能源**（左中）：不同能源增长率不同（薪柴→畜力→水车→风帆→水力→蒸汽）
5. **应对事件**：森林枯竭 / 小冰期 / 洪水毁坝——因果链 + 双选项
6. **纪元更替**：P 达标后点「纪元更替」→ 演出 → 3 选 1 文明特质（永久乘数）
7. **科学卡**：点任意能源/科技/特质，弹出真实公式、常数与来源
8. 进度自动保存（localStorage）；**双击标题可重置**
9. **调试工具**（左栏底部，开发用）：
   - 💾 保存：立即写入存档
   - 📤 导出存档：复制完整存档 JSON 到剪贴板（调试/备份）
   - 📥 导入存档：粘贴 JSON 恢复任意进度
   - ♻️ 完整重置：清除存档并刷新重开
   - ⚡ +能量 / 🧪 +科研：调试作弊按钮（快速推进验证）

## 覆盖范围

- 教学段 5 档：火种(0.0) → 农耕(0.1) → 青铜·铁器(0.2) → 前工业(0.3) → 早期工业(0.4)

## 数值口径

- 增长率模型：`growth = 基础0.002 + 能源 + 科技 + 特质`（每秒）
- 能量：`dE = P × 0.2 × dt`（20% 产出进储备）
- 科研：`dR = P / 1e5 × dt`
- 建筑成本 = `P × 秒数`（DC6 能量投资计价）
- 纪元门槛 = `10^(6+era)`（与原型模型一致）
- **推断数值标注**：来自聪明的大赢鲸的思考与认知（[软数据]）；已核实数据在科学卡内标注来源
