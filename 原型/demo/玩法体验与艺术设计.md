# 《文明指数》玩法体验与艺术设计规范 v0.1

> 适用范围：教学段垂直切片（`原型\demo\`）｜ 日期：2026-08-12
> 本文档同时是 demo 的**交互规范**与**视觉规范**，后续开发（阶段 2+）照此执行。

---

## 1. 交互体验规范（含闪烁问题根因与修复）

### 1.1 已修复的缺陷：按钮悬停闪烁 / 难点击

- **根因诊断（代码审查）**：`game.js` 原 `tick()` 每 100ms 调用一次全量 `render()`，每次用 `innerHTML` 重建能源/建筑/科技列表的全部按钮。鼠标悬停时按钮被销毁重建 → hover 状态丢失 → 视觉上不断闪烁；点击时按钮在 mousedown/up 之间被替换 → 点击丢失 →"难按下去"。
- **修复规范（本切片已实施）**：
  - **R1 数值刷新与结构渲染分离**：`tick` 只更新数值节点（`textContent`）与局部样式（`classList`），**不重建 DOM 结构**；列表结构仅在状态变化时重建（购买科技 / 切换能源 / 建造 / 事件 / 纪元更替）。
  - **R2 科技可购状态局部刷新**：科技项 DOM 缓存引用，`tick` 时只更新 flag 文本与成本颜色，不重建。
  - **R3 主循环节流**：渲染与计算节流到 100ms，交互事件（hover/click）不再被重建打断。

### 1.2 悬停 Tooltip 规范（本次新增）

- **触发**：鼠标悬停 150ms 后显示（防误触抖动）。
- **内容**：`data-tip` 提供——科学卡正文 + 关键标签（增长率 / 成本 / EROI / 解锁条件）。如能源卡：`s.card.body + '｜ 增长率 +x%/s'`。
- **行为**：跟随鼠标（+12px 偏移，不遮挡指针），移出隐藏；可点进弹出完整科学卡（点击行为保留）。
- **视觉**：半透明深底、1px 亮边框、圆角、z-index 高于一切；文本 12px、行高 1.6。

### 1.3 按钮状态规范

| 状态 | 视觉 | 触发 |
|---|---|---|
| default | 深蓝底、细边框 | — |
| hover | 背景提亮 + 边框变亮，`transition:all .15s` | 悬停 |
| active | 更亮 + 微缩放 | 按下 |
| disabled | 35% 透明度 + `cursor:not-allowed` | 不可用（未解锁/能量不足） |
| locked | 🔒 前缀 + 解锁条件文本 | 未来纪元/需前置 |

- **铁律**：任何状态切换不得触发 DOM 重建；hover 期间结构保持稳定。
- **反馈**：购买/建造/切换成功 → 日志 + 数值跳动；失败 → 日志原因 + 短暂抖动提示（可选）。

## 2. 视觉体验设计

> 人类是视觉生物——主界面必须是"看得见的文明"，而不是一屏数字。

### 2.1 整体风格：暗色太空基调 × 文明暖色演进

- 底色：深空蓝黑渐变 + 星点（背景保留）。
- **文明主色随纪元演进**（暖色从低到高，象征"文明之火"升温）：

| 纪元 | 主色 | 意象 |
|---|---|---|
| 火种 | 橙红 #ff7a3d | 篝火、洞穴 |
| 农耕 | 金黄 #e8c05a | 麦田、黎明 |
| 青铜·铁器 | 铜棕 #d08a3e | 熔炉、城邦 |
| 前工业 | 青蓝 #53d8ff | 海洋、风帆 |
| 早期工业 | 赤红 #ff5d5d | 蒸汽、火光 |

### 2.2 主画面场景（本次新增，中间主屏）

**布局**：三栏中央为主画面（Canvas 16:9），左=数值面板，右=知识库。主画面是"文明之窗"。

**每纪元视觉主题**（场景元素随纪元切换）：

| 纪元 | 场景 | 元素 |
|---|---|---|
| 火种 | 篝火营地 | 火堆、洞穴口、森林 |
| 农耕 | 田野村落 | 麦田、房舍、灌溉渠 |
| 青铜·铁器 | 城邦熔炉 | 城墙、冶炼坊、道路 |
| 前工业 | 港口工场 | 帆船、港口、水磨坊 |
| 早期工业 | 蒸汽工场 | 烟囱、锅炉、齿轮 |

**能源可视化**（当前能源有专属动态表现）：
- 薪柴🔥：跳跃的橙色火焰粒子
- 畜力🐂：田野中移动的牛影
- 水车⚙️：旋转水轮（辐条转动）
- 风帆🌬️：摆动帆
- 水力🌊：坝体 + 流动水线
- 蒸汽🚂：烟囱冒烟粒子

**环境与资源可视化**：
- 森林：树冠团（随"森林枯竭"事件减少，直观看到资源危机）
- 河流：贯穿场景的水带（水利/水车高亮）
- 矿脉：冶炼坊旁的矿石堆（冶金后出现）
- 聚落规模：建筑数量随功率对数增长（`1 + log₁₀(P/10⁶)`），让"文明在长大"可见

**昼夜系统（纯视觉，不影响玩法）**：
- 周期 **60 秒**；天空色相循环（白天→黄昏→夜晚→黎明）
- 太阳沿弧线东升西落；夜晚月亮升起 + 星空渐显
- 场景亮度随昼夜微调（HUD 有 🌞/🌙 指示）
- 明确标注：**纯视觉层，与游戏机制零耦合**（资源产出/事件不受昼夜影响）

### 2.3 K 刻度尺视觉规范

- 顶部常驻：K 数值 + 渐变进度条（蓝→青→金），刻度标注 0.0/0.1/0.2/0.3/0.4。
- 到达纪元门槛：刻度条终点发光 +"🎉 可更替"提示。
- 主 HUD 大数字显示 **P（功率）**，K 作为里程碑刻度（对数尺只做里程碑，不做主多巴胺数字——双审查杠点 9 的采纳）。

### 2.4 信息层级（读法）

1. **一眼**：主画面（文明长什么样）+ K 刻度（走到哪了）
2. **二看**：左栏数值（功率/能量/科研/人口）
3. **三操作**：能源/建筑/科技（悬停有 Tooltip，点击弹科学卡）
4. **四感知**：右栏知识库 + 事件面板（异常时醒目）

## 3. 玩法体验设计

### 3.1 核心循环体验目标

- **30 秒上手**：功率自己涨，玩家第一件事是"点一个能点的东西"。
- **1 分钟正反馈**：第一次购买科技 / 扩建 → 增长率可见提升 + 日志 + 主画面聚落变多。
- **每个纪元一个里程碑时刻**：纪元演出（全屏暗转→纪元卡牌→特质选择）。
- **"看得见的因果"**：事件发生时，主画面资源（森林/河流）同步变化——抽象数字与视觉世界联动。

### 3.2 节奏与心流

| 段 | 节奏 | 心流设计 |
|---|---|---|
| 教学段（K<0.4） | 快进 0.4h | 高频小反馈，30–60s 一个"解锁/建造" |
| 中段（0.4–0.7） | 手动高峰 | 决策密集（能源切换/科研路径/事件应对） |
| 末段（>0.7） | 挂机+决策型手动 | 离线收益 + 3–5 分钟一次的轨道/殖民决策 |

### 3.3 反馈设计

- **数字**：功率/能量/科研实时跳动（刷新率 100ms，视觉平滑）。
- **事件**：事件面板高亮（橙红边框）+ 因果链逐行浮现 + 选项悬停 Tooltip。
- **纪元**：全屏演出（0.8s 静默→纪元卡牌→科学卡入口→特质 3 选 1）。

## 4. 音效与动效方向（阶段 2 细化，此处给方向）

- 音效：科技解锁"叮"、建造"笃"、能源切换"咔"、事件"警报"、纪元"庄严低鸣"；昼夜无音效（纯视觉）。
- 动效：数字增长轻量化（不飘字，避免与增量手感冲突）；主画面能源粒子常驻微动。
