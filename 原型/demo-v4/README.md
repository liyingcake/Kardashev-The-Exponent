# 文明指数 · demo-v4（统合乘数 · 能量利用）

> 双击 `index.html` 即玩（Ctrl+F5 强刷清缓存）。存档键 `exponent-demo-v4`。

## 一句话

节点是**工序**（采集→加工→定居→收集），不是堆量；能量是**利用**（燃料+原料→加工品→定居消费→劳动力+科技），不是烧掉；成长来自**一个可分解的小乘数**（整合×规模×技术×国策）。

## 怎么玩

1. **看中间的"经济窗口"**：一条产业链（采集→加工→定居点→收集台）的实时流量 + 一个小乘数。
2. **攒盈余、投资建造**（左栏"建造"，熟食计价）：造"森林/农田"（采集）+ "灶火"（加工）。**造一堆森林但不造灶火 = 生食堆积、统合度下降、P 不涨**——这就是"不该堆量"的教训。
3. **定国策**（左栏，至多 2 条）：重农/尚工/崇尚科学，影响小乘数里的"国策"因子。
4. **看小乘数**：总乘数 = 整合(统合度) × 规模(经济) × 技术 × 国策，可逐因子看懂"为什么我的效率是这个数"。

## 核心机制对照

| 你的要求 | v4 实现 |
|---|---|
| 节点统合，不堆量 | 五类功能节点串联成管线；造失衡节点 → 统合度(整合因子)下降 |
| 窗口 + 小乘数 | 中栏"经济窗口" + 可分解乘数（整合/规模/技术/国策） |
| 能量是利用不是消耗 | 灶火 = 燃料+原料→加工品，EROI≈6；P = 定居"消费"的能量流，不是"烧了多少柴" |
| 定居点消费产出劳动力/科技 | 定居点 = 消费端 + 劳动力源 + 科技源（维3 POP） |
| 收集节点 | 右栏"收集台"汇总产出 + 承载乘数名片 |
| 规模效应（维3） | 规模因子：加工吞吐越大越高效（集中 > 分散） |
| 供需/联系（Upload Labs） | 采集供给 vs 加工需求 → 统合度；缺料实时显示 |
