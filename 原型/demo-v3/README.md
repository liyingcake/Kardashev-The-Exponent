# 文明指数 · demo-v3（上帝视角 · 宏观引导）

> 双击 `index.html` 即可游玩（Ctrl+F5 强刷清缓存）。存档键 `exponent-demo-v3`（与 v2 隔离）。

## 一句话

你是**引导者，不是工匠**。文明会自己长大——你负责：**定国策、调权重、设探索焦点、裁决危机**；节点供需网络退到幕后，成为"文明解剖图"供你观察因果。

## 怎么玩

1. **看世界地图**（默认主画面）：中央是你的文明，周围是迷雾区域。
2. **调六支柱权重**（左栏"文明意志"）：探索/科研/农业/工业/文化/国防。调权重 → 文明自动体朝该方向扩建。这是每 1–3 分钟的核心手感。
3. **定国策**（左栏，至多 2 条）：重农/尚工/崇尚科学/扩张/守成/尚武，给文明装"人格"。
4. **设探索焦点**（右栏"探索世界"，点一个区域）：文明会优先探索它，发现新区域解锁新节点。
5. **裁决危机**（顶部横幅弹出时）：森林枯竭时三选一，国防值会减轻危机。
6. **纪元更替**：达标后点左栏金色按钮选特质。

## 观察层（可选，非必需）

- 切到"🕸️ 文明解剖图"标签：看节点供需网络（能源流、缺料红、缺工蓝、EROI 状态），点节点看详情。
- 你**不需要**手动放节点/连线/雇工——那些是自动体的事。

## 文件

| 文件 | 职责 |
|---|---|
| `data.js` | 数据层：纪元/资源/节点/科技/国策/支柱/区域/特质/危机 |

## 关键修正（相对 v2）

- **EROI 直接标定**（不再用 fuel equiv 反推，修复 v2 "恒绿"失效 bug）：篝火 6.7 / 水车 20 / 蒸汽 3.3 / 工厂 2.5，黄/红状态真实出现。
- **资源砍到 2 燃料**（wood/water）+ 人口流（麦田直接养人），移除微观的食物/矿石/金属库存。
- **劳动力抽象**：能源/科研节点满编才工作，自动体按优先级分配，玩家不再雇工。
- **连线降级为纯可视化**：全局资源池结算，消除"没连线→死锁"。
